Question

Let $F$ be a pseudorandom function. Show that the following MAC for messages of length $2n$ is insecure: The shared key is a random $k \in \{0,1\}^n$. To authenticate a message $m_1 \| m_2$ with $|m_1| = |m_2| = n$, compute the tag $\langle F_k(m_1), F_k(F_k(m_2)) \rangle$.

Attack 1: mix and match

As in Question 34, each half of the tag depends on only one half of the message.

1.Query $x \| y$ and receive $\langle F_k(x), F_k(F_k(y)) \rangle$.
2.Query $x' \| y'$ with $x' \ne x$, $y' \ne y$, and receive $\langle F_k(x'), F_k(F_k(y')) \rangle$.
3.Output $\big(x \| y',\ \langle F_k(x), F_k(F_k(y')) \rangle\big)$.

The tag is valid and $x \| y'$ was never queried, so the forgery succeeds with probability $1$.

Attack 2: using the inner value

The first half of a tag gives PRF values that can be reused inside the nested second half:

1.Query $x \| y$ and receive $a := F_k(x)$ as the first tag half.
2.Query $a \| y$ and receive $F_k(a) = F_k(F_k(x))$ as the first tag half.
3.Output $\big(x \| x,\ \langle a, F_k(a) \rangle\big)$, with $y \ne x$ so that $x \| x$ is new.

Indeed $\mathsf{Mac}_k(x \| x) = \langle F_k(x), F_k(F_k(x)) \rangle = \langle a, F_k(a) \rangle$. $\blacksquare$

Both attacks work with probability $1$ for every $F$, so the PRF assumption does not help. The construction does not bind the two halves of the message together.
