Question

Let $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ be two hash functions. You know that one of $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ is collision resistant, but you do not know which one.

  1. Show how to use $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ to construct a collision resistant hash function $(\mathsf{Gen}, H)$.
  2. Show formally that your construction is collision resistant.

1. Construction: concatenation

$\mathsf{Gen}$ outputs $s = (s_1, s_2)$ with $s_i \leftarrow \mathsf{Gen}_i(1^n)$, and $H^s(x) := H_1^{s_1}(x) \,\|\, H_2^{s_2}(x)$.

2. Proof

A collision $x \ne x'$ for $H$ has equal outputs in both halves, so it is a collision for $H_1$ and for $H_2$.

Say $H_1$ is collision resistant (the other case is symmetric). Given a collision finder $\mathcal{A}$ for $H$, build $\mathcal{A}_1(s_1)$: generate $s_2 \leftarrow \mathsf{Gen}_2(1^n)$ itself, run $\mathcal{A}(s_1, s_2)$ and output its pair. The key has the right distribution, and every collision for $H$ is one for $H_1$, so

$$\Pr[\mathsf{Hash\text{-}coll}_{\mathcal{A},H}(n) = 1] \le \Pr[\mathsf{Hash\text{-}coll}_{\mathcal{A}_1,H_1}(n) = 1] \le \mathsf{negl}(n).$$

The construction works without knowing which hash function is the secure one. $\blacksquare$
