Question

Let $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ be two hash functions. You know that one of $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ is collision resistant, but you do not know which one.

  1. Show how to use $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ to construct a collision resistant hash function $(\mathsf{Gen}, H)$.
  2. Show formally that your construction is collision resistant.

1. Construction: concatenation

Gen$s_1 \leftarrow \mathsf{Gen}_1(1^n)$, $s_2 \leftarrow \mathsf{Gen}_2(1^n)$; output $s = (s_1, s_2)$
$H^s(x)$$H_1^{s_1}(x) \,\|\, H_2^{s_2}(x)$

2. Proof

Observation. If $x \ne x'$ and $H^s(x) = H^s(x')$, the outputs are equal in both halves:

$$H_1^{s_1}(x) = H_1^{s_1}(x') \quad \text{and} \quad H_2^{s_2}(x) = H_2^{s_2}(x').$$

So every collision for $H$ is at the same time a collision for $H_1$ and for $H_2$.

Reduction. Suppose $(\mathsf{Gen}_1, H_1)$ is the collision-resistant one; the other case is symmetric. Let $\mathcal{A}$ be a PPT adversary against $H$. Build $\mathcal{A}_1$ against $H_1$:

$\mathcal{A}_1(s_1)$ $s_2 \leftarrow \mathsf{Gen}_2(1^n)$  (generated by itself) $(x, x') \leftarrow \mathcal{A}(s_1, s_2)$ output $(x, x')$

$s_1$ comes from $\mathsf{Gen}_1$ and $s_2$ from $\mathsf{Gen}_2$, so $\mathcal{A}$ sees a key with exactly the distribution of $\mathsf{Gen}$. Whenever $\mathcal{A}$ finds a collision for $H$, $\mathcal{A}_1$ has a collision for $H_1$ by the observation:

$$\Pr[\mathsf{Hash\text{-}coll}_{\mathcal{A},H}(n) = 1] \ \le\ \Pr[\mathsf{Hash\text{-}coll}_{\mathcal{A}_1,H_1}(n) = 1] \ \le\ \mathsf{negl}(n).$$

If instead $H_2$ is collision resistant, $\mathcal{A}_2$ generates $s_1$ itself and the same argument applies. In both cases $H$ is collision resistant, and the construction does not need to know which case holds. $\blacksquare$

The price is a longer output ($\ell_1 + \ell_2$ bits) and two hash evaluations. Note that $H_1(x) \oplus H_2(x)$ would not work in general.
