Question

Prove unconditionally the existence of an efficient pseudorandom function $F : \{0,1\}^* \times \{0,1\}^* \to \{0,1\}^*$ where the input length is logarithmic in the security parameter (and the key has length polynomial in the security parameter).

Idea

If the input has only $\log n$ bits, there are only $2^{\log n} = n$ possible inputs. A truly random function on this domain is just a table of $n$ random values, which has polynomial size. So we can use the whole table as the key.

Construction

Let the input length be $\ell_{in}(n) = \log n$ (for simplicity, $n$ a power of 2) and the output length $\ell_{out}(n) = n$.

Key$k = (k_0, k_1, \dots, k_{n-1})$ with each $k_i \in \{0,1\}^n$, chosen uniformly; $|k| = n^2$
$F_k(x)$read $x \in \{0,1\}^{\log n}$ as an integer $i \in \{0, \dots, n-1\}$ and output $k_i$
  • Efficient: computing $F_k(x)$ is one table lookup, polynomial in $n$.
  • Polynomial key length: $n \cdot n = n^2$.

Proof of pseudorandomness

A uniformly random function $f : \{0,1\}^{\log n} \to \{0,1\}^n$ is described by its table of values $(f(0), \dots, f(n-1))$, and this table is uniform over $(\{0,1\}^n)^n$. A uniform key $k$ is uniform over exactly the same set. So $F_k$ and $f$ have identical distributions, and for every distinguisher $D$, even one with unlimited running time,

$$\big|\Pr[D^{F_k(\cdot)}(1^n) = 1] - \Pr[D^{f(\cdot)}(1^n) = 1]\big| = 0.$$

This uses no computational assumption, so the existence is unconditional. $\blacksquare$

This also works for input length $c \cdot \log n$ (table size $n^c$), but not for $\omega(\log n)$: then the table would be super-polynomial. Building PRFs with long inputs needs assumptions (e.g. one-way functions, via GGM).
