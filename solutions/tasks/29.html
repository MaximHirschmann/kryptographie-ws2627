Question

Prove unconditionally the existence of an efficient pseudorandom function $F : \{0,1\}^* \times \{0,1\}^* \to \{0,1\}^*$ where the input length is logarithmic in the security parameter (and the key has length polynomial in the security parameter).

Construction: the key is a lookup table

Let $F : \{0,1\}^n \times \{0,1\}^{\log n} \to \{0,1\}$ be defined by

$$F_k(i) := \text{the } i\text{-th bit of } k,$$

where the input $i$ is read as an integer in $\{0, \dots, n-1\}$. It is efficient (one lookup), and the key has length $n$.

Proof

A function $\{0,1\}^{\log n} \to \{0,1\}$ is a table of $n$ bits, and a uniformly random function is a uniformly random such table. A uniform key $k$ is exactly such a table. So $F_k$ for uniform $k$ is a random function, and every distinguisher, even an unbounded one, has advantage $0$. No assumption is used. $\blacksquare$

The same works with $n$-bit outputs (key = $n$ blocks of $n$ bits) or input length $c \log n$. It fails for longer inputs, because the table would no longer have polynomial size.
