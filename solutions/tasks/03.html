Question

Show that the shift, substitution, and Vigenère ciphers are all trivial to break using a known-plaintext attack. How much known plaintext is needed to completely recover the key for each of the ciphers?

In a known-plaintext attack the attacker gets pairs $(m, c)$. All three ciphers work letter by letter, so each letter pair $(m_x, c_x)$ is one simple equation for the key.

CipherKey from one letter pairKnown plaintext needed
Shift$k = c_x - m_x \bmod 26$1 letter
Substitution$\pi(m_x) = c_x$a text with 25 different letters (the 26th value follows, since $\pi$ is a bijection)
Vigenère$k_{x \bmod t} = c_x - m_x \bmod 26$$t$ consecutive letters if the period $t$ is known; otherwise $c_x - m_x$ is the key repeated, which reveals $t$

No search or statistics is needed, so the attacks are trivial. For the substitution cipher the text may have to be long, because rare letters such as q, x, z appear late; but the common letters already decrypt most of a ciphertext.
