Question

Let $\Pi$ be a CCA-secure public-key encryption scheme and $\Pi'$ a CCA-secure private-key encryption scheme. Is the hybrid scheme of Construction 10.12 (encrypt a fresh key $k$ with $\Pi$, the message with $\Pi'$ under $k$) CCA-secure? Prove your answer.

Source: Katz & Lindell, 1st ed., Exercise 10.15 (restated). Compare Question 49 (the CPA version) and Question 54.

The scheme

Enchy$k \leftarrow \{0,1\}^n$; $c_1 \leftarrow \mathsf{Enc}_{pk}(k)$; $c_2 \leftarrow \mathsf{Enc}'_k(m)$; output $\langle c_1, c_2 \rangle$
Dechy$k := \mathsf{Dec}_{sk}(c_1)$ (output $\bot$ if $\bot$); output $\mathsf{Dec}'_k(c_2)$
Claim. Yes. If $\Pi$ is CCA-secure and $\Pi'$ is CCA-secure (even for a single encryption under each key), then $\Pi^{\mathsf{hy}}$ is CCA-secure.

Proof with two game hops

Fix a PPT adversary $\mathcal{A}$ and a challenge bit $b$. Let $(c_1^*, c_2^*)$ be the challenge, created with the key $k^*$.

Game 0 (real experiment). $c_1^* \leftarrow \mathsf{Enc}_{pk}(k^*)$, $c_2^* \leftarrow \mathsf{Enc}'_{k^*}(m_b)$. A decryption query $(c_1, c_2) \ne (c_1^*, c_2^*)$ is answered as follows: if $c_1 \ne c_1^*$, use $\mathsf{Dec}_{sk}(c_1)$; if $c_1 = c_1^*$, use $k^*$ directly to decrypt $c_2$. By correctness $\mathsf{Dec}_{sk}(c_1^*) = k^*$, so this is the real decryption oracle.

Game 1. Like Game 0, but $c_1^* \leftarrow \mathsf{Enc}_{pk}(0^n)$. Queries with $c_1 = c_1^*$ are still answered with $k^*$.

Game 0 ≈ Game 1 (CCA security of $\Pi$)

Reduction $\mathcal{B}$ against $\Pi$:

  • Get $pk$ and a decryption oracle $\mathsf{Dec}_{sk}(\cdot)$. Choose $k^* \leftarrow \{0,1\}^n$. Answer $\mathcal{A}$'s decryption queries: if $c_1 \ne c_1^*$ (or before the challenge), get $k = \mathsf{Dec}_{sk}(c_1)$ from the oracle and decrypt $c_2$ with it; if $c_1 = c_1^*$, use $k^*$.
  • When $\mathcal{A}$ outputs $m_0, m_1$: output $(k^*, 0^n)$ as $\mathcal{B}$'s own challenge pair and receive $c_1^*$; set $c_2^* \leftarrow \mathsf{Enc}'_{k^*}(m_b)$.
  • Output $1$ iff $\mathcal{A}$ outputs $b$.

$\mathcal{B}$ never asks for $c_1^*$ itself. If $c_1^*$ encrypts $k^*$, $\mathcal{A}$ is in Game 0; if it encrypts $0^n$, in Game 1. So $|\Pr[G_0] - \Pr[G_1]| \le \mathsf{negl}(n)$.

Game 1 is hard to win (CCA security of $\Pi'$)

In Game 1, $c_1^*$ no longer contains $k^*$. Reduction $\mathcal{C}$ against $\Pi'$ (whose challenger holds $k^*$):

  • Generate $(pk, sk)$ and $c_1^* \leftarrow \mathsf{Enc}_{pk}(0^n)$ itself.
  • Decryption query $(c_1, c_2)$: if $c_1 \ne c_1^*$, decrypt completely with $sk$; if $c_1 = c_1^*$, then $c_2 \ne c_2^*$ (otherwise the query is the challenge), so ask the $\Pi'$ decryption oracle for $\mathsf{Dec}'_{k^*}(c_2)$, which is allowed.
  • Forward $m_0, m_1$ as $\mathcal{C}$'s challenge, receive $c_2^*$, give $\langle c_1^*, c_2^* \rangle$ to $\mathcal{A}$, and output $\mathcal{A}$'s guess.

This simulates Game 1 exactly, so $\Pr[G_1] \le \frac12 + \mathsf{negl}(n)$.

Conclusion

$$\Pr[\mathsf{PubK}^{\mathsf{cca}}_{\mathcal{A},\Pi^{\mathsf{hy}}} = 1] = \Pr[G_0] \le \Pr[G_1] + \mathsf{negl}(n) \le \tfrac12 + \mathsf{negl}(n). \quad \blacksquare$$
Result. Yes, the hybrid of a CCA-secure public-key scheme and a CCA-secure private-key scheme is CCA-secure (the "KEM/DEM" composition). Every decryption query either changes $c_1$ (answered by $\Pi$'s oracle) or keeps $c_1^*$ and changes $c_2$ (answered by $\Pi'$'s oracle). $\blacksquare$

Both parts must be CCA-secure. If $\Pi'$ is only CPA-secure (e.g. counter mode), the attacker keeps $c_1^*$, flips a bit of $c_2^*$ and asks for decryption, which recovers $m_b$ with one bit flipped.
