Question

Lamport's one-time signature scheme is only secure for one signature. Describe an adversary that obtains signatures on two messages of its choice and can then forge a signature on any message.

Source: Katz & Lindell, 1st ed., Exercise 12.7 (restated).

Lamport's scheme

For messages $m \in \{0,1\}^\ell$ and a one-way function $f$:

Gen$sk = (x_{i,b})_{i \le \ell,\, b \in \{0,1\}}$ uniform; $pk = (y_{i,b})$ with $y_{i,b} = f(x_{i,b})$
Sign$\sigma = (x_{1,m_1}, \dots, x_{\ell,m_\ell})$: for each position, reveal the pre-image for the bit value
Vrfycheck $f(\sigma_i) = y_{i,m_i}$ for all $i$

Attack with two queries

1.Ask for the signature on $0^\ell$: this reveals $x_{1,0}, \dots, x_{\ell,0}$.
2.Ask for the signature on $1^\ell$: this reveals $x_{1,1}, \dots, x_{\ell,1}$.
3.Now the whole private key is known. For any $m^* \notin \{0^\ell, 1^\ell\}$, output $\sigma^* = (x_{1,m^*_1}, \dots, x_{\ell,m^*_\ell})$.

$\sigma^*$ passes verification by definition, and $m^*$ was not queried. The forgery succeeds with probability $1$. $\blacksquare$

The same works with any two messages $m, \bar m$ where $\bar m$ is the bitwise complement of $m$. More generally, two signatures on $m, m'$ allow forgeries on every message that agrees with $m$ or $m'$ in each position. For example, $00$ and $11$ also give $01$ and $10$.

Result. Each signature reveals half of the secret values. Signatures on two complementary messages reveal all of them, and then any message can be signed. Lamport keys must be used at most once. $\blacksquare$
