Question

Call a scheme perfectly secret for two messages if two messages $M, M'$, drawn independently from the same distribution over $\mathcal{M}$ and encrypted with the same key to $C, C'$, satisfy

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c'] = \Pr[M = m \wedge M' = m']$$

for all distributions, all $m, m' \in \mathcal{M}$ and all $c, c'$ with $\Pr[C = c \wedge C' = c'] \gt 0$. Prove that no encryption scheme satisfies this definition.

Source: Katz & Lindell, 1st ed., Exercise 2.9 (restated).

Idea

Both ciphertexts are decrypted with the same key. So if the two ciphertexts are equal, the two messages must be equal too. Seeing $C = C'$ therefore tells the adversary that $M = M'$, which is information about the messages.

Proof

Let $|\mathcal{M}| \ge 2$ (otherwise there is nothing to encrypt) and take the uniform distribution over $\mathcal{M}$. Fix $m \ne m'$, so $\Pr[M = m \wedge M' = m'] = 1/|\mathcal{M}|^2 \gt 0$.

Step 1: equal ciphertexts happen with positive probability

Fix a key $k$ and a message $\hat m$. $\mathsf{Enc}_k(\hat m)$ is a distribution over the finite set $\mathcal{C}$. Two independent encryptions of $\hat m$ under $k$ are equal with probability

$$\sum_{c} \Pr[\mathsf{Enc}_k(\hat m) = c]^2 \;\ge\; \frac{1}{|\mathcal{C}|} \gt 0$$

(by Cauchy–Schwarz; if $\mathsf{Enc}$ is deterministic it is even $1$). The event $M = M' = \hat m$ has probability $1/|\mathcal{M}|^2 \gt 0$. Hence $\Pr[C = C'] \gt 0$, and there is some $c^*$ with $\Pr[C = c^* \wedge C' = c^*] \gt 0$.

Step 2: given $C = C' = c^*$, the messages are equal

Let $k$ be the key that was used. By correctness, $M = \mathsf{Dec}_k(C)$ and $M' = \mathsf{Dec}_k(C')$, and $\mathsf{Dec}$ is deterministic. If $C = C' = c^*$, then $M = \mathsf{Dec}_k(c^*) = M'$. So

$$\Pr[M = m \wedge M' = m' \mid C = c^* \wedge C' = c^*] = 0 \quad \text{since } m \ne m'.$$

Step 3: contradiction

$$0 = \Pr[M = m \wedge M' = m' \mid C = C' = c^*] \ne \Pr[M = m \wedge M' = m'] = \frac{1}{|\mathcal{M}|^2}.$$
Result. Every scheme violates the definition for the uniform distribution, two different messages $m \ne m'$ and a ciphertext pair $(c^*, c^*)$. No scheme is perfectly secret for two messages under the same key. $\blacksquare$

The book's hint uses the opposite view, which is shorter for deterministic $\mathsf{Enc}$: take $m = m'$ and $c \ne c'$. A deterministic scheme encrypts the same message twice to the same ciphertext, so $\Pr[M = M' = m \mid C = c, C' = c'] = 0 \ne \Pr[M = M' = m]$. The proof above also covers randomized encryption. The lesson matches the one-time pad: a key must only be used once (see the script, §5.3).
