Question

Call a scheme perfectly secret for two messages if two messages $M, M'$, drawn independently from the same distribution over $\mathcal{M}$ and encrypted with the same key to $C, C'$, satisfy

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c'] = \Pr[M = m \wedge M' = m']$$

for all distributions, all $m, m' \in \mathcal{M}$ and all $c, c'$ with $\Pr[C = c \wedge C' = c'] \gt 0$. Prove that no encryption scheme satisfies this definition.

Source: Katz & Lindell, 1st ed., Exercise 2.9 (restated).

Idea. Both ciphertexts are decrypted with the same key, so equal ciphertexts imply equal messages. Seeing $C = C'$ therefore tells the adversary that $M = M'$.

Proof

Take the uniform distribution over $\mathcal{M}$ (with $|\mathcal{M}| \ge 2$) and some $c$ with $\Pr[C = c \wedge C' = c] \gt 0$. Such a $c$ exists: with positive probability $M = M'$, and two encryptions of the same message under the same key coincide with positive probability.

Let $m \ne m'$. For every key $k$, correctness gives $\mathsf{Dec}_k(c) = M$ and $\mathsf{Dec}_k(c) = M'$, so $C = C' = c$ is impossible when $M = m \ne m' = M'$:

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c] = 0 \ne \frac{1}{|\mathcal{M}|^2} = \Pr[M = m \wedge M' = m'].$$

This holds for every scheme, so none satisfies the definition. $\blacksquare$
