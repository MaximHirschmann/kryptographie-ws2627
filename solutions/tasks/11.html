Question

When using the one-time pad (Vernam's cipher) with the key $k = 0^\ell$, it follows that $\mathsf{Enc}_k(m) = k \oplus m = m$ and the message is effectively sent in the clear! It has therefore been suggested to improve the one-time pad by only encrypting with a key $k \ne 0^\ell$ (i.e., to have $\mathsf{Gen}$ choose $k$ uniformly at random from the set of non-zero keys of length $\ell$). Is this an improvement? In particular, is it still perfectly secret? Prove your answer. If your answer is positive, explain why the one-time pad is not described in this way. If your answer is negative, reconcile this with the fact that encrypting with $0^\ell$ doesn't change the plaintext.

Answer. No. The modified scheme is not perfectly secret.

Proof

Take the uniform distribution over $\mathcal{M} = \{0,1\}^\ell$ and any $\alpha \in \{0,1\}^\ell$. The ciphertext $\alpha$ can only come from $\alpha$ via the key $0^\ell$, which is excluded, so

$$\Pr[M = \alpha \mid C = \alpha] = 0 \ne 2^{-\ell} = \Pr[M = \alpha].$$

This contradicts perfect secrecy: seeing $c$ tells the attacker that $m \ne c$. $\blacksquare$

Shorter still: $|\mathcal{K}| = 2^\ell - 1 \lt |\mathcal{M}|$, and perfect secrecy needs $|\mathcal{K}| \ge |\mathcal{M}|$ (script Theorem 6).

Reconciling with "the key $0^\ell$ sends the message in the clear"

The eavesdropper never knows which key was used. With the original one-time pad, the ciphertext $c = m$ is exactly as likely as any other ciphertext, so the fact that $\mathsf{Enc}_{0^\ell}(m) = m$ is of no help to it. To obtain perfect secrecy, encrypting with $0^\ell$ must be possible.
