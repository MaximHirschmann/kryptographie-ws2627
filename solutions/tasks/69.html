Question

Recall the Merkle–Damgård transform for a collision-resistant compression function $h^s : \{0,1\}^{2n} \to \{0,1\}^n$: pad $x$ with zeros to $B$ blocks $x_1, \dots, x_B$ of $n$ bits, append the length block $x_{B+1} := L = |x|$, set $z_0 := 0^n$ and $z_i := h^s(z_{i-1} \| x_i)$, and output $z_{B+1}$. For each modification, decide whether the result is collision resistant. Prove it, or give an attack.

  1. No length block: output $z_B$.
  2. Output $z_B \| L$ instead of $z_{B+1} = h^s(z_B \| L)$.
  3. Choose $z_0 := IV \leftarrow \{0,1\}^n$ at random and output $IV \| z_{B+1}$.
  4. No IV: start with $z_1 := x_1$, compute $z_i := h^s(z_{i-1} \| x_i)$ for $i = 2, \dots, B+1$ and output $z_{B+1}$.
  5. Start with $z_0 := L$, compute $z_i := h^s(z_{i-1} \| x_i)$ for $i = 1, \dots, B$ and output $z_B$.

Source: Katz & Lindell, 1st ed., Exercise 4.15 (restated).

Tool (the core of the Merkle–Damgård proof): if two chains with the same number of blocks end in the same value, take the last position where the inputs $(z_{i-1} \| x_i)$ differ. Its outputs are equal, so this is a collision in $h^s$. If no position differs, the inputs were equal.

(a) No length block: not collision resistant

Take any $x$ whose length is not a multiple of $n$ and let $x' := x \| 0$. Both are padded to the same blocks, so $H^s(x) = H^s(x')$ with $x \ne x'$.

(b) Output $z_B \| L$: collision resistant

Equal outputs force $L = L'$, hence the same number of blocks, and $z_B = z'_B$. Since $x \ne x'$, some block differs, and the tool gives a collision in $h^s$. (The case $L \ne L'$ of the usual proof disappears: then the outputs already differ.) $\blacksquare$

(c) Random IV, sent along: collision resistant

Equal outputs contain the same $IV$, and for a fixed starting value the usual Merkle–Damgård proof works unchanged. $\blacksquare$

(d) No IV, start from $x_1$: collision resistant

The same proof: if $L \ne L'$, the final inputs $z_B \| L$ and $z'_{B'} \| L'$ collide; if $L = L'$, the tool runs back to $i = 2$, and if no collision appears then $z_1 = z'_1$, i.e. $x_1 = x'_1$, so $x = x'$. $\blacksquare$

(e) Length as IV, no final length block: not collision resistant in general

Messages of different lengths start at different values, so a collision only needs an $h$-preimage of a length value, which collision resistance does not rule out. Concretely, let $h_0$ be collision resistant with $(n-1)$-bit output and, writing $\langle v \rangle$ for the $n$-bit encoding of $v$,

$$h^s(u) = \begin{cases} \langle n \rangle & \text{if } u = \langle 2n \rangle \| 0^n,\\ 1 \| h_0^s(u) & \text{otherwise.} \end{cases}$$

$h$ is still collision resistant (the special output starts with $0$ and has one preimage). But $x = 0^n \| y$ (length $2n$) and $x' = y$ (length $n$) collide: the chain of $x$ goes $\langle 2n \rangle \to \langle n \rangle \to h^s(\langle n \rangle \| y)$, and the chain of $x'$ goes $\langle n \rangle \to h^s(\langle n \rangle \| y)$. $\blacksquare$
