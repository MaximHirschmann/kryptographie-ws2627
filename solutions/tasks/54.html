Question

Let $\Pi$ be a public encryption scheme having indistinguishable encryptions under a chosen-plaintext attack. Let $\Pi'$ be a private-key encryption scheme having indistinguishable encryptions under a chosen-ciphertext attack.

Consider the following construction of a public-key encryption scheme $\Pi^*$. Let $H : \{0,1\}^n \to \{0,1\}^n$ be a function.

  • $\mathsf{Gen}^*$: input $1^n$; $(pk, sk) \leftarrow \mathsf{Gen}(1^n)$; output $(pk, sk)$
  • $\mathsf{Enc}^*$: input $pk$, $m \in \{0,1\}^n$; $r \leftarrow \{0,1\}^n$; output $\langle \mathsf{Enc}_{pk}(r), \mathsf{Enc}'_{H(r)}(m) \rangle$
  • $\mathsf{Dec}^*$: input $sk$, $\langle c_1, c_2 \rangle$; $r := \mathsf{Dec}_{sk}(c_1)$; output $\mathsf{Dec}'_{H(r)}(c_2)$

In what follows, assume that we model $H$ as a random oracle.

  1. Name a scheme $\Pi$ for which $\Pi^*$ has indistinguishable encryptions under a chosen-ciphertext attack.
  2. Does $\Pi^*$ have indistinguishable encryptions under a chosen-ciphertext attack in general? If yes then provide a proof. Otherwise, explain where a proof would break down.

1. A scheme that works: RSA (lecture, Mitschrift 18.2)

Take plain RSA for the first component: $c_1 := [r^e \bmod N]$ for uniform $r \in \mathbb{Z}_N^*$, with $H : \mathbb{Z}_N^* \to \{0,1\}^n$. The lecture's theorem says:

$$\langle [r^e \bmod N],\ \mathsf{Enc}'_{H(r)}(m) \rangle \ \text{ is CCA-secure if RSA is hard, } \Pi' \text{ is CCA-secure and } H \text{ is a random oracle.}$$

Proof idea. Let $\mathsf{Query}$ be the event that $\mathcal{A}$ asks $H$ at the challenge's $r$.

  • Without $\mathsf{Query}$, $H(r)$ is a fresh uniform key, so winning means breaking $\Pi'$ (reduction to its CCA security).
  • $\mathsf{Query}$ means inverting RSA on $c_1$. The RSA reduction can answer decryption queries without $d$, because $x \mapsto x^e$ is a permutation: every $c_1$ belongs to exactly one $r$, and $[r^e \bmod N] = c_1$ can be checked with the public key.

Strictly, textbook RSA is only one-way, not CPA-secure. Any CCA-secure $\Pi$ also works.

2. Not in general

No. A CPA-secure $\Pi$ may be malleable: the adversary turns the challenge $c_1$ into a different $c_1'$ that decrypts to the same $r$, and the decryption oracle then returns $m_b$.

Counterexample. From any CPA-secure $\hat\Pi$, let $\mathsf{Enc}_{pk}(r) := \langle \hat{\mathsf{Enc}}_{pk}(r), 0 \rangle$, where decryption ignores the extra bit; $\Pi$ is still CPA-secure. Given the challenge $\langle \langle \hat c, 0 \rangle, c_2 \rangle$, ask for the decryption of $\langle \langle \hat c, 1 \rangle, c_2 \rangle$. It is a different ciphertext with the same $r$, so the answer is $m_b$. The attack wins with probability $1$.

Where the proof breaks down. A reduction to $\Pi$ has no decryption oracle, so for a query with $c_1' \ne c_1$ it cannot find $r' = \mathsf{Dec}_{sk}(c_1')$, and for a general randomised $\Pi$ it cannot even test whether $c_1'$ encrypts a given $r'$. (RSA avoids this because the test $r'^e = c_1'$ is public.) $\blacksquare$
