Question

Weaken the definition of Question 57: the adversary may learn whether the two messages are equal, but nothing else. For all distributions, all $m \ne m'$ and all $c \ne c'$ with $\Pr[C = c \wedge C' = c'] \gt 0$ we require

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c'] = \Pr[M = m \wedge M' = m' \mid M \ne M'],$$

where $M, M'$ are independent samples from the same distribution, encrypted with the same key. Give a scheme that provably satisfies this definition. How long is its key compared to a message? (It need not be efficient.)

Source: Katz & Lindell, 1st ed., Exercise 2.10 (restated).

Construction: a random permutation

Let $N = |\mathcal{M}|$ and $\mathcal{C} = \mathcal{M}$. $\mathsf{Gen}$ chooses a uniformly random permutation $\pi$ of $\mathcal{M}$; $\mathsf{Enc}_\pi(m) = \pi(m)$ and $\mathsf{Dec}_\pi(c) = \pi^{-1}(c)$.

Proof

For fixed $m \ne m'$ and $c \ne c'$, a random permutation maps $(m, m')$ to $(c, c')$ with probability $\frac{1}{N(N-1)}$, the same for all such pairs. Since the key is independent of the messages,

$$\Pr[M = m \wedge M' = m' \wedge C = c \wedge C' = c'] = \frac{\Pr[M = m \wedge M' = m']}{N(N-1)}.$$

$\pi$ is a bijection, so $C \ne C'$ happens exactly when $M \ne M'$. Summing over all pairs $m_1 \ne m_2$ gives $\Pr[C = c \wedge C' = c'] = \frac{\Pr[M \ne M']}{N(N-1)}$. Dividing:

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c'] = \frac{\Pr[M = m \wedge M' = m']}{\Pr[M \ne M']} = \Pr[M = m \wedge M' = m' \mid M \ne M']. \qquad \blacksquare$$

Key length

There are $N!$ keys, so a key has about $\log_2 N! \approx N \log_2 N$ bits. For $\ell$-bit messages that is about $\ell \cdot 2^\ell$ bits, exponentially longer than a message.

The proof only used that every pair of distinct messages goes to every pair of distinct ciphertexts with the same probability. A random affine map $m \mapsto am + b$ over $\mathrm{GF}(2^\ell)$ ($a \ne 0$) also has this property, with a key of only $2\ell$ bits.
