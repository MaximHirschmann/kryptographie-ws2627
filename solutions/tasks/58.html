Question

Weaken the definition of Question 57: the adversary may learn whether the two messages are equal, but nothing else. For all distributions, all $m \ne m'$ and all $c \ne c'$ with $\Pr[C = c \wedge C' = c'] \gt 0$ we require

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c'] = \Pr[M = m \wedge M' = m' \mid M \ne M'],$$

where $M, M'$ are independent samples from the same distribution, encrypted with the same key. Give a scheme that provably satisfies this definition. How long is its key compared to a message? (It need not be efficient.)

Source: Katz & Lindell, 1st ed., Exercise 2.10 (restated).

Construction 1: a random permutation

Let $N = |\mathcal{M}|$ and $\mathcal{C} = \mathcal{M}$.

Genchoose a uniformly random permutation $\pi$ of $\mathcal{M}$; output $k = \pi$
Enc$\mathsf{Enc}_\pi(m) = \pi(m)$
Dec$\mathsf{Dec}_\pi(c) = \pi^{-1}(c)$

Key lemma

For fixed $m \ne m'$ and $c \ne c'$:

$$\Pr_\pi[\pi(m) = c \wedge \pi(m') = c'] = \frac{(N-2)!}{N!} = \frac{1}{N(N-1)}.$$

The pair $(\pi(m), \pi(m'))$ is uniform over all ordered pairs of distinct ciphertexts, whatever $m \ne m'$ are. Also, since $\pi$ is a bijection, $C \ne C'$ holds exactly when $M \ne M'$.

Proof

Fix a distribution and $m \ne m'$, $c \ne c'$. The key is independent of the messages, so

$$\Pr[M = m \wedge M' = m' \wedge C = c \wedge C' = c'] = \Pr[M = m \wedge M' = m'] \cdot \tfrac{1}{N(N-1)}.$$

Summing over all pairs $(m_1, m_2)$: pairs with $m_1 = m_2$ give $C = C'$ and contribute nothing, so

$$\Pr[C = c \wedge C' = c'] = \sum_{m_1 \ne m_2} \Pr[M = m_1 \wedge M' = m_2] \cdot \tfrac{1}{N(N-1)} = \frac{\Pr[M \ne M']}{N(N-1)}.$$

Dividing the two lines:

$$\Pr[M = m \wedge M' = m' \mid C = c \wedge C' = c'] = \frac{\Pr[M = m \wedge M' = m']}{\Pr[M \ne M']} = \Pr[M = m \wedge M' = m' \mid M \ne M'],$$

where the last step uses $m \ne m'$ (so the event $M = m \wedge M' = m'$ is contained in $M \ne M'$). $\blacksquare$

Key length. There are $N!$ keys, so a key needs $\log_2 N! \approx N \log_2 N$ bits. For $\ell$-bit messages ($N = 2^\ell$) that is about $\ell \cdot 2^\ell$ bits: exponentially longer than a message.

Construction 2: much shorter keys

The proof only used the key lemma: every pair of distinct messages goes to every pair of distinct ciphertexts with the same probability. An affine map already has this property. Identify $\{0,1\}^\ell$ with the field $\mathrm{GF}(2^\ell)$:

Gen$a \leftarrow \mathrm{GF}(2^\ell) \setminus \{0\}$, $b \leftarrow \mathrm{GF}(2^\ell)$; output $k = (a, b)$
Enc$\mathsf{Enc}_{a,b}(m) = a \cdot m + b$
Dec$\mathsf{Dec}_{a,b}(c) = a^{-1}(c - b)$

For $m \ne m'$ and $c \ne c'$ the system $am + b = c$, $am' + b = c'$ has exactly one solution: $a = (c - c')/(m - m') \ne 0$ and $b = c - am$. There are $N(N-1)$ keys, so the probability is $\frac{1}{N(N-1)}$ and the key lemma holds. The proof above goes through unchanged. The key is $2\ell$ bits, twice the message length.

Lower bound: $2\ell$ is essentially optimal

Fix $c \ne c'$ with $\Pr[C = c \wedge C' = c'] \gt 0$ under the uniform distribution. The definition forces every pair $m \ne m'$ to have positive probability given $(c, c')$, so every such pair must be reachable. A key determines $(m, m') = (\mathsf{Dec}_k(c), \mathsf{Dec}_k(c'))$, so different pairs need different keys: $|\mathcal{K}| \ge N(N-1)$, i.e. about $2\ell$ bits.

Result. A uniformly random permutation works (key $\approx \ell \cdot 2^\ell$ bits). A random affine map $m \mapsto am + b$ over $\mathrm{GF}(2^\ell)$ also works, with a key of $2\ell$ bits, which is optimal up to one bit. $\blacksquare$
