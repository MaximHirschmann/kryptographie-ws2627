Question

Let $(\mathsf{Gen}, H)$ be a collision-resistant hash function. Is $(\mathsf{Gen}, \bar H)$ with $\bar H^s(x) := H^s(H^s(x))$ necessarily collision resistant?

Answer. Yes. Any collision for $\bar H$ contains a collision for $H$.

Key observation

Let $x \ne x'$ with $\bar H^s(x) = \bar H^s(x')$, i.e. $H^s(H^s(x)) = H^s(H^s(x'))$. There are two cases:

  1. $H^s(x) \ne H^s(x')$. Then $y := H^s(x)$ and $y' := H^s(x')$ are different inputs with $H^s(y) = H^s(y')$, a collision for $H$.
  2. $H^s(x) = H^s(x')$. Then $(x, x')$ itself is a collision for $H$, because $x \ne x'$.

Reduction

Let $\bar{\mathcal{A}}$ be a PPT adversary in $\mathsf{Hash\text{-}coll}_{\bar{\mathcal{A}},\bar H}(n)$. Build $\mathcal{A}$ against $H$:

$\mathcal{A}(s)$ run $\bar{\mathcal{A}}(s)$ and receive $x, x'$ if $H^s(x) \ne H^s(x')$: output $(H^s(x), H^s(x'))$ else: output $(x, x')$

$\mathcal{A}$ is PPT, gets the same key $s \leftarrow \mathsf{Gen}(1^n)$, and by the case distinction it outputs a collision whenever $\bar{\mathcal{A}}$ does:

$$\Pr[\mathsf{Hash\text{-}coll}_{\mathcal{A},H}(n) = 1] \ \ge\ \Pr[\mathsf{Hash\text{-}coll}_{\bar{\mathcal{A}},\bar H}(n) = 1].$$

The left side is negligible, so the right side is too. $\blacksquare$

For the composition to be defined, the output of $H^s$ must be a valid input for $H^s$. This holds for $H^s : \{0,1\}^* \to \{0,1\}^{\ell(n)}$.
