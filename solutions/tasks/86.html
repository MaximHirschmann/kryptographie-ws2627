Question

Two results from the book: Theorem 10.10 (single-message security implies multiple-message security for public-key encryption) and Proposition 10.11 (encrypting a long message bit by bit with a secure single-bit scheme $\Pi$ gives a secure scheme $\Pi'$). Show that Proposition 10.11 does not hold for CCA security, whereas Theorem 10.10 does. Explain why CPA security does not distinguish "many messages" from "one long message", but CCA security does.

Source: Katz & Lindell, 1st ed., Exercise 10.13 (restated).

$\Pi'$ encrypts $m = m_1 \cdots m_t$ bit by bit as $\langle \mathsf{Enc}_{pk}(m_1), \dots, \mathsf{Enc}_{pk}(m_t) \rangle$.

Part 1: $\Pi'$ is not CCA-secure, even if $\Pi$ is

1.Output $m_0 = 00$ and $m_1 = 11$; receive $c = \langle c_1, c_2 \rangle$.
2.Compute $c_2' \leftarrow \mathsf{Enc}_{pk}(0)$ and ask the decryption oracle for $\langle c_1, c_2' \rangle$.
3.The answer is $b\,0$. Output its first bit $b$.

The query is legal, since $\langle c_1, c_2' \rangle \ne c$ (a CPA-secure $\Pi$ repeats a ciphertext only with negligible probability). So the attacker wins with probability $1 - \mathsf{negl}(n)$. $\blacksquare$

Part 2: Theorem 10.10 holds for CCA

In the multiple-message CCA experiment, every challenge ciphertext $C^i$ is forbidden as a decryption query. The usual hybrid argument then goes through: to distinguish neighbouring hybrids, the reduction embeds its own challenge at position $j$, encrypts all other positions itself with $pk$, and forwards every decryption query to its own oracle. The only query it may not forward is its challenge $C^j$, which the adversary may not ask either. An advantage $\varepsilon$ over $t$ hybrids gives advantage $\varepsilon/t$ against $\Pi$. $\blacksquare$

Part 3: why only CCA distinguishes the two

Under CPA the adversary sees the same vector of ciphertexts either way and has no oracle whose rules depend on the view. Under CCA the rule "do not query the challenge" does: for $t$ separate messages each component is forbidden, but for one long message only the exact vector is forbidden, so vectors that reuse some components, as in Part 1, are allowed.
