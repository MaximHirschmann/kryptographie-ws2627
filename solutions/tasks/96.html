Question

Call a public-key scheme one-way if every PPT adversary that gets $pk$ and an encryption $c$ of a uniform $m \in \{0,1\}^n$ outputs $m$ with only negligible probability.

  1. In the random oracle model, construct a CPA-secure scheme from any one-way scheme.
  2. Can a scheme with deterministic encryption be one-way? Give a proof, or a construction based on an assumption from the lecture.

Source: Katz & Lindell, 1st ed., Exercise 13.5 (restated).

(a) From one-way to CPA-secure

Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be one-way and $H : \{0,1\}^n \to \{0,1\}^{\ell}$ a random oracle. Encrypt a random string with $\Pi$ and use its hash as a one-time pad:

Gen'same as $\mathsf{Gen}$
Enc'$r \leftarrow \{0,1\}^n$; output $\langle c_1, c_2 \rangle = \langle \mathsf{Enc}_{pk}(r),\; H(r) \oplus m \rangle$ for $m \in \{0,1\}^\ell$
Dec'$r := \mathsf{Dec}_{sk}(c_1)$; output $H(r) \oplus c_2$

Proof

Let $\mathcal{A}$ be a PPT adversary in $\mathsf{PubK}^{\mathsf{eav}}$ (which equals CPA for public-key schemes) making $q$ queries to $H$. Let $r^*$ be the random string in the challenge and $\mathsf{Query}$ the event that $\mathcal{A}$ queries $H(r^*)$.

Without $\mathsf{Query}$, $\mathcal{A}$ only guesses. If $\mathcal{A}$ never asks for $H(r^*)$, that value is uniform and independent of its view, so $c_2 = H(r^*) \oplus m_b$ is a one-time pad and $\Pr[b' = b \mid \neg\mathsf{Query}] = \frac12$. Hence

$$\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi'} = 1] \le \tfrac12 + \Pr[\mathsf{Query}].$$

$\mathsf{Query}$ inverts $\Pi$. Build $\mathcal{I}$ for the one-way experiment, which gets $(pk, c)$ with $c = \mathsf{Enc}_{pk}(r^*)$ for uniform $r^*$:

1.Run $\mathcal{A}(pk)$ and answer its $H$-queries with fresh random values, kept in a table.
2.When $\mathcal{A}$ outputs $m_0, m_1$, give it $\langle c, s \rangle$ for a uniform $s \in \{0,1\}^\ell$.
3.When $\mathcal{A}$ stops, output a uniformly chosen one of its $q$ $H$-queries.

Until $\mathcal{A}$ queries $r^*$, this is a perfect simulation (implicitly $H(r^*) := s \oplus m_b$). So $\mathsf{Query}$ has the same probability here as in the real experiment, and

$$\Pr[\mathcal{I} \text{ outputs } r^*] \ge \frac{\Pr[\mathsf{Query}]}{q}.$$

By one-wayness the left side is negligible, so $\Pr[\mathsf{Query}] \le q \cdot \mathsf{negl}(n)$ is negligible too, and $\Pi'$ is CPA-secure. $\blacksquare$

(b) Deterministic one-way encryption exists

Yes. One-wayness only asks that a uniform message cannot be recovered completely. Deterministic encryption breaks CPA security (Question 84), but not this weaker goal.

Construction: textbook RSA. $\mathsf{Enc}_{(N,e)}(m) = m^e \bmod N$ is deterministic. Its one-wayness for uniform messages in $\mathbb{Z}_N^*$ is exactly the RSA assumption: an adversary recovering $m$ from $m^e$ solves the RSA problem for $y = m^e$, which is uniform in $\mathbb{Z}_N^*$.

To match the message space $\{0,1\}^n$, choose $N$ with $2^n \lt N \lt 2^{n+1}$ and treat $m \in \{0,1\}^n$ as a number below $N$. An RSA inverter gets a uniform $y$; if it is not of the form $m^e$ with $m \lt 2^n$, we cannot use the one-way adversary directly. Instead, re-randomize: $y \cdot s^e$ for random $s$ until the decryption would be a valid message, which happens after an expected constant number of tries since at least half of $\mathbb{Z}_N$ is below $2^n$. Then divide the answer by $s$.

Plugging textbook RSA into (a) gives $\langle r^e \bmod N,\ H(r) \oplus m \rangle$, the CPA-secure RSA scheme in the random oracle model.

Result. (a) $\langle \mathsf{Enc}_{pk}(r), H(r) \oplus m \rangle$ is CPA-secure in the random oracle model: learning anything about $m$ requires querying $H(r)$, i.e. inverting $\Pi$. (b) Yes: textbook RSA is deterministic and one-way under the RSA assumption. $\blacksquare$
