Question

Call a public-key scheme one-way if every PPT adversary that gets $pk$ and an encryption $c$ of a uniform $m \in \{0,1\}^n$ outputs $m$ with only negligible probability.

  1. In the random oracle model, construct a CPA-secure scheme from any one-way scheme.
  2. Can a scheme with deterministic encryption be one-way? Give a proof, or a construction based on an assumption from the lecture.

Source: Katz & Lindell, 1st ed., Exercise 13.5 (restated).

(a) From one-way to CPA-secure

Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be one-way and $H : \{0,1\}^n \to \{0,1\}^{\ell}$ a random oracle. Encrypt a random $r$ with $\Pi$ and use $H(r)$ as a one-time pad:

Gen'same as $\mathsf{Gen}$
Enc'$r \leftarrow \{0,1\}^n$; output $\langle \mathsf{Enc}_{pk}(r),\; H(r) \oplus m \rangle$
Dec'$r := \mathsf{Dec}_{sk}(c_1)$; output $H(r) \oplus c_2$

Proof sketch. For public-key schemes, eavesdropping security is CPA security. Let $r^*$ be the challenge's random value and $\mathsf{Query}$ the event that $\mathcal{A}$ asks $H(r^*)$.

  • Without $\mathsf{Query}$, $H(r^*)$ is uniform and independent of $\mathcal{A}$'s view, so $H(r^*) \oplus m_b$ is a one-time pad: $\Pr[\text{win}] \le \frac12 + \Pr[\mathsf{Query}]$.
  • $\Pr[\mathsf{Query}]$ is negligible: an inverter given $(pk, c = \mathsf{Enc}_{pk}(r^*))$ runs $\mathcal{A}$, answers $H$-queries randomly, gives the challenge $\langle c, s \rangle$ for a uniform $s$, and outputs one of $\mathcal{A}$'s $q$ queries at random. It finds $r^*$ with probability $\ge \Pr[\mathsf{Query}]/q$, which is negligible by one-wayness.

So $\Pi'$ is CPA-secure. $\blacksquare$

(b) Deterministic one-way encryption exists

Yes. Textbook RSA, $\mathsf{Enc}_{(N,e)}(m) = [m^e \bmod N]$, is deterministic, and recovering a uniform $m$ from $m^e$ is exactly the RSA problem. So it is one-way under the RSA assumption. (Deterministic encryption only rules out CPA security, see Question 84.) $\blacksquare$

Plugging textbook RSA into (a) gives the CPA-secure RSA scheme $\langle r^e \bmod N,\ H(r) \oplus m \rangle$ from the lecture.
