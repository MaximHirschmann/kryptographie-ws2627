Question

Prove that Definition 2.4 implies Definition 2.1.

Definition 2.1 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every $m \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$ for which $\Pr[C = c] \gt 0$ it holds that $\Pr[M = m \mid C = c] = \Pr[M = m]$.

Definition 2.4 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every adversary $\mathcal{A}$ it holds that $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] = \frac12$.

Hints: prove the contrapositive. Start with the negation of Def. 2.1, i.e., make a statement about some ciphertext $\tilde c$. Analyze the probability of $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1$ separated into the conditions $M = m_0$ and $M = m_1$. Analyze and re-write the probabilities in terms of events that involve $\tilde c$. Your conclusion needs to show that $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] \ne \frac12$.

This follows the script's proof of Theorem 4 (case Def. 6 $\Rightarrow$ Def. 5), but starts from the negation of Definition 2.1 instead of the script's Definition 5. Notation: $p_m(c) := \Pr[\mathsf{Enc}_K(m) = c] = \Pr[C = c \mid M = m]$. This value does not depend on the distribution of $M$ (see Question 14).

Proof (contrapositive)

Assume that Definition 2.1 does not hold. We construct an adversary $\mathcal{A}$ with $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] \gt \frac12$.

Step 1: Negation of Definition 2.1

There are a distribution over $\mathcal{M}$, a message $m$ and a ciphertext $\tilde c$ with $\Pr[C = \tilde c] \gt 0$ and

$$\Pr[M = m \mid C = \tilde c] \ne \Pr[M = m].$$

This forces $\Pr[M = m] \gt 0$, because otherwise both sides would be $0$. Using $\Pr[M = m \wedge C = \tilde c] = \Pr[M = m] \cdot p_m(\tilde c)$ and dividing by $\Pr[M = m]$:

$$p_m(\tilde c) \ne \Pr[C = \tilde c] = \sum_{m' \in \mathcal{M}} \Pr[M = m'] \cdot p_{m'}(\tilde c).$$

The right-hand side is a weighted average of the values $p_{m'}(\tilde c)$. If all $p_{m'}(\tilde c)$ were equal to $p_m(\tilde c)$, the average would be $p_m(\tilde c)$ as well. So there are two messages whose values differ. Name them $m_0, m_1$ so that

$$p_0 := \Pr[C = \tilde c \mid M = m_0] \ \gt\ p_1 := \Pr[C = \tilde c \mid M = m_1]. \tag{1}$$

Step 2: The adversary

askoutput $m_0, m_1$
guesson ciphertext $c$: if $c = \tilde c$ output $b' = 0$; otherwise output a uniformly random bit $b'$

Step 3: Success probability

In the game $b$ is uniform, so $M = m_b$ is uniform over $\{m_0, m_1\}$, and

$$\Pr[\mathsf{win}] = \tfrac12 \Pr[\mathsf{win} \mid M = m_0] + \tfrac12 \Pr[\mathsf{win} \mid M = m_1].$$

Case $M = m_0$. If $C = \tilde c$, $\mathcal{A}$ answers $0$ and is right. Otherwise it guesses and is right with probability $\frac12$:

$$\Pr[\mathsf{win} \mid M = m_0] = p_0 \cdot 1 + (1 - p_0) \cdot \tfrac12 = \tfrac12 + \tfrac12 p_0.$$

Case $M = m_1$. If $C = \tilde c$, $\mathcal{A}$ answers $0$ and is wrong. Otherwise it guesses:

$$\Pr[\mathsf{win} \mid M = m_1] = p_1 \cdot 0 + (1 - p_1) \cdot \tfrac12 = \tfrac12 - \tfrac12 p_1.$$

Together:

$$\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] = \tfrac12\Big(\tfrac12 + \tfrac12 p_0\Big) + \tfrac12\Big(\tfrac12 - \tfrac12 p_1\Big) = \tfrac12 + \tfrac14\,(p_0 - p_1) \overset{(1)}{\gt} \tfrac12.$$

So Definition 2.4 does not hold. By contraposition, Definition 2.4 implies Definition 2.1. $\blacksquare$

Choosing the order in (1) makes the advantage positive. With the opposite order, the same adversary would win with probability below $\frac12$, which also violates Definition 2.4, as in the script.
