Question

Use DES as a fixed-length hash function $h : \{0,1\}^{112} \to \{0,1\}^{64}$ by $h(x_1 \| x_2) = \mathsf{DES}_{x_1}(\mathsf{DES}_{x_2}(0^{64}))$ with $|x_1| = |x_2| = 56$.

  1. Write down an explicit collision.
  2. Show how to find a pre-image of a given $y$ in roughly $2^{56}$ time.
  3. Give a smarter pre-image attack that runs in roughly $2^{32}$ time and succeeds with high probability.

Source: Katz & Lindell, 1st ed., Exercise 5.15 (restated).

(a) Explicit collision via weak keys

For a weak key $w$ (Question 71), $\mathsf{DES}_w(\mathsf{DES}_w(z)) = z$. Hence

$$h(w \| w) = \mathsf{DES}_w(\mathsf{DES}_w(0^{64})) = 0^{64}$$

for each of the four weak keys. Any two of them collide, e.g.

$$h(0^{56} \| 0^{56}) = h(1^{56} \| 1^{56}) = 0^{64}.$$

(b) Pre-image in about $2^{56}$: meet in the middle

We need $\mathsf{DES}_{x_2}(0^{64}) = \mathsf{DES}^{-1}_{x_1}(y)$. Both sides can be computed independently:

1.For every $x_2 \in \{0,1\}^{56}$: store $v = \mathsf{DES}_{x_2}(0^{64})$ in a table indexed by $v$.
2.For every $x_1 \in \{0,1\}^{56}$: compute $u = \mathsf{DES}^{-1}_{x_1}(y)$; if $u$ is in the table under some $x_2$, output $x_1 \| x_2$.

There are $2^{112}$ pairs, and a pair matches with probability about $2^{-64}$, so about $2^{48}$ pre-images exist and the attack finds one. Time about $2 \cdot 2^{56}$, memory $2^{56}$.

A naive search over all $2^{112}$ inputs would be far slower. The meet-in-the-middle split is what makes $2^{56}$ possible.

(c) Pre-image in about $2^{32}$: birthday-style matching

We do not need to try all keys on each side, only enough to make a match likely.

1.Choose $2^{32}$ random $x_2$, compute $v = \mathsf{DES}_{x_2}(0^{64})$, and store them in a table.
2.Choose $2^{32}$ random $x_1$, compute $u = \mathsf{DES}^{-1}_{x_1}(y)$, and look each up in the table.

Model the $u$'s and $v$'s as independent uniform 64-bit strings. There are $2^{32} \cdot 2^{32} = 2^{64}$ pairs $(u, v)$, each equal with probability $2^{-64}$, so the expected number of matches is $1$, and the probability of at least one match is about $1 - e^{-1} \approx 0.63$. With $2^{33}$ values on each side the expected number is $4$ and the success probability is about $1 - e^{-4} \approx 0.98$.

Cost. About $2^{33}$–$2^{34}$ DES evaluations and $2^{32}$–$2^{33}$ memory: "roughly $2^{32}$".

Result. (a) Weak keys give $h(w\|w) = 0^{64}$, so e.g. $0^{112}$ and $1^{112}$ collide. (b) A meet-in-the-middle attack finds pre-images in about $2^{56}$. (c) Matching about $2^{32}$ random values on each side succeeds with constant probability, because the 64-bit middle value is short. A 64-bit output is too short for a hash function. $\blacksquare$

Generic collision attacks are even cheaper. By the birthday bound, about $2^{32}$ random inputs to $h$ already contain a collision, without using weak keys. Pre-image resistance with $n$-bit outputs can be at most about $2^{n}$; here the structure lowers it to $2^{n/2}$.
