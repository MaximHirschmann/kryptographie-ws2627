Question

Use DES as a fixed-length hash function $h : \{0,1\}^{112} \to \{0,1\}^{64}$ by $h(x_1 \| x_2) = \mathsf{DES}_{x_1}(\mathsf{DES}_{x_2}(0^{64}))$ with $|x_1| = |x_2| = 56$.

  1. Write down an explicit collision.
  2. Show how to find a pre-image of a given $y$ in roughly $2^{56}$ time.
  3. Give a smarter pre-image attack that runs in roughly $2^{32}$ time and succeeds with high probability.

Source: Katz & Lindell, 1st ed., Exercise 5.15 (restated).

(a) Explicit collision via weak keys

For a weak key $w$ (Question 71), encryption equals decryption, so $h(w \| w) = \mathsf{DES}_w(\mathsf{DES}_w(0^{64})) = 0^{64}$. Hence

$$h(0^{56} \| 0^{56}) = h(1^{56} \| 1^{56}) = 0^{64}.$$

(b) Pre-image in about $2^{56}$: meet in the middle

We need $\mathsf{DES}_{x_2}(0^{64}) = \mathsf{DES}^{-1}_{x_1}(y)$, as in the attack on double encryption with the "plaintext/ciphertext pair" $(0^{64}, y)$:

1.For every $x_2 \in \{0,1\}^{56}$: store $\mathsf{DES}_{x_2}(0^{64})$ in a table.
2.For every $x_1 \in \{0,1\}^{56}$: compute $\mathsf{DES}^{-1}_{x_1}(y)$ and look it up; on a match output $x_1 \| x_2$.

Time about $2 \cdot 2^{56}$. Any match is a pre-image, and about $2^{112-64} = 2^{48}$ pre-images exist.

(c) Pre-image in about $2^{32}$

Here any pre-image will do, so we do not need all keys. Run the same attack with only $2^{32}$ random values of $x_2$ and $2^{32}$ random values of $x_1$. Treating the 64-bit middle values as random, the $2^{32} \cdot 2^{32} = 2^{64}$ pairs give about one expected match, so the attack succeeds with constant probability ($\approx 1 - e^{-1}$); doubling both lists raises it to about $0.98$. $\blacksquare$

The book's solution uses $2^{28}$ values per side, which gives only about $2^{56-64} = 2^{-8}$ expected matches; $2^{32}$ per side are needed.
