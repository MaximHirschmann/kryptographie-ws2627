Question

Assume that we require only that an encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ satisfies the following: for all $m \in \mathcal{M}$, the probability that $\mathsf{Dec}_k(\mathsf{Enc}_k(m)) = m$ is at least $2^{-t}$. This probability is taken over the choice of $k$ as well as any randomness that may be used during encryption and decryption. Show that perfect secrecy as in Definition 2.1 is achievable with $|\mathcal{K}| \lt |\mathcal{M}|$ when $t \ge 1$. Can you prove a lower bound?

Hints: define an encryption scheme that fulfills the requirements; formulate a theorem that captures precisely what you are going to prove; prove your theorem while clearly reasoning from one step to the next.

Definition 2.1 is Definition 3 in the script: $\Pr[M = m \mid C = c] = \Pr[M = m]$ for every distribution over $\mathcal{M}$. By the script's Theorems 2 and 3, it is enough to show Definition 5: $\Pr[C = c \mid M = m_0] = \Pr[C = c \mid M = m_1]$.

Idea

Encrypt only the first $\ell - t$ bits of the message with a one-time pad and throw the last $t$ bits away. The receiver guesses the missing $t$ bits and is right with probability exactly $2^{-t}$. The key only has to cover $\ell - t$ bits, so it is shorter than the message.

Part 1: A scheme with $|\mathcal{K}| \lt |\mathcal{M}|$

Let $\mathcal{M} = \{0,1\}^\ell$ with $\ell \gt t$. For $m \in \mathcal{M}$, write $m = m' \,\|\, m''$ with $m' \in \{0,1\}^{\ell - t}$ and $m'' \in \{0,1\}^t$. Let $\mathcal{K} = \mathcal{C} = \{0,1\}^{\ell - t}$.

Gen$k \leftarrow \{0,1\}^{\ell - t}$ uniformly; output $k$
Enc input $k \in \mathcal{K}$, $m = m' \| m'' \in \mathcal{M}$ output $c := m' \oplus k$
Dec input $k \in \mathcal{K}$, $c \in \mathcal{C}$ $r \leftarrow \{0,1\}^t$ uniformly output $(c \oplus k) \,\|\, r$
Theorem. Let $t \ge 1$ and $\ell \gt t$. The scheme above satisfies
  1. $\Pr[\mathsf{Dec}_K(\mathsf{Enc}_K(m)) = m] = 2^{-t}$ for all $m \in \mathcal{M}$,
  2. perfect secrecy (Definition 2.1),
  3. $|\mathcal{K}| = 2^{\ell - t} \lt 2^\ell = |\mathcal{M}|$.

Proof

1. Decryption probability. $\mathsf{Dec}_k(\mathsf{Enc}_k(m)) = (m' \oplus k \oplus k) \,\|\, r = m' \,\|\, r$. This equals $m$ if and only if $r = m''$. The string $r$ is uniform over $\{0,1\}^t$, so

$$\Pr[\mathsf{Dec}_K(\mathsf{Enc}_K(m)) = m] = \Pr[r = m''] = 2^{-t}.$$

2. Perfect secrecy. Fix any distribution over $\mathcal{M}$, a message $m = m' \| m''$ and a ciphertext $c$. $K$ is independent of $M$ and uniform, so, as for the one-time pad (script Theorem 5):

$$\Pr[C = c \mid M = m] = \Pr[m' \oplus K = c] = \Pr[K = m' \oplus c] = 2^{-(\ell - t)}.$$

This value does not depend on $m$. So $\Pr[C = c \mid M = m_0] = \Pr[C = c \mid M = m_1]$ for all $m_0, m_1, c$. That is the script's Definition 5, which is equivalent to Definition 2.1.

3. Key size. $|\mathcal{K}| = 2^{\ell-t} \lt 2^\ell = |\mathcal{M}|$, because $t \ge 1$. $\blacksquare$

If $t \ge \ell$, a single key suffices: $\mathsf{Enc}$ outputs a constant and $\mathsf{Dec}$ outputs a uniformly random message. That succeeds with probability $2^{-\ell} \ge 2^{-t}$ and is trivially perfectly secret.

Part 2: Lower bound

Theorem. Let $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be perfectly secret over a finite $\mathcal{M}$, and suppose $\Pr[\mathsf{Dec}_K(\mathsf{Enc}_K(m)) = m] \ge 2^{-t}$ for all $m$. Then $$|\mathcal{K}| \ \ge\ 2^{-t} \cdot |\mathcal{M}|.$$ The scheme from Part 1 meets this bound with equality, so the bound is tight.

Proof

Let $M$ be uniform over $\mathcal{M}$. Each single message decrypts correctly with probability at least $2^{-t}$, so the average does too:

$$2^{-t} \le \Pr[\mathsf{Dec}_K(C) = M] = \sum_{k \in \mathcal{K}} \sum_{c \in \mathcal{C}} \Pr[K = k \wedge C = c \wedge \mathsf{Dec}_k(c) = M].$$

Split each summand by the value of $M$. The random coins of $\mathsf{Dec}$ are independent of $K$, $M$ and $C$, so

$$ \begin{aligned} \Pr[K = k \wedge C = c \wedge \mathsf{Dec}_k(c) = M] &= \sum_{m \in \mathcal{M}} \Pr[K = k \wedge C = c \wedge M = m] \cdot \Pr[\mathsf{Dec}_k(c) = m] \\ &\overset{(a)}{\le} \sum_{m \in \mathcal{M}} \Pr[C = c \wedge M = m] \cdot \Pr[\mathsf{Dec}_k(c) = m] \\ &\overset{(b)}{=} \sum_{m \in \mathcal{M}} \Pr[C = c] \cdot \frac{1}{|\mathcal{M}|} \cdot \Pr[\mathsf{Dec}_k(c) = m] \\ &\overset{(c)}{=} \frac{\Pr[C = c]}{|\mathcal{M}|}. \end{aligned} $$
  1. Dropping the event $K = k$ can only increase the probability.
  2. Perfect secrecy: $M$ and $C$ are independent, and $\Pr[M = m] = \frac{1}{|\mathcal{M}|}$.
  3. $\sum_m \Pr[\mathsf{Dec}_k(c) = m] = 1$, because $\mathsf{Dec}_k(c)$ outputs exactly one message.

Putting this back in:

$$2^{-t} \le \sum_{k \in \mathcal{K}} \sum_{c \in \mathcal{C}} \frac{\Pr[C = c]}{|\mathcal{M}|} = \sum_{k \in \mathcal{K}} \frac{1}{|\mathcal{M}|} = \frac{|\mathcal{K}|}{|\mathcal{M}|}.$$

Multiplying by $|\mathcal{M}|$ gives $|\mathcal{K}| \ge 2^{-t} |\mathcal{M}|$. $\blacksquare$

Summary. If decryption only has to succeed with probability $2^{-t}$, the key space can shrink by a factor of exactly $2^t$, but no more: $|\mathcal{K}| \ge 2^{-t}|\mathcal{M}|$. For $t = 0$ this is the usual bound $|\mathcal{K}| \ge |\mathcal{M}|$ (script Theorem 6).
