Question

Let $F$ be a pseudorandom permutation, and define a fixed-length encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ as follows: On input $m \in \{0,1\}^{n/2}$ and key $k \in \{0,1\}^n$, algorithm $\mathsf{Enc}$ chooses a random string $r \leftarrow \{0,1\}^{n/2}$ of length $n/2$ and computes $c := F_k(r \| m)$.

  1. Give formulas for encryption and decryption.
  2. Prove that this scheme is CPA-secure for messages of length $n/2$.

1. Formulas

Gen$k \leftarrow \{0,1\}^n$ uniformly
Encinput $k$, $m \in \{0,1\}^{n/2}$:   $r \leftarrow \{0,1\}^{n/2}$;   output $c := F_k(r \,\|\, m)$
Decinput $k$, $c \in \{0,1\}^n$:   compute $x := F_k^{-1}(c)$;   output the last $n/2$ bits of $x$

Correctness: $F_k^{-1}(F_k(r \| m)) = r \| m$, and its last $n/2$ bits are $m$. Decryption needs $F_k^{-1}$, which exists and is efficient because $F$ is a keyed permutation; strong PRP security is not needed here.

2. CPA security

By Question 18, $F$ is also a pseudorandom function. Let $\mathcal{A}$ be a PPT adversary that makes at most $q(n)$ encryption queries.

Step 1: The idealised scheme $\tilde\Pi$

$\tilde\Pi$ is the same scheme with $F_k$ replaced by a truly random function $f : \{0,1\}^n \to \{0,1\}^n$. In the CPA game for $\tilde\Pi$, the challenge is $c^* = f(r^* \| m_b)$ with a fresh $r^*$. Let $\mathsf{Repeat}$ be the event that $r^*$ equals one of the values $r_1, \dots, r_q$ used for the oracle answers.

  • If $\mathsf{Repeat}$ does not occur, the input $r^* \| m_b$ was never given to $f$ before. So $c^*$ is uniform and independent of everything $\mathcal{A}$ has seen, including $b$. $\mathcal{A}$ wins with probability exactly $\frac12$.
  • $\Pr[\mathsf{Repeat}] \le \frac{q(n)}{2^{n/2}}$ (union bound over the $q$ values).
$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n) = 1] \le \tfrac12 + \frac{q(n)}{2^{n/2}}.$$

Step 2: Reduction to the PRF

Build a distinguisher $D^{\mathcal{O}}$ with oracle $\mathcal{O}$, which is either $F_k$ or $f$:

1.Run $\mathcal{A}(1^n)$. Answer each encryption query $m$ with $\mathcal{O}(r \| m)$ for a fresh $r \leftarrow \{0,1\}^{n/2}$.
2.When $\mathcal{A}$ outputs $m_0, m_1$: choose $b \leftarrow \{0,1\}$, $r^* \leftarrow \{0,1\}^{n/2}$, and give $c^* := \mathcal{O}(r^* \| m_b)$.
3.Keep answering queries as in step 1. When $\mathcal{A}$ outputs $b'$, output $1$ iff $b' = b$.

$D$ simulates the CPA game perfectly: for $\Pi$ if $\mathcal{O} = F_k$, and for $\tilde\Pi$ if $\mathcal{O} = f$. Therefore

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi} = 1] = \Pr[D^{F_k} = 1] \le \Pr[D^{f} = 1] + \mathsf{negl}(n) = \Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi} = 1] + \mathsf{negl}(n).$$

Combining with Step 1:

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] \le \tfrac12 + \frac{q(n)}{2^{n/2}} + \mathsf{negl}(n) = \tfrac12 + \mathsf{negl}'(n). \qquad \blacksquare$$

The random half $r$ is essential. Without it, encryption would be deterministic, and no deterministic scheme can be CPA-secure (repeated messages give repeated ciphertexts). $r$ needs $n/2$ bits so that a repetition among polynomially many encryptions is negligible.
