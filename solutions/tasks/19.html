Question

Let $F$ be a pseudorandom permutation, and define a fixed-length encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ as follows: On input $m \in \{0,1\}^{n/2}$ and key $k \in \{0,1\}^n$, algorithm $\mathsf{Enc}$ chooses a random string $r \leftarrow \{0,1\}^{n/2}$ of length $n/2$ and computes $c := F_k(r \| m)$.

  1. Give formulas for encryption and decryption.
  2. Prove that this scheme is CPA-secure for messages of length $n/2$.

1. Formulas

Gen$k \leftarrow \{0,1\}^n$ uniformly
Enc$r \leftarrow \{0,1\}^{n/2}$; output $c := F_k(r \,\|\, m)$
Decoutput the last $n/2$ bits of $F_k^{-1}(c)$

2. CPA security

Let $\mathcal{A}$ make at most $q(n)$ encryption queries, and let $\tilde\Pi$ be the same scheme with a truly random permutation $f$ instead of $F_k$.

The ideal scheme. Let $\mathsf{Repeat}$ be the event that the challenge's random $r^*$ was also used to answer some oracle query; by the union bound $\Pr[\mathsf{Repeat}] \le q(n)/2^{n/2}$. Otherwise $r^* \| m_b$ is a new input to $f$, so the challenge $f(r^* \| m_b)$ is a uniform value (among those not yet used) independent of $b$, and $\mathcal{A}$ wins with probability $\frac12$. Hence

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n) = 1] \le \tfrac12 + \frac{q(n)}{2^{n/2}}.$$

Reduction. A distinguisher $D^{\mathcal{O}}$ runs $\mathcal{A}$ and answers every encryption (including the challenge) as $\mathcal{O}(r \| m)$ with fresh $r$; it outputs $1$ iff $\mathcal{A}$ guesses $b$. With $\mathcal{O} = F_k$ this is the real game, with $\mathcal{O} = f$ the ideal one. Since $F$ is a PRP,

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] \le \tfrac12 + \frac{q(n)}{2^{n/2}} + \mathsf{negl}(n). \qquad \blacksquare$$
