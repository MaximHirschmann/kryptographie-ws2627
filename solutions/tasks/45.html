Question

Consider the following key-exchange protocol:

  1. Alice chooses $k, r \leftarrow \{0,1\}^n$ at random, and sends $s := k \oplus r$ to Bob.
  2. Bob chooses $t \leftarrow \{0,1\}^n$ at random and sends $u := s \oplus t$ to Alice.
  3. Alice computes $w := u \oplus r$ and sends $w$ to Bob.
  4. Alice outputs $k$ and Bob computes $w \oplus t$.

Show that Alice and Bob output the same key. Analyze the security of the scheme (i.e., either prove its security or show a concrete attack).

Correctness

$$w \oplus t = (u \oplus r) \oplus t = (k \oplus r \oplus t) \oplus r \oplus t = k.$$

So Bob outputs $k$, the same key as Alice.

Security: completely insecure

An eavesdropper sees the whole transcript $(s, u, w)$. XORing the three messages gives

$$s \oplus u \oplus w = (k \oplus r) \oplus (k \oplus r \oplus t) \oplus (k \oplus t) = k.$$

Every mask $r$ and $t$ appears exactly twice and cancels, and $k$ appears three times, so it remains.

Attack in $\mathsf{KE}^{\mathsf{eav}}$

As in the lecture's experiment (Question 46), $\mathcal{A}$ gets the transcript $(s, u, w)$ and $k_b$, where $k_1 = k$ is the real key and $k_0$ is uniform. $\mathcal{A}$ outputs $b' = 1$ iff $k_b = s \oplus u \oplus w$.

$$\Pr[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] = \tfrac12 \cdot 1 + \tfrac12 \cdot (1 - 2^{-n}) = 1 - 2^{-(n+1)}.$$

This is far from $\frac12$, so the protocol is not secure. $\blacksquare$

The idea is the "double lock" (Shamir's three-pass protocol): Alice locks the box, Bob adds his lock, Alice removes hers, Bob removes his. This needs locks that commute but cannot be removed by combining the transcripts, such as exponentiation $k^{a}$, $k^{ab}$, $k^{b}$ modulo $p$. XOR is commutative too, but it is linear, so the transcripts can simply be XORed together.
