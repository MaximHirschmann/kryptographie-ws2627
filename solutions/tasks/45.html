Question

Consider the following key-exchange protocol:

  1. Alice chooses $k, r \leftarrow \{0,1\}^n$ at random, and sends $s := k \oplus r$ to Bob.
  2. Bob chooses $t \leftarrow \{0,1\}^n$ at random and sends $u := s \oplus t$ to Alice.
  3. Alice computes $w := u \oplus r$ and sends $w$ to Bob.
  4. Alice outputs $k$ and Bob computes $w \oplus t$.

Show that Alice and Bob output the same key. Analyze the security of the scheme (i.e., either prove its security or show a concrete attack).

Correctness

$$w \oplus t = (u \oplus r) \oplus t = (k \oplus r \oplus t) \oplus r \oplus t = k.$$

So Bob outputs $k$, the same key as Alice.

Security: completely insecure

An eavesdropper sees the transcript $(s, u, w)$ and computes

$$s \oplus u \oplus w = (k \oplus r) \oplus (k \oplus r \oplus t) \oplus (k \oplus t) = k.$$

So it learns the key itself. In $\mathsf{KE}^{\mathsf{eav}}$ it outputs $1$ iff the given key equals $s \oplus u \oplus w$, and wins with probability $1 - 2^{-(n+1)}$. $\blacksquare$
