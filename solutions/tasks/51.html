Question

Show that for any CPA-secure public-key encryption scheme, the size of the ciphertext after encrypting a single bit is superlogarithmic in the security parameter. That is, for $(pk, sk) \leftarrow \mathsf{Gen}(1^n)$ it must hold that $|\mathsf{Enc}_{pk}(b)| = \omega(\log n)$ for any $b \in \{0,1\}$.

Hint: If not then the range of possible ciphertexts is only polynomial in size.

Proof (contrapositive)

Suppose single-bit ciphertexts have length at most $c \log n$. Then there are at most $N := 2n^c$ possible ciphertexts, polynomially many.

Adversary: output $m_0 = 0$, $m_1 = 1$, receive $c^*$, compute a fresh $c_0 \leftarrow \mathsf{Enc}_{pk}(0)$ with the public key, and output $0$ iff $c^* = c_0$.

  • $b = 0$: two independent encryptions of $0$ coincide with probability $\sum_c p_c^2 \ge \frac1N$ (Cauchy–Schwarz, with $p_c := \Pr[\mathsf{Enc}_{pk}(0) = c]$).
  • $b = 1$: by correctness an encryption of $1$ never equals one of $0$, so the adversary is always right.
$$\Pr[\mathsf{PubK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] \ge \tfrac12 \cdot \tfrac1N + \tfrac12 = \tfrac12 + \tfrac{1}{4n^c},$$

which is a non-negligible advantage. So ciphertexts must have length $\omega(\log n)$. $\blacksquare$
