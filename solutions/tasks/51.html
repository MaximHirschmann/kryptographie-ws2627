Question

Show that for any CPA-secure public-key encryption scheme, the size of the ciphertext after encrypting a single bit is superlogarithmic in the security parameter. That is, for $(pk, sk) \leftarrow \mathsf{Gen}(1^n)$ it must hold that $|\mathsf{Enc}_{pk}(b)| = \omega(\log n)$ for any $b \in \{0,1\}$.

Hint: If not then the range of possible ciphertexts is only polynomial in size.

Proof (contrapositive)

Suppose ciphertexts of single bits have length at most $c \log n$ for some constant $c$ (for infinitely many $n$). Then there are at most

$$N := 2^{c \log n + 1} = 2n^c$$

possible ciphertexts, which is polynomially many. Since $pk$ is public, the attacker can produce encryptions of $0$ itself and check whether the challenge "looks like" one of them.

Adversary

$\mathcal{A}(pk)$ output $m_0 = 0$, $m_1 = 1$; receive the challenge $c^*$ compute one fresh encryption $c_0 \leftarrow \mathsf{Enc}_{pk}(0)$ if $c^* = c_0$ output $0$, else output $1$

Analysis

Let $p_c := \Pr[\mathsf{Enc}_{pk}(0) = c]$ for each of the at most $N$ possible ciphertexts $c$.

  • $b = 0$: $c^*$ and $c_0$ are independent samples from the same distribution. By the Cauchy–Schwarz inequality, $$\Pr[c^* = c_0] = \sum_c p_c^2 \ \ge\ \frac{\big(\sum_c p_c\big)^2}{N} = \frac{1}{N}.$$
  • $b = 1$: by correctness, an encryption of $1$ is never equal to an encryption of $0$, because it would decrypt to two different bits. So $c^* \ne c_0$ and $\mathcal{A}$ outputs $1$, which is correct.
$$\Pr[\mathsf{PubK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] \ \ge\ \tfrac12 \cdot \frac1N + \tfrac12 \cdot 1 = \tfrac12 + \frac{1}{4n^c}.$$

This advantage is an inverse polynomial, hence not negligible, so $\Pi$ is not CPA-secure. By contraposition, a CPA-secure scheme has $|\mathsf{Enc}_{pk}(b)| = \omega(\log n)$. $\blacksquare$

The attack needs no oracle at all; $pk$ is enough. This is the public-key analogue of Question 30: with only polynomially many possible values, the attacker can "hit" the right one with noticeable probability. If decryption errors are allowed, the case $b = 1$ loses only a negligible amount.
