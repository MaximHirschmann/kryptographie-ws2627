Question

Prove or refute: Every encryption scheme for which the size of the key space equals the size of the message space, and for which the key is chosen uniformly from the key space, is perfectly secret.

Answer. False. $|\mathcal{K}| = |\mathcal{M}|$ and a uniform key are necessary for this kind of scheme, but not enough. Shannon's theorem (script Theorem 7) also requires that, for every pair $(m, c)$, exactly one key maps $m$ to $c$. The encryption has to actually use the key.

Counterexample 1: a scheme that ignores the key

Let $\mathcal{M} = \mathcal{K} = \mathcal{C} = \{0,1\}^\ell$ and define

Gen$k \leftarrow \{0,1\}^\ell$ uniformly; output $k$
Encinput $k$, $m$; output $c := m$
Decinput $k$, $c$; output $m := c$

The scheme is correct, $|\mathcal{K}| = |\mathcal{M}| = 2^\ell$, and the key is uniform. But for any $m_0 \ne m_1$ and $c = m_0$:

$$\Pr[C = c \mid M = m_0] = 1 \ne 0 = \Pr[C = c \mid M = m_1].$$

This violates the script's Definition 5, so the scheme is not perfectly secret. $\blacksquare$

Counterexample 2: a scheme that uses the key, but not fully

The first example might look like cheating, so here is one where the key is used. Let $\mathcal{M} = \mathcal{K} = \mathcal{C} = \{0,1\}^2$, with $\mathsf{Gen}$ uniform, and

$$\mathsf{Enc}_{k_1 k_2}(m_1 m_2) := (m_1 \oplus k_1) \, (m_2 \oplus k_1).$$

The second key bit is never used. Decryption works: $\mathsf{Dec}_{k}(c_1 c_2) = (c_1 \oplus k_1)(c_2 \oplus k_1)$. However, $c_1 \oplus c_2 = m_1 \oplus m_2$ is always visible. For example, the ciphertext $00$ can only come from $00$ or $11$:

$$\Pr[C = 00 \mid M = 01] = 0 \ne \tfrac12 = \Pr[C = 00 \mid M = 00].$$

Here, two keys ($k_2 = 0$ and $k_2 = 1$) map $m$ to the same $c$, so the uniqueness condition of Shannon's theorem fails.

By Shannon's theorem, for $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}|$: perfect secrecy $\iff$ uniform key and a unique key for every $(m, c)$. The question only gives the first condition.
