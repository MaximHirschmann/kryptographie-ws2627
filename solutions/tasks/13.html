Question

Prove or refute: Every encryption scheme for which the size of the key space equals the size of the message space, and for which the key is chosen uniformly from the key space, is perfectly secret.

Answer. False. Shannon's theorem (script Theorem 7) also requires that exactly one key maps each $m$ to each $c$; the encryption has to actually use the key.

Counterexample: a scheme that ignores the key

Let $\mathcal{M} = \mathcal{K} = \mathcal{C} = \{0,1\}^\ell$, $\mathsf{Gen}$ uniform, $\mathsf{Enc}_k(m) := m$ and $\mathsf{Dec}_k(c) := c$. The scheme is correct, $|\mathcal{K}| = |\mathcal{M}|$ and the key is uniform. But for $m_0 \ne m_1$ and $c = m_0$,

$$\Pr[C = c \mid M = m_0] = 1 \ne 0 = \Pr[C = c \mid M = m_1],$$

so it is not perfectly secret (script Definition 5). $\blacksquare$
