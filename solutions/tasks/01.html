Question

Provide a formal definition of the $\mathsf{Gen}$, $\mathsf{Enc}$, and $\mathsf{Dec}$ algorithms for both the mono-alphabetic substitution and Vigenère ciphers. Remark: a permutation is typically denoted $\pi$.

Let $\Sigma = \{0, \dots, 25\}$ ($\texttt{a} = 0, \dots, \texttt{z} = 25$). Messages $m = m_0 \cdots m_{|m|-1} \in \Sigma^*$ are encrypted letter by letter.

Mono-alphabetic substitution cipher

The key is a permutation $\pi$ of $\Sigma$; there are $26! \approx 2^{88}$ of them.

Genchoose a uniform permutation $\pi$ of $\Sigma$; output $k := \pi$
Encinput $\pi$, $m$: for $i = 0, \dots, |m| - 1$: $c_i := \pi(m_i)$; output $c$
Decinput $\pi$, $c$: for $i = 0, \dots, |c| - 1$: $m_i := \pi^{-1}(c_i)$; output $m$

Correctness: $\pi^{-1}(\pi(m_i)) = m_i$.

Vigenère cipher

The key is a word $k = (k_0, \dots, k_{t-1}) \in \Sigma^t$; letter $i$ is shifted by $k_{i \bmod t}$.

Genfor $j = 0, \dots, t - 1$: $k_j \leftarrow \Sigma$ uniformly; output $k = (k_0, \dots, k_{t-1})$
Encinput $k$, $m$: for $i = 0, \dots, |m| - 1$: $c_i := m_i + k_{i \bmod t} \bmod 26$; output $c$
Decinput $k$, $c$: for $i = 0, \dots, |c| - 1$: $m_i := c_i - k_{i \bmod t} \bmod 26$; output $m$

Correctness: $(m_i + k_{i \bmod t}) - k_{i \bmod t} = m_i \bmod 26$.

$\mathsf{Gen}$ could also choose the period $t$ at random from a range; the book notes that several choices are plausible.
