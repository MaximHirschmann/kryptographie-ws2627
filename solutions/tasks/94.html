Question

A variant of Lamport's scheme with $2\ell$ secret values $x_1, \dots, x_{2\ell}$ and public values $y_i = f(x_i)$ for a one-way function $f$. Messages are mapped injectively to subsets $S_m \subseteq \{1, \dots, 2\ell\}$ of size exactly $\ell$, and the signature on $m$ reveals $\{x_i\}_{i \in S_m}$. Prove that this is a one-time signature scheme. What is the longest message length it supports?

Source: Katz & Lindell, 1st ed., Exercise 12.8 (restated).

Scheme

Gen$x_1, \dots, x_{2\ell} \leftarrow \{0,1\}^n$; $pk = (y_1, \dots, y_{2\ell})$, $y_i = f(x_i)$; $sk = (x_1, \dots, x_{2\ell})$
Sign$\sigma = (x_i)_{i \in S_m}$
Vrfycheck $f(\sigma_i) = y_i$ for all $i \in S_m$

Key combinatorial fact

If $m^* \ne m$, then $S_{m^*} \ne S_m$ (the map is injective), and both sets have size $\ell$. Two different sets of the same size cannot contain each other, so

$$S_{m^*} \not\subseteq S_m: \quad \text{there is an } i^* \in S_{m^*} \setminus S_m.$$

To forge on $m^*$, the adversary must output a pre-image of $y_{i^*}$, a value whose pre-image was never revealed.

Security proof

Let $\mathcal{A}$ be a PPT forger in the one-time experiment (one signing query, then a forgery on a new message) with success probability $\varepsilon(n)$. Build an inverter $\mathcal{I}$ for $f$:

$\mathcal{I}(1^n, y)$:
1.Choose $j \leftarrow \{1, \dots, 2\ell\}$ and set $y_j := y$. For $i \ne j$ choose $x_i$ and set $y_i := f(x_i)$.
2.Run $\mathcal{A}(pk)$. When it asks for a signature on $m$: if $j \in S_m$, abort; otherwise answer $(x_i)_{i \in S_m}$.
3.When $\mathcal{A}$ outputs $(m^*, \sigma^*)$: if $j \in S_{m^*}$, output the component $\sigma^*_j$.

Simulation. $y = f(x)$ for uniform $x$ has the same distribution as every other $y_i$, so $\mathcal{A}$'s view does not depend on $j$ (as long as we don't abort).

Success. $\mathcal{I}$ inverts $y$ if $\mathcal{A}$ succeeds and $j \in S_{m^*} \setminus S_m$; then $f(\sigma^*_j) = y_j = y$. If $\mathcal{A}$ succeeds, $S_{m^*} \setminus S_m$ contains at least one index, and $j$ is a uniform index independent of $\mathcal{A}$'s view, so it hits that set with probability at least $\frac{1}{2\ell}$. (Then $j \notin S_m$ automatically, so we never aborted.)

$$\Pr[\mathsf{Invert}_{\mathcal{I},f}(n) = 1] \ge \frac{\varepsilon(n)}{2\ell}.$$

Since $f$ is one-way and $\ell$ is polynomial, $\varepsilon$ is negligible. $\blacksquare$

Maximum message length

The messages must map injectively into the size-$\ell$ subsets of $\{1, \dots, 2\ell\}$, of which there are $\binom{2\ell}{\ell}$. So at most

$$\ell_{\max} = \left\lfloor \log_2 \binom{2\ell}{\ell} \right\rfloor \approx 2\ell - \tfrac12 \log_2(\pi \ell)$$

bits (using $\binom{2\ell}{\ell} \approx 4^\ell/\sqrt{\pi \ell}$). For example, $\ell = 128$ gives $\binom{256}{128} \approx 2^{251.6}$, i.e. 251-bit messages with 256 public values. That is almost twice the 128 bits of plain Lamport with the same key size. An efficient injective map is the combinatorial number system (ranking/unranking of subsets).
