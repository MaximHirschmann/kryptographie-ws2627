Question

Prove formally that the hardness of the CDH problem relative to $\mathcal{G}$ implies the hardness of the discrete logarithm problem relative to $\mathcal{G}$.

The experiments

$\mathcal{G}(1^n)$ outputs a cyclic group $\mathbb{G}$ of order $q$ (with $\|q\| = n$) and a generator $g$.

$\mathsf{DLog}_{\mathcal{A},\mathcal{G}}(n)$$(\mathbb{G}, q, g) \leftarrow \mathcal{G}(1^n)$; $h \leftarrow \mathbb{G}$ uniformly; $x \leftarrow \mathcal{A}(\mathbb{G}, q, g, h)$; output $1$ iff $g^x = h$.
CDH$(\mathbb{G}, q, g) \leftarrow \mathcal{G}(1^n)$; $x_1, x_2 \leftarrow \mathbb{Z}_q$; given $(\mathbb{G}, q, g, g^{x_1}, g^{x_2})$, the adversary must output $g^{x_1 x_2}$.

Hardness means: every PPT adversary succeeds with only negligible probability.

Theorem. If CDH is hard relative to $\mathcal{G}$, then DL is hard relative to $\mathcal{G}$.

Proof (contrapositive)

Let $\mathcal{A}$ be a PPT adversary that solves DL with probability $\varepsilon(n)$. Build $\mathcal{A}'$ for CDH:

$\mathcal{A}'(\mathbb{G}, q, g, h_1, h_2)$ $x := \mathcal{A}(\mathbb{G}, q, g, h_1)$  (try to compute $\log_g h_1$) output $h_2^{\,x}$
  • Same input distribution: $h_1 = g^{x_1}$ with $x_1$ uniform in $\mathbb{Z}_q$ is a uniform group element, exactly as $h$ in $\mathsf{DLog}$. So $\mathcal{A}$ outputs $x$ with $g^x = h_1$ with probability exactly $\varepsilon(n)$.
  • Correct output: if $g^x = h_1$, then $x \equiv x_1 \pmod q$ and $h_2^{\,x} = (g^{x_2})^{x_1} = g^{x_1 x_2}$.
  • Efficient: one call to $\mathcal{A}$ plus one exponentiation, $\mathcal{O}(n)$ group operations.
$$\Pr[\mathcal{A}' \text{ solves CDH}] \ \ge\ \Pr[\mathsf{DLog}_{\mathcal{A},\mathcal{G}}(n) = 1] = \varepsilon(n).$$

If CDH is hard, the left side is negligible, so $\varepsilon$ is negligible for every PPT $\mathcal{A}$, i.e. DL is hard. $\blacksquare$

In short: CDH is at most as hard as DL. Whoever can compute discrete logarithms can compute Diffie–Hellman keys.
