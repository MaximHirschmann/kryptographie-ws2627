Question

Prove formally that the hardness of the CDH problem relative to $\mathcal{G}$ implies the hardness of the discrete logarithm problem relative to $\mathcal{G}$.

Contrapositive. Let $\mathcal{A}$ solve the discrete-log problem with probability $\varepsilon(n)$. Build a CDH solver:

$\mathcal{A}'(\mathbb{G}, q, g, h_1, h_2)$$x := \mathcal{A}(\mathbb{G}, q, g, h_1)$; output $h_2^{\,x}$
  • $h_1 = g^{x_1}$ for uniform $x_1$ is a uniform group element, exactly as in the DLog experiment, so $\mathcal{A}$ returns $x = \log_g h_1$ with probability $\varepsilon(n)$.
  • In that case $h_2^{\,x} = (g^{x_2})^{x_1} = g^{x_1 x_2}$, the correct CDH answer.
  • $\mathcal{A}'$ is PPT: one call to $\mathcal{A}$ plus one exponentiation.

So $\Pr[\mathcal{A}' \text{ solves CDH}] \ge \varepsilon(n)$. If CDH is hard, $\varepsilon$ is negligible for every PPT $\mathcal{A}$, i.e. DL is hard. $\blacksquare$
