Question

Prove that any pseudorandom permutation is also a pseudorandom function. Hint: Show first that in polynomial time, a random permutation cannot be distinguished from a random function. Use the "birthday bound" when necessary.

Setup

Let $F : \{0,1\}^n \times \{0,1\}^n \to \{0,1\}^n$ be a pseudorandom permutation (PRP): for every PPT distinguisher $D$,

$$\big|\Pr[D^{F_k(\cdot)}(1^n) = 1] - \Pr[D^{\pi(\cdot)}(1^n) = 1]\big| \le \mathsf{negl}(n),$$

where $k \leftarrow \{0,1\}^n$ and $\pi$ is a uniformly random permutation of $\{0,1\}^n$. We have to show the same with a uniformly random function $f$ in place of $\pi$.

Step 1: Random permutation vs. random function

Lemma. If $D$ makes at most $q = q(n)$ oracle queries, then $\big|\Pr[D^{\pi} = 1] - \Pr[D^{f} = 1]\big| \le \frac{q^2}{2^{n+1}}$.

Proof. Without loss of generality $D$ never repeats a query, because it can remember the answers. Answer the oracle by "lazy sampling":

  • Random function $f$: each new query gets an independent uniform answer $y_i \leftarrow \{0,1\}^n$.
  • Random permutation $\pi$: each new query gets a uniform answer from the values not used before. Equivalently: draw $y_i$ uniformly as for $f$, and if $y_i$ equals an earlier answer, draw again.

Run both with the same random $y_i$. The two oracles answer identically as long as no $y_i$ repeats an earlier $y_j$. Let $\mathsf{Coll}$ be the event that this happens. Then $D$'s output can differ only if $\mathsf{Coll}$ occurs, so

$$\big|\Pr[D^{\pi} = 1] - \Pr[D^{f} = 1]\big| \le \Pr[\mathsf{Coll}] \le \sum_{1 \le j \lt i \le q} \Pr[y_i = y_j] = \binom{q}{2} \cdot 2^{-n} \le \frac{q^2}{2^{n+1}}.$$

This is the birthday bound. $\blacksquare$

Step 2: PRP $\Rightarrow$ PRF

Let $D$ be any PPT distinguisher. It runs in polynomial time, so it makes at most a polynomial number $q(n)$ of queries. By the triangle inequality:

$$ \begin{aligned} \big|\Pr[D^{F_k} = 1] - \Pr[D^{f} = 1]\big| &\le \underbrace{\big|\Pr[D^{F_k} = 1] - \Pr[D^{\pi} = 1]\big|}_{\le\, \mathsf{negl}(n) \text{ (F is a PRP)}} + \underbrace{\big|\Pr[D^{\pi} = 1] - \Pr[D^{f} = 1]\big|}_{\le\, q(n)^2 / 2^{n+1} \text{ (Lemma)}}. \end{aligned} $$

$\frac{q(n)^2}{2^{n+1}}$ is negligible (a polynomial times $2^{-n}$, see Question 17), and the sum of two negligible functions is negligible. Hence $F$ is a pseudorandom function. $\blacksquare$

The polynomial bound on $D$ is essential. An unbounded distinguisher that makes $2^{n/2}$ or more queries will see a collision of $f$ with constant probability, and that never happens for a permutation.
