Question

Prove that any pseudorandom permutation is also a pseudorandom function. Hint: Show first that in polynomial time, a random permutation cannot be distinguished from a random function. Use the "birthday bound" when necessary.

Step 1: a random permutation looks like a random function

Lemma. If $D$ makes at most $q$ queries, then $\big|\Pr[D^{\pi} = 1] - \Pr[D^{f} = 1]\big| \le \frac{q^2}{2^{n+1}}$ for a random permutation $\pi$ and a random function $f$.

Proof. Answer each new query with a fresh uniform value $y_i$. For $f$ that is exactly right; for $\pi$ it is right as long as no $y_i$ repeats an earlier answer. So the two oracles differ only on the event $\mathsf{Coll}$ of such a repetition, and by the birthday bound

$$\Pr[\mathsf{Coll}] \le \binom{q}{2} 2^{-n} \le \frac{q^2}{2^{n+1}}. \qquad \blacksquare$$

Step 2: PRP $\Rightarrow$ PRF

A PPT distinguisher $D$ makes polynomially many queries $q(n)$. By the triangle inequality,

$$\big|\Pr[D^{F_k} = 1] - \Pr[D^{f} = 1]\big| \le \underbrace{\big|\Pr[D^{F_k} = 1] - \Pr[D^{\pi} = 1]\big|}_{\le\, \mathsf{negl}(n)\ (F \text{ is a PRP})} + \underbrace{\frac{q(n)^2}{2^{n+1}}}_{\text{Lemma}},$$

which is negligible. So $F$ is a PRF. $\blacksquare$
