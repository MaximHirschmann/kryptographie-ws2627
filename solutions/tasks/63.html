Question

For $g : \{0,1\}^n \to \{0,1\}^n$, let $g^{\$}$ be an oracle that on each call picks a fresh uniform $r \in \{0,1\}^n$ and returns $(r, g(r))$. A keyed function $F$ is a weak PRF if every PPT $D$ distinguishes $F_k^{\$}$ from $f^{\$}$ (for random $f \in \mathsf{Func}_n$) with at most negligible advantage. In short: $F$ only has to look random on random inputs.

  1. Show that every PRF is a weak PRF.
  2. For a PRF $F'$ let $F_k(x) = F'_k(x)$ if $x$ is even and $F_k(x) = F'_k(x+1)$ if $x$ is odd. Show that $F$ is a weak PRF but not a PRF.
  3. Is counter mode with a weak PRF necessarily CPA-secure? Does it necessarily have indistinguishable encryptions for an eavesdropper?
  4. Construct a CPA-secure encryption scheme from a weak PRF.

Source: Katz & Lindell, 1st ed., Exercise 3.20 (restated).

(a) PRF ⇒ weak PRF

Given a weak-PRF distinguisher $D$, build $D'$ with an ordinary oracle $O$: answer each of $D$'s oracle calls by picking $r \leftarrow \{0,1\}^n$ and returning $(r, O(r))$. If $O = F_k$, $D$ sees $F_k^{\$}$; if $O = f$, it sees $f^{\$}$. So $D'$ has the same advantage as $D$, which is negligible since $F$ is a PRF. $\blacksquare$

(b) Weak PRF but not PRF

Not a PRF. Query $1$ and $2$: $F_k(1) = F'_k(2) = F_k(2)$ always, while a random function gives equal values only with probability $2^{-n}$.

Weak PRF. $F$ differs from a random function only through the pairing of each odd $x$ with $x + 1$. On random inputs $r_1, \dots, r_q$, two of them land in the same pair only with probability $\le q^2/2^n$. Without that, the answers $F_k(r_i) = F'_k(\varphi(r_i))$, where $\varphi$ rounds odd inputs up to the next even one, are values of the PRF $F'$ at distinct points, hence indistinguishable from independent uniform strings, exactly as for $f^{\$}$. So the advantage is $\le \mathsf{negl}(n) + q^2/2^n$. $\blacksquare$

(c) Counter mode with a weak PRF: not even EAV-secure

Use $F$ from (b). If $\mathit{ctr}$ is even, the pads $F_k(\mathit{ctr}+1)$ and $F_k(\mathit{ctr}+2)$ are equal. Output $m_0 = 0^n \| 0^n$ and $m_1 = 0^n \| 1^n$; given $\langle \mathit{ctr}, c_1, c_2 \rangle$ with even $\mathit{ctr}$, output $0$ iff $c_1 \oplus c_2 = 0^n$ (and guess if $\mathit{ctr}$ is odd). This wins with probability $\frac34$, so counter mode is neither EAV- nor CPA-secure. $\blacksquare$

(d) CPA security from a weak PRF

Use $\mathsf{Enc}_k(m) = \langle r, F_k(r) \oplus m \rangle$ with a fresh $r \leftarrow \{0,1\}^n$. Its CPA proof (script Theorem 11) only ever evaluates $F_k$ at uniformly random points, so the reduction can get all its values $(r, F_k(r))$ from the oracle $F_k^{\$}$. The proof therefore goes through for a weak PRF unchanged. $\blacksquare$
