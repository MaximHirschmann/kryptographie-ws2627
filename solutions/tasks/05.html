The ciphertext was generated with a Beaufort cipher.

Gen: Let $t$ be the period. For $i = 0, \dots, t-1$ set $k_i$ to be a random number in $\{0, \dots, 25\}$. Output $k = k_0, \dots, k_{t-1}$.
Enc: Given plaintext $p = p_0, \dots, p_n$ set $c_i = k_{i \bmod t} - p_i \bmod 26$. Output $c = c_0, \dots, c_n$.

Answer. The key has period $t = 5$ and is FROST $= (5, 17, 14, 18, 19)$. The plaintext is the poem A Cliff Dwelling by Robert Frost.

Decryption

Solve $c_i = k_{i \bmod t} - p_i$ for $p_i$:

$$p_i = k_{i \bmod t} - c_i \bmod 26.$$

Decryption is therefore the same operation as encryption: the Beaufort cipher is its own inverse. The decryption key is the encryption key.

Every $t$-th letter uses the same key letter. With $-c_i = p_i - k_{i \bmod t}$, each column of the negated ciphertext is a shift cipher with key $-k_i$. So the Vigenère attack from the script works unchanged: first find $t$, then break each column as a shift cipher.

Step 1: Find the period $t$

Index of coincidence

To check this, split the ciphertext into $\tilde t$ columns for $\tilde t = 1,\dots,10$. In a column of $L>1$ letters with counts $N_i$, use the finite-sample estimate $\widehat S=\sum_iN_i(N_i-1)/(L(L-1))$, then average over the columns. This is the pair-count correction to the script’s $\sum_iq_i^2$ statistic. Values near $0.065$ suggest English-like frequencies; values near $0.038$ suggest a more uniform distribution.

The peaks at $5$ and its multiple $10$ support $t=5$; the readable decryption below confirms that choice.

Step 2: Break each column

Column $i$ contains the letters $c_i, c_{i+5}, c_{i+10}, \dots$. Let $q_0, \dots, q_{25}$ be the frequencies of the negated letters $-c$ in that column. As in the script, for each candidate $k$ compare them with the English letter probabilities $p_0, \dots, p_{25}$:

$$I_k = \sum_{j=0}^{25} p_j \cdot q_{j - k}$$

The correct key letter gives $I_k \approx 0.065$:

In every column the best value is close to $0.065$ and clearly ahead of the runner-up. Together the columns give the key FROST.

Step 3: Decrypt

Apply $p_i = k_{i \bmod 5} - c_i \bmod 26$ with $k = \texttt{FROST}$:

M K K B P N R B P V ...     ciphertext
F R O S T F R O S T ...     key (repeated)
t h e r e s a n d y ...     plaintext = key - ciphertext

Adding spaces and line breaks to the decrypted text gives:

Robert Frost, A Cliff Dwelling. The key is the poet's name.

Code

c = "MKKBPNRBPVNNKGBMKKMFUOKF..."   # full ciphertext without line breaks
key = "FROST"

# Beaufort: p = k - c (mod 26), the same operation as encryption
print("".join(chr((ord(key[i % 5]) - ord(ch)) % 26 + ord("a"))
              for i, ch in enumerate(c)))
