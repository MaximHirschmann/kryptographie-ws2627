Question

Let $G$ be a pseudorandom generator and let $\hat G(s)$ be the first $n$ bits of $G(s)$, where $|s| = n$. Prove that the keyed function $F_k(x) = \hat G(k) \oplus x$ is not a pseudorandom function.

Source: Katz & Lindell, 1st ed., Exercise 3.10 (restated).

Idea

For a fixed key, $F_k$ XORs every input with the same string $\hat G(k)$. So $F_k(x) \oplus F_k(x') = x \oplus x'$ for all inputs, a structure that a random function almost never has. The pseudorandomness of $G$ does not help: the problem is the linearity in $x$.

Distinguisher

$D^{O}(1^n)$:
1.Query $y_1 := O(0^n)$ and $y_2 := O(1^n)$.
2.Output $1$ iff $y_1 \oplus y_2 = 1^n$.

Analysis

Oracle $F_k$. $y_1 \oplus y_2 = (\hat G(k) \oplus 0^n) \oplus (\hat G(k) \oplus 1^n) = 1^n$, so

$$\Pr[D^{F_k(\cdot)}(1^n) = 1] = 1.$$

Oracle $f \leftarrow \mathsf{Func}_n$. $f(0^n)$ and $f(1^n)$ are independent and uniform, so $y_1 \oplus y_2$ is uniform and

$$\Pr[D^{f(\cdot)}(1^n) = 1] = 2^{-n}.$$

The difference is $1 - 2^{-n}$, which is not negligible. $D$ makes two queries and runs in polynomial time. $\blacksquare$

Result. $F$ is not pseudorandom: two queries $0^n, 1^n$ reveal the relation $F_k(x) \oplus F_k(x') = x \oplus x'$. $\blacksquare$

The same construction is fine as a one-time pad ($c = \hat G(k) \oplus m$ for a single message). The difference is that a PRF must look random on many inputs under the same key, like a fresh pad for every input.
