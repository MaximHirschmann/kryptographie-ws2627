Question

DES has the so-called complementarity property. This means that

$$\mathrm{DES}_k(x) = \overline{\mathrm{DES}_{\overline k}(\overline x)}$$

for $k \in \mathcal{K}$ and $x \in \mathcal{M}$. Show that it is possible to find the secret key in DES (with probability 1) using $2^{55}$ local computations of DES.

Hint: Use a chosen-plaintext attack with two carefully chosen plaintexts.

Chosen plaintexts

Choose any $x$ and ask for the encryptions of $x$ and $\overline x$:

$$y_1 := \mathrm{DES}_k(x), \qquad y_2 := \mathrm{DES}_k(\overline x).$$

By the complementarity property (Question 39), the encryption of $x$ under the complementary key is also known:

$$\mathrm{DES}_{\overline k}(x) = \overline{\mathrm{DES}_{k}(\overline x)} = \overline{y_2}.$$

Search over half the keys

The key space $\{0,1\}^{56}$ splits into $2^{55}$ pairs $\{k', \overline{k'}\}$. Exactly one key of each pair starts with $0$. For each of these $2^{55}$ keys $k'$, compute one DES encryption $z := \mathrm{DES}_{k'}(x)$:

  • if $z = y_1$: $k'$ is a candidate for $k$;
  • if $z = \overline{y_2}$: then $\mathrm{DES}_{k'}(x) = \mathrm{DES}_{\overline k}(x)$, so $\overline{k'}$ is a candidate for $k$.

One encryption under $k'$ tests both $k'$ and $\overline{k'}$. So $2^{55}$ DES computations cover all $2^{56}$ keys, and the true key is always among the candidates.

Correctness

The true key $k$ is never missed. If $k$ starts with $0$, it is found as $k' = k$ via $z = y_1$. Otherwise $\overline k$ starts with $0$, and for $k' = \overline k$ we get $z = \mathrm{DES}_{\overline k}(x) = \overline{y_2}$, which yields $\overline{k'} = k$. A wrong key that happens to map $x$ to the same value gives a false candidate. Such candidates are rare (about $2^{56-64}$ expected) and are removed by checking them against the second pair, or against one more known pair. This costs only a handful of extra DES computations. So the key is found with probability $1$ using about $2^{55}$ DES evaluations, half of a naive exhaustive search. $\blacksquare$
