Question

Consider any public-key encryption scheme for single-bit messages. Show that an adversary with unlimited computing power, given $pk$ and $c \leftarrow \mathsf{Enc}_{pk}(m)$, can find $m$ with probability $1$. Conclude that perfectly secret public-key encryption is impossible.

Source: Katz & Lindell, 1st ed., Exercise 10.1 (restated).

Idea

In the private-key setting the adversary does not know the key, so it cannot encrypt. With public keys the adversary can encrypt everything itself. With unlimited time it can list all possible encryptions of 0 and check whether $c$ is among them.

The adversary

$\mathsf{Enc}$ is a polynomial-time algorithm, so on input $pk$ it uses at most $p(n)$ random bits for some polynomial $p$. Write $\mathsf{Enc}_{pk}(0; r)$ for the encryption with random tape $r$.

$\mathcal{A}(pk, c)$:
1.For every $r \in \{0,1\}^{p(n)}$: if $\mathsf{Enc}_{pk}(0; r) = c$, output $0$.
2.If no $r$ matched, output $1$.

This takes $2^{p(n)}$ encryptions: exponential, but we put no limit on time.

Correctness

  • If $m = 0$: $c = \mathsf{Enc}_{pk}(0; r^*)$ for the random tape $r^*$ that was actually used, so the search finds a match and $\mathcal{A}$ outputs $0$.
  • If $m = 1$: suppose some $r$ gives $\mathsf{Enc}_{pk}(0; r) = c$. Then $c$ is both a possible encryption of $0$ and of $1$ under $pk$. With the matching $sk$, correctness requires $\mathsf{Dec}_{sk}(c) = 0$ and $\mathsf{Dec}_{sk}(c) = 1$, which is impossible. So no $r$ matches and $\mathcal{A}$ outputs $1$.

$\mathcal{A}$ is always right. $\blacksquare$

Consequence

In $\mathsf{PubK}^{\mathsf{eav}}$ with $m_0 = 0$ and $m_1 = 1$, this adversary wins with probability $1 \ne \frac12$. So no public-key scheme is perfectly secret. Any security must be computational.

Result. Because anyone can encrypt, an unbounded adversary can compare $c$ with all encryptions of $0$. The supports of $\mathsf{Enc}_{pk}(0)$ and $\mathsf{Enc}_{pk}(1)$ are disjoint, so this decides $m$ with certainty. $\blacksquare$

An alternative is to search all random tapes of $\mathsf{Gen}$ for some $(pk, sk')$ with the given $pk$ and decrypt with $sk'$. If correctness only holds with overwhelming probability (not perfectly), the adversary still succeeds with probability $1 - \mathsf{negl}(n)$, which is still far from $\frac12$.
