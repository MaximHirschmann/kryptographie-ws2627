Question

Consider any public-key encryption scheme for single-bit messages. Show that an adversary with unlimited computing power, given $pk$ and $c \leftarrow \mathsf{Enc}_{pk}(m)$, can find $m$ with probability $1$. Conclude that perfectly secret public-key encryption is impossible.

Source: Katz & Lindell, 1st ed., Exercise 10.1 (restated).

The adversary: brute force over the random coins

Let $\ell = \ell(n)$ be the number of random bits used by $\mathsf{Enc}$. Given $pk$ and $c$, compute $\mathsf{Enc}_{pk}(0; r)$ for every $r \in \{0,1\}^\ell$. If some result equals $c$, output $0$; otherwise output $1$.

  • If $m = 0$, then $c = \mathsf{Enc}_{pk}(0; r)$ for the coins actually used, so the adversary outputs $0$.
  • If $m = 1$, then no encryption of $0$ equals $c$, because $\mathsf{Dec}_{sk}(c)$ cannot be both $0$ and $1$ (correctness). So the adversary outputs $1$.

The adversary is always right; it is exponential-time, which is allowed here. $\blacksquare$

Consequence. In $\mathsf{PubK}^{\mathsf{eav}}$ with $m_0 = 0$, $m_1 = 1$ it wins with probability $1 \ne \frac12$, so no public-key scheme is perfectly secret. The reason is that anyone can encrypt with $pk$.
