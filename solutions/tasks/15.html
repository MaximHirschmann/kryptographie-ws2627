Question

Prove that Definition 2.1 implies Definition 2.4.

Definition 2.1 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every $m \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$ for which $\Pr[C = c] \gt 0$ it holds that $\Pr[M = m \mid C = c] = \Pr[M = m]$.

Definition 2.4 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every adversary $\mathcal{A}$ it holds that $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] = \frac12$.

Hints: use the answer to Exercise 2.6 in [Katz & Lindell] (Question 14 here). Note that $\mathcal{A}$ is a deterministic algorithm, so it always outputs the same pair of messages. Since $\mathcal{A}$ is deterministic, the sets of ciphertexts for which it answers 0 and 1 are well-defined and disjoint.

The game $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}$ (script §5.1)

1.$k \leftarrow \mathsf{Gen}$
2.$\mathcal{A}$ outputs two messages $m_0, m_1 \in \mathcal{M}$
3.$b \leftarrow \{0,1\}$ uniformly; $c \leftarrow \mathsf{Enc}_k(m_b)$
4.$\mathcal{A}(c)$ outputs a guess $b'$; the game outputs $1$ iff $b' = b$

Proof

Assume Definition 2.1 and fix a (deterministic) adversary $\mathcal{A}$. It always outputs the same pair $m_0, m_1$. If $m_0 = m_1$, the ciphertext does not depend on $b$, so $\Pr[b' = b] = \frac12$. Otherwise the encrypted message $M := m_b$ is uniform over $\{m_0, m_1\}$, and Definition 2.1 (applied to this distribution; see Question 14) gives, for every $c$ with $\Pr[C = c] \gt 0$:

$$\Pr[M = m_0 \mid C = c] = \Pr[M = m_1 \mid C = c] = \tfrac12. \tag{$*$}$$

Let $\mathcal{C}_i := \{c \mid \mathcal{A}(c) = i\}$; these sets are disjoint and cover $\mathcal{C}$. $\mathcal{A}$ wins iff $c \in \mathcal{C}_0, M = m_0$ or $c \in \mathcal{C}_1, M = m_1$, so

$$ \begin{aligned} \Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] &= \sum_{c \in \mathcal{C}_0} \Pr[M = m_0 \mid C = c] \Pr[C = c] + \sum_{c \in \mathcal{C}_1} \Pr[M = m_1 \mid C = c] \Pr[C = c] \\ &\overset{(*)}{=} \tfrac12 \sum_{c \in \mathcal{C}} \Pr[C = c] = \tfrac12. \end{aligned} $$

Since $\mathcal{A}$ was arbitrary, Definition 2.4 holds. $\blacksquare$

Intuition: whatever $\mathcal{A}$ sees, both messages remain equally likely, so every guess is right with probability $\frac12$. A randomised $\mathcal{A}$ is handled by fixing its coins and averaging. The script proves the same statement from Definition 5 (Theorem 4).
