Question

Prove that Definition 2.1 implies Definition 2.4.

Definition 2.1 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every $m \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$ for which $\Pr[C = c] \gt 0$ it holds that $\Pr[M = m \mid C = c] = \Pr[M = m]$.

Definition 2.4 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every adversary $\mathcal{A}$ it holds that $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] = \frac12$.

Hints: use the answer to Exercise 2.6 in [Katz & Lindell] (Question 14 here). Note that $\mathcal{A}$ is a deterministic algorithm, so it always outputs the same pair of messages. Since $\mathcal{A}$ is deterministic, the sets of ciphertexts for which it answers 0 and 1 are well-defined and disjoint.

The game $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}$ (script §5.1)

1.$k \leftarrow \mathsf{Gen}$
2.$\mathcal{A}$ outputs two messages $m_0, m_1 \in \mathcal{M}$
3.$b \leftarrow \{0,1\}$ uniformly; $c \leftarrow \mathsf{Enc}_k(m_b)$
4.$\mathcal{A}(c)$ outputs a guess $b'$; the game outputs $1$ iff $b' = b$

Proof

Assume the scheme satisfies Definition 2.1 and fix an adversary $\mathcal{A}$.

Step 1: The message distribution in the game. $\mathcal{A}$ is deterministic, so it always outputs the same pair $m_0, m_1$.

  • If $m_0 = m_1$, then $c$ has the same distribution for $b = 0$ and $b = 1$. So $\mathcal{A}$'s guess is independent of $b$, and $\Pr[b' = b] = \frac12$. Done.
  • Otherwise $m_0 \ne m_1$. The message $M := m_b$ that is encrypted is uniform over $\mathcal{M}' = \{m_0, m_1\}$, and the event $b = i$ is the same as the event $M = m_i$.

This is a distribution over $\mathcal{M}$ with $\Pr[M = m] = 0$ for $m \notin \{m_0, m_1\}$. By Definition 2.1 (and, by Question 14, even if one only assumes it for distributions with full support), for every $c$ with $\Pr[C = c] \gt 0$:

$$\Pr[M = m_0 \mid C = c] = \Pr[M = m_0] = \tfrac12 \quad\text{and}\quad \Pr[M = m_1 \mid C = c] = \Pr[M = m_1] = \tfrac12. \tag{$*$}$$

Step 2: Split by $\mathcal{A}$'s answer. $\mathcal{A}$ is deterministic, so for each $c$ its answer $\mathcal{A}(c)$ is fixed. Let

$$\mathcal{C}_0 := \{c \in \mathcal{C} \mid \mathcal{A}(c) = 0\}, \qquad \mathcal{C}_1 := \{c \in \mathcal{C} \mid \mathcal{A}(c) = 1\}.$$

These sets are disjoint and $\mathcal{C} = \mathcal{C}_0 \cup \mathcal{C}_1$. Only ciphertexts with $\Pr[C = c] \gt 0$ contribute.

Step 3: Compute the success probability. $\mathcal{A}$ wins exactly when $c \in \mathcal{C}_0$ and $M = m_0$, or when $c \in \mathcal{C}_1$ and $M = m_1$. By the law of total probability:

$$ \begin{aligned} \Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] &= \sum_{c \in \mathcal{C}_0} \Pr[C = c \wedge M = m_0] + \sum_{c \in \mathcal{C}_1} \Pr[C = c \wedge M = m_1] \\ &= \sum_{c \in \mathcal{C}_0} \Pr[M = m_0 \mid C = c] \cdot \Pr[C = c] + \sum_{c \in \mathcal{C}_1} \Pr[M = m_1 \mid C = c] \cdot \Pr[C = c] \\ &\overset{(*)}{=} \sum_{c \in \mathcal{C}_0} \tfrac12 \Pr[C = c] + \sum_{c \in \mathcal{C}_1} \tfrac12 \Pr[C = c] \\ &= \tfrac12 \sum_{c \in \mathcal{C}} \Pr[C = c] = \tfrac12. \end{aligned} $$

Since $\mathcal{A}$ was arbitrary, Definition 2.4 holds. $\blacksquare$

Intuition. Whatever ciphertext $\mathcal{A}$ sees, both messages are still equally likely, because the posterior equals the prior of $\frac12$. So every guess is right with probability exactly $\frac12$.

The script proves the same statement starting from Definition 5 (Theorem 4, case Def. 5 $\Rightarrow$ Def. 6). This proof starts from Definition 2.1 directly, so it does not need the detour through Definitions 4 and 5. If $\mathcal{A}$ were randomised, we would fix its random coins, apply the argument above for each choice, and average. The result is still $\frac12$.
