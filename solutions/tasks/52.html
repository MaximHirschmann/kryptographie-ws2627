Question

Show that any 2-round key-exchange protocol (that is, where each party sends a single message) satisfying the key exchange definition from class can be converted into a public-key encryption scheme that is CPA-secure.

Structure of a 2-round protocol

Alice chooses randomness $\rho_A$ and sends $\mathsf{msg}_1 = \mathsf{A}_1(1^n; \rho_A)$. Bob chooses $\rho_B$, sends $\mathsf{msg}_2 = \mathsf{B}(1^n, \mathsf{msg}_1; \rho_B)$ and outputs $k_B$. Alice computes $k_A = \mathsf{A}_2(\rho_A, \mathsf{msg}_2)$. By correctness $k_A = k_B =: k \in \{0,1\}^n$. Since Alice's message does not depend on Bob, it can be published in advance; it becomes the public key.

Construction

Genchoose $\rho_A$;   $pk := \mathsf{msg}_1 = \mathsf{A}_1(1^n; \rho_A)$;   $sk := \rho_A$
Encinput $pk$, $m \in \{0,1\}^n$: run Bob on $\mathsf{msg}_1 = pk$, obtaining $(\mathsf{msg}_2, k)$; output $\langle \mathsf{msg}_2,\ k \oplus m \rangle$
Decinput $sk = \rho_A$, $\langle c_1, c_2 \rangle$: $k := \mathsf{A}_2(\rho_A, c_1)$; output $c_2 \oplus k$

Correctness: Alice and Bob compute the same key, so $c_2 \oplus k = m$. (Diffie–Hellman turns into ElGamal this way.)

CPA security

For public-key schemes EAV security implies CPA security (Question 50), so consider $\mathsf{PubK}^{\mathsf{eav}}$. What the adversary sees, $pk = \mathsf{msg}_1$ and $c = \langle \mathsf{msg}_2, k \oplus m_b \rangle$, is a transcript plus the key used as a one-time pad.

Let $\mathcal{A}$ be PPT. Build $\mathcal{A}'$ for the lecture's $\mathsf{KE}^{\mathsf{eav}}$ (Question 46; $k_1 = k$ is the real key, $k_0$ is uniform):

$\mathcal{A}'(\mathsf{trans} = (\mathsf{msg}_1, \mathsf{msg}_2), k_b)$ run $\mathcal{A}(pk := \mathsf{msg}_1)$, which outputs $m_0, m_1$ choose $\beta \leftarrow \{0,1\}$; give $\mathcal{A}$ the ciphertext $\langle \mathsf{msg}_2,\ k_b \oplus m_\beta \rangle$; receive $\beta'$ output $1$ ("real key") if $\beta' = \beta$, otherwise $0$
  • $b = 1$, real key $k_1 = k$: $\mathcal{A}$ sees exactly $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}$, so $\Pr[\beta' = \beta] = \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] =: P$.
  • $b = 0$, uniform $k_0$: $k_0 \oplus m_\beta$ is a one-time pad, uniform and independent of $\beta$, so $\Pr[\beta' = \beta] = \frac12$, and $\mathcal{A}'$ correctly outputs $0$ with probability $\frac12$.
$$\Pr[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A}',\Pi_{KE}} = 1] = \tfrac12 P + \tfrac12 \cdot \tfrac12 \quad\Longrightarrow\quad P = 2\Pr[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A}',\Pi_{KE}} = 1] - \tfrac12 \le 2\big(\tfrac12 + \mathsf{negl}(n)\big) - \tfrac12 = \tfrac12 + 2\,\mathsf{negl}(n).$$

So the scheme is EAV-secure and therefore CPA-secure. $\blacksquare$

Messages longer than $n$ bits: use the key $k$ in a private-key scheme instead of the one-time pad, i.e. hybrid encryption (Question 49). The construction needs exactly 2 rounds: Alice's message must not depend on anything the sender does, so that it can serve as a fixed public key.
