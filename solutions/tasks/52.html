Question

Show that any 2-round key-exchange protocol (that is, where each party sends a single message) satisfying the key exchange definition from class can be converted into a public-key encryption scheme that is CPA-secure.

Idea. In a 2-round protocol, Alice's message does not depend on Bob, so it can be published in advance as the public key. The sender plays Bob and uses the shared key as a one-time pad. (Diffie–Hellman becomes ElGamal this way.)

Construction

Genchoose Alice's randomness $\rho_A$; $pk :=$ Alice's message $\mathsf{msg}_1$; $sk := \rho_A$
Encrun Bob on $\mathsf{msg}_1 = pk$, obtaining his message $\mathsf{msg}_2$ and the key $k$; output $\langle \mathsf{msg}_2,\ k \oplus m \rangle$
Deccompute Alice's key $k$ from $\rho_A$ and $c_1 = \mathsf{msg}_2$; output $c_2 \oplus k$

Correctness follows from the correctness of the key exchange.

Security

For public-key schemes EAV security is CPA security. The adversary sees a transcript $(\mathsf{msg}_1, \mathsf{msg}_2)$ plus the key used as a one-time pad. Given an adversary $\mathcal{A}$, build $\mathcal{A}'$ in $\mathsf{KE}^{\mathsf{eav}}$: on input $(\mathsf{trans}, k_b)$ it runs $\mathcal{A}(\mathsf{msg}_1)$, encrypts a random $m_\beta$ as $\langle \mathsf{msg}_2, k_b \oplus m_\beta \rangle$, and outputs $1$ ("real key") iff $\mathcal{A}$ guesses $\beta$.

  • With the real key, $\mathcal{A}$ sees exactly the encryption game and guesses $\beta$ with probability $P$.
  • With a uniform key, $k_0 \oplus m_\beta$ is a one-time pad, so $\mathcal{A}$ guesses with probability exactly $\frac12$.

So $\Pr[\mathcal{A}' \text{ wins}] = \frac12 P + \frac14$, and security of the key exchange gives $P \le \frac12 + 2\,\mathsf{negl}(n)$. $\blacksquare$
