Question

Let $F$ be a pseudorandom function, and $G$ a pseudorandom generator with expansion factor $\ell(n) = n + 1$. For each of the following encryption schemes, state whether the scheme has indistinguishable encryptions in the presence of an eavesdropper and whether it is CPA-secure, and justify your answer very briefly. In each case, the shared key is a random $k \in \{0,1\}^n$.

  1. To encrypt $m \in \{0,1\}^{2n+2}$ parse $m$ as $m_1 \| m_2$ with $|m_1| = |m_2|$ and send $\langle G(k) \oplus m_1, G(k+1) \oplus m_2 \rangle$.
  2. To encrypt $m \in \{0,1\}^{n+1}$ choose a random $r \leftarrow \{0,1\}^n$ and send $\langle r, G(r) \oplus m \rangle$.
  3. To encrypt $m \in \{0,1\}^n$ send $m \oplus F_k(0^n)$.
  4. To encrypt $m \in \{0,1\}^{2n}$ parse $m$ as $m_1 \| m_2$ with $|m_1| = |m_2|$, then choose $r \leftarrow \{0,1\}^n$ at random, and send $\langle r, m_1 \oplus F_k(r), m_2 \oplus F_k(r+1) \rangle$.

CPA security implies EAV security, and a deterministic scheme is never CPA-secure: query $\mathsf{Enc}(m_0)$ and compare it with the challenge.

1. Not EAV-secure in general, not CPA-secure

It is deterministic, so not CPA-secure. For EAV: the PRG guarantee covers one output on a uniform seed, not two outputs on the related seeds $k$ and $k+1$. Counterexample: let $G(s) := G'(s_1 \cdots s_{n-1})$ for a PRG $G'$; this $G$ ignores the last seed bit and is still a PRG. Whenever the last bit of $k$ is $0$ (probability $\frac12$), $G(k) = G(k+1)$ and $c_1 \oplus c_2 = m_1 \oplus m_2$. Distinguishing $0^{n+1} \| 0^{n+1}$ from $0^{n+1} \| u$ (uniform $u$) by checking $c_1 = c_2$ succeeds with probability about $\frac34$.

2. Neither

The ciphertext does not depend on the key. Anyone computes $m = G(r) \oplus (G(r) \oplus m)$.

3. EAV-secure, not CPA-secure

$F_k(0^n)$ is pseudorandom, so this is a one-time pad with a pseudorandom pad, secure for one message exactly as in the PRG scheme (script Theorem 8). It is deterministic, so not CPA-secure.

4. EAV- and CPA-secure

This is randomised counter mode with two blocks. The proof is the one for $\langle r, F_k(r) \oplus m \rangle$ (Question 19), with $\mathsf{Repeat}$ now the event that $r^* - 1$, $r^*$ or $r^* + 1$ is used in another ciphertext; this has probability $\le 3q/2^n$, which is negligible. $\blacksquare$
