Question

Modify the DES key schedule so that all sub-keys of rounds 1–8 come from the left half (28 bits) of the master key, and all sub-keys of rounds 9–16 from the right half (28 bits). Show an attack that recovers the whole key in roughly $2^{28}$ time.

Source: Katz & Lindell, 1st ed., Exercise 5.14 (restated).

Idea: meet in the middle

The cipher splits into two independent halves: the first 8 rounds depend only on $k_L$, the last 8 only on $k_R$. Given a known pair $(x, y)$, compute the state after round 8 forwards from $x$ for every $k_L$ and backwards from $y$ for every $k_R$, then look for a match. This is the same idea as the attack on double encryption.

Attack

Let $E^{(1)}_{k_L}$ be $IP$ followed by rounds 1–8, and $E^{(2)}_{k_R}$ rounds 9–16 followed by the swap and $IP^{-1}$. Then $\mathsf{DES}'_{k}(x) = E^{(2)}_{k_R}(E^{(1)}_{k_L}(x))$. Both parts are invertible, since Feistel rounds are invertible given their sub-keys.

0.Get two known plaintext/ciphertext pairs $(x, y)$ and $(x', y')$.
1.For every $k_L \in \{0,1\}^{28}$: compute $v = E^{(1)}_{k_L}(x)$ and store $(v, k_L)$ in a hash table indexed by $v$.
2.For every $k_R \in \{0,1\}^{28}$: compute $w = (E^{(2)}_{k_R})^{-1}(y)$ and look up all $k_L$ stored under $w$.
3.For each match $(k_L, k_R)$, test it on $(x', y')$ and output it if it passes.

Analysis

Correctness. For the true key, $E^{(1)}_{k_L}(x)$ and $(E^{(2)}_{k_R})^{-1}(y)$ are both the true middle state, so the true key is found.

False matches. There are $2^{56}$ pairs $(k_L, k_R)$ and the middle state has 64 bits, so a wrong pair matches with probability about $2^{-64}$. The expected number of false matches is about $2^{56-64} = 2^{-8}$. The second pair removes them (a wrong key survives it with probability $2^{-64}$).

Cost. $2^{28}$ evaluations of 8 rounds forwards and $2^{28}$ backwards: about $2^{29}$ half-DES evaluations, i.e. roughly $2^{28}$ full DES evaluations. Memory: a table with $2^{28}$ entries (a few GB).

Result. Because the two key halves act on disjoint sets of rounds, a meet-in-the-middle attack on the state after round 8 recovers both halves in about $2^{28}$ time and memory, instead of $2^{56}$ for brute force. $\blacksquare$

The real DES key schedule rotates and selects bits so that each key bit is used in about 14 of the 16 rounds. That rules out such a split.
