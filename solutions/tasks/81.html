Question

An interactive encryption protocol $\Pi'$: sender and receiver first run a key-exchange protocol $\Pi$ to get a shared key $k$; then the sender sends $c \leftarrow \mathsf{Enc}_k(m)$, and the receiver decrypts with $k$.

  1. Define indistinguishable encryptions in the presence of an eavesdropper for this interactive setting (analogous to Definition 3.8).
  2. Prove: if $\Pi$ is secure against eavesdroppers and $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ has indistinguishable encryptions for an eavesdropper, then $\Pi'$ satisfies your definition.

Source: Katz & Lindell, 1st ed., Exercise 9.1 (restated).

We assume, as usual, that the key-exchange outputs $n$-bit keys and that $\mathsf{Gen}(1^n)$ outputs a uniform $n$-bit key.

(a) Definition

The experiment $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi'}(n)$:

1.$\mathcal{A}(1^n)$ outputs $m_0, m_1$ with $|m_0| = |m_1|$.
2.The honest parties run $\Pi(1^n)$, giving a transcript $\mathit{trans}$ and a key $k$. Choose $b \leftarrow \{0,1\}$ and compute $c \leftarrow \mathsf{Enc}_k(m_b)$.
3.$\mathcal{A}$ gets $(\mathit{trans}, c)$, i.e. everything sent over the channel, and outputs $b'$. The output is $1$ iff $b' = b$.

$\Pi'$ has indistinguishable encryptions in the presence of an eavesdropper if for every PPT $\mathcal{A}$: $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi'}(n) = 1] \le \frac12 + \mathsf{negl}(n)$.

(b) Proof by a hybrid argument

Define $\mathsf{Hyb}$: like the experiment above, but $c \leftarrow \mathsf{Enc}_{k'}(m_b)$ for a fresh uniform key $k'$, independent of $\mathit{trans}$. Write $p_{\mathsf{real}} = \Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi'} = 1]$ and $p_{\mathsf{hyb}} = \Pr[\mathsf{Hyb} = 1]$.

Step 1: $|p_{\mathsf{real}} - p_{\mathsf{hyb}}| \le \mathsf{negl}(n)$ by the security of $\Pi$

In $\mathsf{KE}^{\mathsf{eav}}_{\mathcal{B},\Pi}$, $\mathcal{B}$ gets $(\mathit{trans}, \hat k)$, where $\hat k$ is the real key (if $\beta = 1$) or a uniform key (if $\beta = 0$), and must guess $\beta$. Build $\mathcal{B}$:

1.Receive $(\mathit{trans}, \hat k)$. Run $\mathcal{A}$ to get $m_0, m_1$.
2.Choose $b \leftarrow \{0,1\}$, compute $c \leftarrow \mathsf{Enc}_{\hat k}(m_b)$ and give $(\mathit{trans}, c)$ to $\mathcal{A}$.
3.Output $\beta' = 1$ iff $\mathcal{A}$ outputs $b' = b$.

If $\beta = 1$, $\mathcal{A}$ is in the real experiment; if $\beta = 0$, in $\mathsf{Hyb}$. So

$$\Pr[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{B},\Pi} = 1] = \tfrac12 p_{\mathsf{real}} + \tfrac12 (1 - p_{\mathsf{hyb}}) = \tfrac12 + \tfrac12(p_{\mathsf{real}} - p_{\mathsf{hyb}}).$$

By security of $\Pi$ this is at most $\frac12 + \mathsf{negl}(n)$, so $p_{\mathsf{real}} - p_{\mathsf{hyb}} \le \mathsf{negl}(n)$. (We only need this direction.)

Step 2: $p_{\mathsf{hyb}} \le \frac12 + \mathsf{negl}(n)$ by the security of the encryption scheme

Build $\mathcal{A}'$ against $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ in $\mathsf{PrivK}^{\mathsf{eav}}$:

1.Run $\Pi(1^n)$ by simulating both honest parties; keep $\mathit{trans}$ and throw away its key.
2.Run $\mathcal{A}$ to get $m_0, m_1$, output them, and receive $c \leftarrow \mathsf{Enc}_{k'}(m_b)$ for the challenger's independent key $k'$.
3.Give $(\mathit{trans}, c)$ to $\mathcal{A}$ and output its $b'$.

This is exactly $\mathsf{Hyb}$, so $p_{\mathsf{hyb}} = \Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A}',\Pi_{\mathsf{enc}}} = 1] \le \frac12 + \mathsf{negl}(n)$.

Combine

$$p_{\mathsf{real}} \le p_{\mathsf{hyb}} + \mathsf{negl}(n) \le \tfrac12 + \mathsf{negl}(n) + \mathsf{negl}(n). \quad \blacksquare$$
Result. An eavesdropper's view $(\mathit{trans}, \mathsf{Enc}_k(m_b))$ is indistinguishable from $(\mathit{trans}, \mathsf{Enc}_{k'}(m_b))$ with an independent key (by key-exchange security), and in that world the transcript is useless (by encryption security). Key exchange followed by private-key encryption is a secure "public-key-like" encryption against passive attackers. $\blacksquare$

This is only for eavesdroppers. An active attacker breaks the composition with a man-in-the-middle attack (Question 82).
