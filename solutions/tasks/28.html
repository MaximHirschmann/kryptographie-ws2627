Question

Assuming the existence of a pseudorandom function, show that there exists an encryption scheme that has indistinguishable multiple encryptions in the presence of an eavesdropper, but is not CPA-secure.

Hint (1): a full formal proof is too long and tedious to be developed in an exam. Instead, give a cipher construction that accomplishes what is required, and reason informally why the construction is secure according to one definition but not according to the other.

Hint (2): the cipher construction must not necessarily make "practical" sense i.e., it can be deliberately weakened to meet the goals outlined above.

Idea. In the multiple-message eavesdropper game, the adversary fixes all messages before seeing any ciphertext; in the CPA game it can choose them adaptively. So build in a trapdoor that only a message derived from an earlier ciphertext can trigger.

Construction

Let $F$ be a PRF. The key is a pair $(k, s)$ of uniform $n$-bit strings; messages are in $\{0,1\}^n$.

Encif $m = s$: output $\langle 0, k \rangle$ (trapdoor: leak the key); otherwise choose $r \leftarrow \{0,1\}^n$ and output $\langle 1, s, r, F_k(r) \oplus m \rangle$
Decfor $\langle 0, \cdot \rangle$ output $s$; for $\langle 1, s, r, c \rangle$ output $F_k(r) \oplus c$

Secure for multiple eavesdropped messages

The adversary fixes its messages without any information about $s$, so one of them equals $s$ only with negligible probability. Otherwise every ciphertext is $\langle 1, s, r, F_k(r) \oplus m \rangle$, where $s$ is independent of the messages, and the rest is the CPA-secure scheme $\langle r, F_k(r) \oplus m \rangle$. So the multiple-message advantage is negligible.

Not CPA-secure

Query the oracle on $0^n$: the answer contains $s$ (unless $0^n = s$, which directly leaks $k$). Query the oracle on $s$: the answer contains $k$. Now decrypt the challenge and output the correct $b$. This wins with probability $1$, because the second query depends on the first answer. $\blacksquare$
