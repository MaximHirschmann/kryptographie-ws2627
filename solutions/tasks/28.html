Question

Assuming the existence of a pseudorandom function, show that there exists an encryption scheme that has indistinguishable multiple encryptions in the presence of an eavesdropper, but is not CPA-secure.

Hint (1): a full formal proof is too long and tedious to be developed in an exam. Instead, give a cipher construction that accomplishes what is required, and reason informally why the construction is secure according to one definition but not according to the other.

Hint (2): the cipher construction must not necessarily make "practical" sense i.e., it can be deliberately weakened to meet the goals outlined above.

Difference between the two definitions

In the multiple-message eavesdropper game, the adversary fixes two message vectors before seeing any ciphertext. In the CPA game, it can choose messages adaptively, after it has seen ciphertexts. So we build in a trapdoor that can only be triggered by a message that depends on a previous ciphertext.

Construction

Let $F$ be a PRF with $F_k : \{0,1\}^n \to \{0,1\}^n$. Messages are $m = m_1 \| m_2 \in \{0,1\}^{2n}$.

Gen$k \leftarrow \{0,1\}^n$
Enc if $F_k(m_1) = m_2$: output $\langle 1, k \rangle$  (trapdoor: leak the key) else: $r \leftarrow \{0,1\}^n$; output $\langle 0, r, m_1 \oplus F_k(r), m_2 \oplus F_k(r+1) \rangle$
Decas for counter mode; a ciphertext $\langle 1, k \rangle$ decrypts to any fixed message

Normally this is randomised counter mode, which is CPA-secure (Question 20, scheme 4). The trapdoor fires only on a message of the form $x \,\|\, F_k(x)$.

Secure for multiple eavesdropped messages

The adversary chooses all messages $m^{(1)}, m^{(2)}, \dots$ without any information about $k$. A message triggers the trapdoor only if $m_2 = F_k(m_1)$, which means correctly guessing a PRF value. For each message this happens with probability $2^{-n} + \mathsf{negl}(n)$. Over polynomially many messages the probability is still negligible (union bound). Without the trapdoor, the ciphertexts are counter-mode encryptions, which are secure for multiple messages. So the scheme has indistinguishable multiple encryptions.

Not CPA-secure

1.Query the oracle on $0^{2n}$ and receive $\langle 0, r, F_k(r), F_k(r+1) \rangle$. This reveals the pair $(r, F_k(r))$.
2.Query the oracle on $m = r \,\|\, F_k(r)$. The trapdoor fires, and the answer is $\langle 1, k \rangle$.
3.Choose any $m_0 \ne m_1$, decrypt the challenge with $k$, and output the correct $b$.

This attack wins with probability (almost) $1$. It needs the second query to depend on the answer to the first, which is exactly what the eavesdropper game does not allow. $\blacksquare$
