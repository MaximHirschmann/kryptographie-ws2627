Question

Attack these two modifications of DES:

  1. Every round has an independent 32-bit sub-key $k_i$ and the mangler function is just $\hat f(k_i, R) = k_i \oplus R$.
  2. The same 48-bit sub-key is used in all 16 rounds. Distinguish the cipher from a random permutation much faster than a $2^{48}$ key search.

Source: Katz & Lindell, 1st ed., Exercise 5.10 (restated).

(a) XOR mangler: the cipher is affine

Follow the rounds: $L_1 = R_0$, $R_1 = L_0 \oplus R_0 \oplus k_1$; $L_2 = L_0 \oplus R_0 \oplus k_1$, $R_2 = L_0 \oplus k_1 \oplus k_2$; and so on. Every round is XOR-linear in its input plus a key term, and $IP$, $IP^{-1}$ and the swap are bit permutations. So the whole cipher is

$$E_k(x) = M x \oplus K$$

for a public matrix $M$ (independent of the key) and a 64-bit value $K$ that depends only on the sub-keys.

Attack. From one known pair $(x, y)$ compute $K = y \oplus Mx$. Now encrypt or decrypt anything: $x' = M^{-1}(y' \oplus K)$. (Even without a known pair, $E_k(x) \oplus E_k(x') = M(x \oplus x')$ distinguishes it from a random permutation.)

(b) Same sub-key in every round: encryption equals decryption

By Question 70, decryption is DES with the sub-keys in reverse order. With identical sub-keys the order does not matter, so $E_k(E_k(x)) = x$ for every key.

Distinguisher: query $y = O(x)$, then $O(y)$, and output $1$ iff $O(y) = x$. For the modified DES this always holds; for a random permutation only with probability about $2^{-64}$. Two queries suffice. $\blacksquare$
