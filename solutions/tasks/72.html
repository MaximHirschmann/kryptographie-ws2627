Question

Attack these two modifications of DES:

  1. Every round has an independent 32-bit sub-key $k_i$ and the mangler function is just $\hat f(k_i, R) = k_i \oplus R$.
  2. The same 48-bit sub-key is used in all 16 rounds. Distinguish the cipher from a random permutation much faster than a $2^{48}$ key search.

Source: Katz & Lindell, 1st ed., Exercise 5.10 (restated).

(a) XOR mangler: the whole cipher is affine

One round is $L_i = R_{i-1}$, $R_i = L_{i-1} \oplus R_{i-1} \oplus k_i$. In matrix form over $\mathrm{GF}(2)$, with $I$ the $32 \times 32$ identity:

$$\begin{pmatrix} L_i \\ R_i \end{pmatrix} = \underbrace{\begin{pmatrix} 0 & I \\ I & I \end{pmatrix}}_{A} \begin{pmatrix} L_{i-1} \\ R_{i-1} \end{pmatrix} \oplus \begin{pmatrix} 0 \\ k_i \end{pmatrix}.$$

Composing 16 affine maps (and the fixed bit permutations $IP$, $IP^{-1}$ and the swap, which are linear) gives an affine map

$$E_k(x) = M x \oplus K,$$

where $M$ is a public invertible $64 \times 64$ matrix (it does not depend on the key) and $K \in \{0,1\}^{64}$ depends only on the sub-keys.

Attack with one known plaintext.

1.Given one pair $(x, y = E_k(x))$, compute $K = y \oplus Mx$.
2.Decrypt any ciphertext $y'$ as $x' = M^{-1}(y' \oplus K)$, and encrypt anything as $Mx \oplus K$.

We never learn the individual $k_i$ (many sub-key sequences give the same $K$), but we do not need them: $K$ is an equivalent key. Total cost: a few matrix–vector products. Without any known plaintext, $E_k(x) \oplus E_k(x') = M(x \oplus x')$ distinguishes the cipher from a random permutation with two queries.

(b) Same sub-key in every round: an involution

By Question 70, decryption is the same procedure with the sub-keys in reverse order. If all 16 sub-keys are the same $\hat k$, the reversed order is identical, so for every key

$$E_{\hat k}^{-1} = E_{\hat k}, \qquad \text{i.e. } E_{\hat k}(E_{\hat k}(x)) = x.$$

This is the weak-key property of Question 71, now for all keys.

$D^{O}$:pick any $x$, query $y = O(x)$, then query $O(y)$; output $1$ iff $O(y) = x$.

Against the modified DES, $D$ outputs $1$ with probability $1$. Against a random permutation $\pi$ of $\{0,1\}^{64}$: if $y \ne x$, the value $\pi(y)$ is uniform over the $2^{64} - 1$ values other than $\pi(x) = y$, so it equals $x$ with probability $\frac{1}{2^{64}-1}$; and $y = x$ happens with probability $2^{-64}$. The advantage is $\approx 1$ with two queries and constant time.

Result. (a) With a linear mangler the cipher is affine, $E(x) = Mx \oplus K$: one known pair gives an equivalent key. (b) With identical sub-keys every key is a weak key: $E(E(x)) = x$ distinguishes with two queries. The non-linear S-boxes and the changing sub-keys are both essential. $\blacksquare$
