Question

Which of the definitions below properly define perfect secrecy?

Definition: An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every message $m, m_0, m_1 \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$:

  1. $\Pr[M = m \mid C = c] = \Pr[M = m]$ for $c \in \mathcal{C}$ s.t. $\Pr[C = c] \gt 0$
  2. $\Pr[C = c \mid M = m] = \Pr[C = c]$
  3. $\Pr[C = c \mid M = m_0] = \Pr[C = c \mid M = m_1]$
Answer. All three, because they are equivalent: they are Definitions 3, 4 and 5 of the script. (In 2 and 3 we read the conditional probabilities for $\Pr[M = m] \gt 0$.)

$1 \Leftrightarrow 2$: Bayes

For $\Pr[C = c] \gt 0$ and $\Pr[M = m] \gt 0$,

$$\Pr[M = m \mid C = c] = \frac{\Pr[C = c \mid M = m] \cdot \Pr[M = m]}{\Pr[C = c]},$$

so $\Pr[M = m \mid C = c] = \Pr[M = m]$ holds iff $\Pr[C = c \mid M = m] = \Pr[C = c]$. If $\Pr[C = c] = 0$, then $\Pr[C = c \mid M = m] = 0 = \Pr[C = c]$ as well, so 2 holds there trivially.

$2 \Leftrightarrow 3$

$2 \Rightarrow 3$: both sides equal $\Pr[C = c]$. $3 \Rightarrow 2$: if $p := \Pr[C = c \mid M = m]$ is the same for all $m$, then $\Pr[C = c] = \sum_m p \cdot \Pr[M = m] = p$. $\blacksquare$
