Question

Which of the definitions below properly define perfect secrecy?

Definition: An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every message $m, m_0, m_1 \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$:

  1. $\Pr[M = m \mid C = c] = \Pr[M = m]$ for $c \in \mathcal{C}$ s.t. $\Pr[C = c] \gt 0$
  2. $\Pr[C = c \mid M = m] = \Pr[C = c]$
  3. $\Pr[C = c \mid M = m_0] = \Pr[C = c \mid M = m_1]$
Answer. All three properly define perfect secrecy, because they are equivalent. They are Definitions 3, 4 and 5 of the script.
  1. The ciphertext gives no information about the message: the posterior equals the prior.
  2. The ciphertext distribution does not depend on which message was sent.
  3. Any two messages give the same ciphertext distribution.

In 2 and 3 we condition on $M = m$, so we read them for messages with $\Pr[M = m] \gt 0$. In general, $\Pr[C = c \mid M = m]$ means $\Pr[\mathsf{Enc}_K(m) = c]$. That value does not depend on the distribution of $M$, because $K$ is independent of $M$. Question 14 shows that messages with probability $0$ do not matter.

Proof that $1 \Rightarrow 2$

This direction is left as an exercise in the script. Fix a distribution, a message $m$ with $\Pr[M = m] \gt 0$, and a ciphertext $c$.

Case $\Pr[C = c] \gt 0$. By Bayes' theorem and then 1:

$$\Pr[C = c \mid M = m] = \frac{\Pr[M = m \mid C = c] \cdot \Pr[C = c]}{\Pr[M = m]} \overset{(1)}{=} \frac{\Pr[M = m] \cdot \Pr[C = c]}{\Pr[M = m]} = \Pr[C = c].$$

Case $\Pr[C = c] = 0$. Then

$$\Pr[C = c \mid M = m] = \frac{\Pr[C = c \wedge M = m]}{\Pr[M = m]} \le \frac{\Pr[C = c]}{\Pr[M = m]} = 0 = \Pr[C = c].$$

Proof that $2 \Rightarrow 1$

Script Theorem 2. For $\Pr[C = c] \gt 0$, use Bayes' theorem in the other direction:

$$\Pr[M = m \mid C = c] = \frac{\Pr[C = c \mid M = m] \cdot \Pr[M = m]}{\Pr[C = c]} \overset{(2)}{=} \frac{\Pr[C = c] \cdot \Pr[M = m]}{\Pr[C = c]} = \Pr[M = m].$$

If $\Pr[M = m] = 0$, both sides are $0$.

Proof that $2 \Leftrightarrow 3$

Script Theorem 3.

$2 \Rightarrow 3$: $\Pr[C = c \mid M = m_0] = \Pr[C = c] = \Pr[C = c \mid M = m_1]$.

$3 \Rightarrow 2$: By 3, $p := \Pr[C = c \mid M = m]$ is the same for every $m$. By the law of total probability,

$$\Pr[C = c] = \sum_{m \in \mathcal{M}} \Pr[C = c \mid M = m] \cdot \Pr[M = m] = p \cdot \sum_{m \in \mathcal{M}} \Pr[M = m] = p = \Pr[C = c \mid M = m].$$

Why the condition $\Pr[C = c] \gt 0$ appears only in 1

Definition 1 conditions on $C = c$, which is undefined if $\Pr[C = c] = 0$. Definitions 2 and 3 condition on $M = m$ instead. For them, a ciphertext with $\Pr[C = c] = 0$ is no problem: both sides are simply $0$.

In practice, Definition 3 is usually the easiest one to check, because it does not involve the distribution of $M$ at all. The script uses it, for example, to prove that the one-time pad is perfectly secret (Theorem 5).
