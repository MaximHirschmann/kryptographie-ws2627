Question

Let $N = pq$ for distinct primes $p, q$. Show that from $N$ and an integer $d$ with $3d \equiv 1 \pmod{\phi(N)}$ one can compute $p$ and $q$ in polynomial time. (This is the RSA private exponent for $e = 3$.)

Source: Katz & Lindell, 1st ed., Exercise 7.14 (restated). Hint: obtain a short list of candidates for $\phi(N)$, then use Question 41.

Step 1: few candidates for $\phi(N)$

$3d \equiv 1 \pmod{\phi(N)}$ means $3d - 1 = t \cdot \phi(N)$ for an integer $t \ge 1$ (since $3d - 1 \gt 0$).

As an RSA exponent, $d$ is reduced: $0 \lt d \lt \phi(N)$. Then

$$t = \frac{3d - 1}{\phi(N)} \lt \frac{3\phi(N)}{\phi(N)} = 3, \qquad \text{so } t \in \{1, 2\}.$$

The candidates are $\phi(N) \in \{\,3d - 1,\ (3d-1)/2\,\}$ (the second only if $3d - 1$ is even).

If we only know $0 \lt d \lt N$: since $p, q \ge 2$ are distinct, $\phi(N)/N = (1 - \frac1p)(1 - \frac1q) \ge \frac12 \cdot \frac23 = \frac13$. Then $t \lt 3N/\phi(N) \le 9$, so at most 8 candidates $t \in \{1, \dots, 8\}$. Still constant.

Step 2: factor with each candidate (as in Question 41)

For a candidate value $\varphi$:

1.$S := N - \varphi + 1$. If $\varphi = \phi(N)$, then $S = p + q$, because $\phi(N) = N - p - q + 1$.
2.$p$ and $q$ are the roots of $X^2 - SX + N = 0$. Compute $\Delta := S^2 - 4N$ and check that $\Delta \ge 0$ is a perfect square (integer square root by binary search or Newton's method).
3.Set $p' = (S + \sqrt\Delta)/2$, $q' = (S - \sqrt\Delta)/2$. If $p' q' = N$ and $1 \lt q' \lt p'$, output $(p', q')$.

Correctness. For the right candidate, $X^2 - (p+q)X + pq = (X - p)(X - q)$, so the roots are $p$ and $q$. A wrong candidate either fails a check, or still produces integers with $p'q' = N$ and $1 \lt q' \lt p'$; since $N = pq$ has only one such factorization, that output is correct too.

Running time. At most 2 (or 8) candidates, each needing a constant number of arithmetic operations on $O(\log N)$-bit numbers plus an integer square root. That is polynomial in $\log N$.

Result. $3d - 1$ is a small multiple of $\phi(N)$, so $\phi(N)$ is one of a constant number of candidates. From $\phi(N)$ and $N$, the factors are the roots of $X^2 - (N - \phi(N) + 1)X + N$. Knowing the private exponent $d$ is as good as knowing the factorization. $\blacksquare$

This generalizes to every $e$: $ed - 1$ is a multiple of $\phi(N)$, and a randomized algorithm factors $N$ from any multiple of $\phi(N)$. So one must never reuse a modulus $N$ with different key pairs.
