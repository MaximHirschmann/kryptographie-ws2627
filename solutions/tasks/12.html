Question

In this exercise, we study the conditions under which the shift, mono-alphabetic substitution, and Vigenère ciphers are perfectly secret:

  1. Prove that if only a single character is encrypted, then the shift cipher is perfectly secret.
  2. What is the largest plaintext space $\mathcal{M}$ you can find for which the mono-alphabetic substitution cipher provides perfect secrecy? (Note: $\mathcal{M}$ need not contain only valid English words.)
  3. Show how to use the Vigenère cipher to encrypt any word of length $t$ so that perfect secrecy is obtained (note: you can choose the length of the key). Prove your answer.

Reconcile this with the attacks that were shown in the previous chapter.

Main tool: Shannon's theorem (script Theorem 7). If $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}|$, the scheme is perfectly secret iff (1) every key is chosen with probability $\frac{1}{|\mathcal{K}|}$ and (2) for every $m, c$ there is exactly one key $k$ with $c = \mathsf{Enc}_k(m)$. Letters are $\Sigma = \{0, \dots, 25\}$.

1. Shift cipher on a single character

$\mathcal{M} = \mathcal{K} = \mathcal{C} = \Sigma$, keys are uniform, and for every $m, c$ the only key with $c = m + k \bmod 26$ is $k = c - m \bmod 26$. By Shannon's theorem the scheme is perfectly secret. $\blacksquare$

2. Largest $\mathcal{M}$ for the substitution cipher

Answer. $\mathcal{M}$ = all permutations of the alphabet, i.e. all words of length $26$ in which every letter appears exactly once. Then $|\mathcal{M}| = 26!$.

It works. Encrypting such a word gives another such word, so $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}| = 26!$. For given $m$ and $c$, the condition $\pi(m_i) = c_i$ for all $i$ fixes $\pi$ on every letter, so exactly one key maps $m$ to $c$. Keys are uniform, so Shannon's theorem applies.

It is the largest. $|\mathcal{K}| = 26!$, and every perfectly secret scheme has $|\mathcal{M}| \le |\mathcal{K}|$ (script Theorem 6). $\blacksquare$

3. Vigenère for words of length $t$

Choose the key length equal to the message length $t$, with uniform key letters, and use the key once. Then $\mathcal{M} = \mathcal{K} = \mathcal{C} = \Sigma^t$, all $26^t$ keys are equally likely, and for given $m, c$ the only key is $k_i = c_i - m_i \bmod 26$. By Shannon's theorem the scheme is perfectly secret. It is the one-time pad over $\Sigma$. $\blacksquare$

Reconciling with the attacks

The attacks from the previous chapter (frequency analysis, Kasiski, known/chosen plaintext) all need longer plaintexts under the same key: repeated letters, a repeating key period, or a key that is used again. Here every key is used for a single, short message, so there is nothing to exploit.
