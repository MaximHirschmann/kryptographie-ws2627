Question

In this exercise, we study the conditions under which the shift, mono-alphabetic substitution, and Vigenère ciphers are perfectly secret:

  1. Prove that if only a single character is encrypted, then the shift cipher is perfectly secret.
  2. What is the largest plaintext space $\mathcal{M}$ you can find for which the mono-alphabetic substitution cipher provides perfect secrecy? (Note: $\mathcal{M}$ need not contain only valid English words.)
  3. Show how to use the Vigenère cipher to encrypt any word of length $t$ so that perfect secrecy is obtained (note: you can choose the length of the key). Prove your answer.

Reconcile this with the attacks that were shown in the previous chapter.

Main tool: Shannon's theorem (script Theorem 7). If $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}|$, the scheme is perfectly secret if and only if (1) $\mathsf{Gen}$ chooses every key with probability $\frac{1}{|\mathcal{K}|}$, and (2) for every $m, c$ there is exactly one key $k$ with $c = \mathsf{Enc}_k(m)$. Notation as in Question 1, with $\Sigma = \{0, \dots, 25\}$.

1. Shift cipher on a single character

Here $\mathcal{M} = \mathcal{K} = \mathcal{C} = \Sigma$, so $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}| = 26$, and $\mathsf{Gen}$ chooses $k$ uniformly.

For every $m, c \in \Sigma$ there is exactly one key with $c = m + k \bmod 26$, namely $k = c - m \bmod 26$. By Shannon's theorem the shift cipher is perfectly secret.

Directly (script Definition 5): $K$ is independent of $M$, so

$$\Pr[C = c \mid M = m] = \Pr[K = c - m \bmod 26] = \tfrac{1}{26},$$

which is the same for every $m$. $\blacksquare$

2. Largest $\mathcal{M}$ for the substitution cipher

Answer. $\mathcal{M} = $ all words of length $26$ in which every letter appears exactly once, i.e. all arrangements of the alphabet. Then $|\mathcal{M}| = 26!$. The words of length $25$ with distinct letters work equally well and also give $26!$ messages.

No larger $\mathcal{M}$ is possible

The key space is the set of permutations of $\Sigma$, so $|\mathcal{K}| = 26!$. Every perfectly secret scheme has $|\mathcal{M}| \le |\mathcal{K}|$ (script Theorem 6). Hence $|\mathcal{M}| \le 26!$.

This $\mathcal{M}$ works

Here $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}| = 26!$, because the encryption of such a word is again a word containing every letter once. Keys are chosen uniformly. For any $m = m_0 \cdots m_{25}$ and $c = c_0 \cdots c_{25}$ in $\mathcal{M}$, the condition $\pi(m_i) = c_i$ for all $i$ defines $\pi$ on every letter exactly once. So there is exactly one key with $c = \mathsf{Enc}_\pi(m)$. By Shannon's theorem the scheme is perfectly secret. $\blacksquare$

Why repeated letters are a problem

The substitution cipher keeps the pattern of equal letters. If $\mathcal{M}$ contains $\texttt{aa}$ and $\texttt{ab}$, then $c = \texttt{XX}$ shows that $m \ne \texttt{ab}$. In general $\mathcal{M}$ may only contain words with the same length and the same pattern of repeated letters. Words of length $n$ with all letters different give $\frac{26!}{(26-n)!}$ messages:

$$\Pr[C = c \mid M = m] = \frac{\#\{\pi : \pi(m_i) = c_i \ \forall i\}}{26!} = \frac{(26 - n)!}{26!},$$

which is the same for all such $m$ and $c$. The count is largest for $n = 25$ or $n = 26$.

The single letters, $\mathcal{M} = \Sigma$ ($n = 1$), also work, with $\Pr[C = c \mid M = m] = \frac{25!}{26!} = \frac{1}{26}$, but that space is much smaller.

3. Vigenère for words of length $t$

Choose the key length equal to the message length $t$ and choose each key letter uniformly. Use the key only once. Then $\mathcal{M} = \mathcal{K} = \mathcal{C} = \Sigma^t$ and $c_i = m_i + k_i \bmod 26$ for $i = 0, \dots, t-1$.

Claim. Vigenère with a uniform key of length $t$ is perfectly secret on $\mathcal{M} = \Sigma^t$.

Proof. $|\mathcal{M}| = |\mathcal{K}| = |\mathcal{C}| = 26^t$, and $\mathsf{Gen}$ picks each of the $26^t$ keys with probability $26^{-t}$. For given $m, c$, the only key with $c = \mathsf{Enc}_k(m)$ is $k_i = c_i - m_i \bmod 26$ for all $i$. By Shannon's theorem the scheme is perfectly secret. Directly:

$$\Pr[C = c \mid M = m] = \prod_{i=0}^{t-1} \Pr[K_i = c_i - m_i] = 26^{-t}. \qquad \blacksquare$$

This is the one-time pad over the alphabet $\Sigma$ instead of bits, with addition mod 26 instead of XOR.

Reconciling with the attacks

The attacks on these ciphers (frequency analysis, Kasiski, index of coincidence, and the known- and chosen-plaintext attacks of Questions 3–5) all rely on reusing the key:

  • The shift cipher was attacked on long texts in which every letter uses the same key. With one letter there is nothing to compare.
  • The substitution cipher was broken through the frequencies of repeated letters and bigrams. If $\mathcal{M}$ contains no repeated letters, there are no frequencies to exploit.
  • Vigenère was broken because the key is shorter than the text and repeats, so every $t$-th letter shares a shift. If the key is as long as the message and used once, there is no period and each column has a single letter.
  • Known- and chosen-plaintext attacks reveal the key, but a key that is never used again protects nothing. Perfect secrecy is about one ciphertext.

Perfect secrecy is only possible if $|\mathcal{K}| \ge |\mathcal{M}|$ (script Theorem 6). The attacks work exactly when this fails: long messages with short keys.
