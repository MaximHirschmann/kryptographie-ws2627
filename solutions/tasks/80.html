Question

Prove formally: if the DDH problem is hard relative to $\mathcal{G}$, then the CDH problem is hard relative to $\mathcal{G}$.

Source: Katz & Lindell, 1st ed., Exercise 7.16 (restated). Compare Question 42 (CDH ⇒ DL).

Definitions

$\mathcal{G}(1^n)$ outputs a cyclic group $\mathbb{G}$ of order $q$ (with $\|q\| = n$) and a generator $g$.

CDH is hard if for every PPT $\mathcal{A}$:

$$\Pr\big[\mathcal{A}(\mathbb{G}, q, g, g^x, g^y) = g^{xy}\big] \le \mathsf{negl}(n), \quad x, y \leftarrow \mathbb{Z}_q.$$

DDH is hard if for every PPT $D$:

$$\Big|\Pr[D(\mathbb{G}, q, g, g^x, g^y, g^{xy}) = 1] - \Pr[D(\mathbb{G}, q, g, g^x, g^y, g^z) = 1]\Big| \le \mathsf{negl}(n), \quad x, y, z \leftarrow \mathbb{Z}_q.$$

Proof (contrapositive)

Assume CDH is not hard: some PPT $\mathcal{A}$ computes $g^{xy}$ with non-negligible probability $\varepsilon(n)$. Build a DDH distinguisher:

$D(\mathbb{G}, q, g, h_1, h_2, h_3)$:
1.Run $h := \mathcal{A}(\mathbb{G}, q, g, h_1, h_2)$.
2.Output $1$ iff $h = h_3$.

Real triple ($h_3 = g^{xy}$): $\mathcal{A}$'s input is distributed exactly as in the CDH experiment, so

$$\Pr[D = 1] = \Pr[\mathcal{A} \text{ outputs } g^{xy}] = \varepsilon(n).$$

Random triple ($h_3 = g^z$): $z$ is independent of $\mathcal{A}$'s input $(g^x, g^y)$, so $h_3$ is a uniform group element independent of $\mathcal{A}$'s output $h$:

$$\Pr[D = 1] = \Pr[h = g^z] = \frac{1}{q}.$$

The advantage is

$$\varepsilon(n) - \frac1q \;\ge\; \varepsilon(n) - 2^{-(n-1)},$$

which is non-negligible because $\varepsilon$ is non-negligible and $2^{-(n-1)}$ is negligible. $D$ runs in polynomial time (one call to $\mathcal{A}$ and one comparison). So DDH is not hard either. $\blacksquare$

Result. DDH hard ⇒ CDH hard: whoever can compute $g^{xy}$ can check whether a given third element equals it. Together with Question 42: DDH hard ⇒ CDH hard ⇒ DL hard. $\blacksquare$

The converse is false in general: in $\mathbb{Z}_p^*$, DDH is easy (the Legendre symbol reveals whether $g^{xy}$ is a square), although CDH is believed to be hard there. That is why ElGamal uses prime-order subgroups.
