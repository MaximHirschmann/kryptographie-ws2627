Question

Present formulas for decryption of the ECB, CBC, OFB, and CTR modes of encryption. For which modes can decryption be parallelized?

Write the $i$-th plaintext block as $m_i$, the $i$-th ciphertext block as $c_i$, and write $F_k$ and $F_k^{-1}$ as the encryption and decryption function given key $k$.

Hint: The presentation may be simplified by writing the $IV$ as $c_0$ or as a helper variable $b_0$ where appropriate.

ModeEncryptionDecryptionParallel decryption?
ECB$c_i = F_k(m_i)$$m_i = F_k^{-1}(c_i)$yes
CBC$c_0 = IV$, $c_i = F_k(c_{i-1} \oplus m_i)$$m_i = F_k^{-1}(c_i) \oplus c_{i-1}$yes (all $c_{i-1}$ are known)
OFB$b_0 = IV$, $b_i = F_k(b_{i-1})$, $c_i = m_i \oplus b_i$$b_0 = c_0$, $b_i = F_k(b_{i-1})$, $m_i = c_i \oplus b_i$no ($b_i$ needs $b_{i-1}$, but can be precomputed)
CTR$c_0 = ctr$, $c_i = m_i \oplus F_k(ctr + i)$$m_i = c_i \oplus F_k(c_0 + i)$yes (random access too)

ECB and CBC need $F_k^{-1}$, so $F$ must be a permutation; OFB and CTR only use $F_k$ forwards.
