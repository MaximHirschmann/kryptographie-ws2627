Question

Present formulas for decryption of the ECB, CBC, OFB, and CTR modes of encryption. For which modes can decryption be parallelized?

Write the $i$-th plaintext block as $m_i$, the $i$-th ciphertext block as $c_i$, and write $F_k$ and $F_k^{-1}$ as the encryption and decryption function given key $k$.

Hint: The presentation may be simplified by writing the $IV$ as $c_0$ or as a helper variable $b_0$ where appropriate.

ModeEncryptionDecryptionParallel decryption?
ECB$c_i = F_k(m_i)$$m_i = F_k^{-1}(c_i)$yes
CBC$c_0 = IV$, $c_i = F_k(c_{i-1} \oplus m_i)$$m_i = F_k^{-1}(c_i) \oplus c_{i-1}$yes
OFB$b_0 = IV$, $b_i = F_k(b_{i-1})$, $c_i = m_i \oplus b_i$$b_0 = c_0 = IV$, $b_i = F_k(b_{i-1})$, $m_i = c_i \oplus b_i$no (but the $b_i$ can be precomputed)
CTR$c_0 = ctr$, $c_i = m_i \oplus F_k(ctr + i)$$m_i = c_i \oplus F_k(c_0 + i)$yes

Explanation

  • ECB: each block is processed independently.
  • CBC: encryption is sequential, because $c_i$ depends on $c_{i-1}$. For decryption, all $c_{i-1}$ are already known from the ciphertext, so every $m_i = F_k^{-1}(c_i) \oplus c_{i-1}$ can be computed independently.
  • OFB: the key stream $b_i = F_k^{(i)}(IV)$ is a chain, and $b_i$ needs $b_{i-1}$. So it cannot be parallelised. However, the stream does not depend on the ciphertext, so it can be computed in advance, before the ciphertext arrives.
  • CTR: every pad $F_k(ctr + i)$ depends only on $ctr$ and $i$. Fully parallel, and blocks can be decrypted in any order (random access).

ECB and CBC need $F_k^{-1}$, so $F$ must be a permutation (block cipher). OFB and CTR only ever evaluate $F_k$ in the forward direction, so a pseudorandom function is enough.
