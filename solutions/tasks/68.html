Question

Give formal definitions of second pre-image resistance and pre-image resistance for a hash function $(\mathsf{Gen}, H)$. Prove that collision resistance implies second pre-image resistance, and that second pre-image resistance implies pre-image resistance.

Source: Katz & Lindell, 1st ed., Exercise 4.10 (restated).

Setting

$\mathsf{Gen}(1^n)$ outputs a key $s$. $H^s$ maps inputs of length $\ell'(n)$ to outputs of length $\ell(n) \lt \ell'(n)$. (For variable-length hash functions, fix one input length $\ell'(n)$.) For the second implication the function must compress a lot: $\ell'(n) - \ell(n) \ge n$ suffices, and anything $\omega(\log n)$ also works.

Definitions

Collision resistance (from the lecture): no PPT $\mathcal{A}$ given $s$ outputs $x \ne x'$ with $H^s(x) = H^s(x')$, except with negligible probability.

Second pre-image experiment $\mathsf{Hash\text{-}2pre}_{\mathcal{A},H}(n)$: $s \leftarrow \mathsf{Gen}(1^n)$, $x \leftarrow \{0,1\}^{\ell'(n)}$ uniform; $\mathcal{A}(s, x)$ outputs $x'$; the output is $1$ iff $x' \ne x$ and $H^s(x') = H^s(x)$.

Pre-image experiment $\mathsf{Hash\text{-}pre}_{\mathcal{A},H}(n)$: $s \leftarrow \mathsf{Gen}(1^n)$, $x \leftarrow \{0,1\}^{\ell'(n)}$ uniform, $y := H^s(x)$; $\mathcal{A}(s, y)$ outputs $x'$; the output is $1$ iff $H^s(x') = y$.

$H$ is second pre-image resistant (pre-image resistant) if every PPT $\mathcal{A}$ wins the respective experiment with only negligible probability.

In the pre-image experiment $y$ is the hash of a random input, not a uniformly random string, because a uniform $y$ might have no pre-image at all.

Collision resistant ⇒ second pre-image resistant

Let $\mathcal{A}_2$ attack second pre-images. Build $\mathcal{A}_{\mathsf{coll}}(s)$: choose $x \leftarrow \{0,1\}^{\ell'(n)}$, run $x' \leftarrow \mathcal{A}_2(s, x)$, and output $(x, x')$.

$\mathcal{A}_2$ sees exactly the distribution of its experiment. Whenever it wins, $x \ne x'$ and $H^s(x) = H^s(x')$, which is a collision. So

$$\Pr[\mathsf{Hash\text{-}coll}_{\mathcal{A}_{\mathsf{coll}},H} = 1] = \Pr[\mathsf{Hash\text{-}2pre}_{\mathcal{A}_2,H} = 1],$$

and the right-hand side is negligible because the left-hand side is. $\blacksquare$

Second pre-image resistant ⇒ pre-image resistant

Let $\mathcal{A}_{\mathsf{pre}}$ find pre-images with probability $\varepsilon(n)$. Build $\mathcal{A}_2(s, x)$: compute $y := H^s(x)$, run $x' \leftarrow \mathcal{A}_{\mathsf{pre}}(s, y)$, and output $x'$.

$\mathcal{A}_{\mathsf{pre}}$ gets $(s, H^s(x))$ for uniform $x$, exactly as in its experiment, so $H^s(x') = H^s(x)$ with probability $\varepsilon$. $\mathcal{A}_2$ wins unless $x' = x$. We must show that $\Pr[x' = x]$ is negligible.

Bounding $\Pr[x' = x]$. $\mathcal{A}_{\mathsf{pre}}$ only sees $y$. Given $y$, the input $x$ is uniform over the pre-image set $H^{-1}(y)$, so $\Pr[x' = x \mid y] \le 1/|H^{-1}(y)|$. Call $x$ lonely if its pre-image set has at most $T$ elements. There are at most $2^{\ell}$ outputs, each with at most $T$ lonely pre-images, so

$$\Pr_x[x \text{ lonely}] \le \frac{T \cdot 2^{\ell}}{2^{\ell'}}, \qquad \Pr[x' = x] \le \frac{T \cdot 2^{\ell}}{2^{\ell'}} + \frac{1}{T}.$$

Choose $T = 2^{(\ell' - \ell)/2}$: then $\Pr[x' = x] \le 2 \cdot 2^{-(\ell' - \ell)/2} \le 2 \cdot 2^{-n/2}$, which is negligible.

$$\Pr[\mathsf{Hash\text{-}2pre}_{\mathcal{A}_2,H} = 1] \ge \varepsilon(n) - 2 \cdot 2^{-n/2}.$$

If $H$ is second pre-image resistant, the left side is negligible, so $\varepsilon$ is negligible. $\blacksquare$

Result. Collision resistance ⇒ second pre-image resistance ⇒ pre-image resistance. The first step is direct. The second needs enough compression, so that a found pre-image is almost never the original input. $\blacksquare$

Why compression is needed: the identity function $H^s(x) = x$ is trivially second pre-image resistant (there is no second pre-image), but not pre-image resistant.
