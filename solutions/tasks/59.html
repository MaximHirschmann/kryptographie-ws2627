Question

Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be a scheme with indistinguishable encryptions in the presence of an eavesdropper (Definition 3.8), where $\mathsf{Enc}_k$ for $k \in \{0,1\}^n$ only accepts messages of length at most $\ell(n)$ for a polynomial $\ell$. Construct a scheme that satisfies Definition 3.8 even if the adversary in $\mathsf{PrivK}^{\mathsf{eav}}$ may output two messages of different lengths.

Source: Katz & Lindell, 1st ed., Exercise 3.4 (restated). This is the positive counterpart of Question 26.

Idea

Question 26 shows that hiding the length is impossible for messages of unbounded length. Here the message length is bounded by a polynomial, so we can pad every message to the same length before encrypting. Then all ciphertexts encrypt equally long strings and the length leaks nothing.

Construction

The new message space is all strings of length at most $\ell(n) - 1$. Padding has to be reversible, so append a $1$ and then zeros:

$$\mathsf{pad}(m) = m \,\|\, 1 \,\|\, 0^{\ell(n) - |m| - 1}, \qquad |\mathsf{pad}(m)| = \ell(n).$$
Gen'$k \leftarrow \mathsf{Gen}(1^n)$
Enc'$\mathsf{Enc}'_k(m) = \mathsf{Enc}_k(\mathsf{pad}(m))$ for $|m| \le \ell(n) - 1$
Dec'$\hat m := \mathsf{Dec}_k(c)$; remove all trailing zeros and then the last $1$; output the rest

Correctness. $\mathsf{pad}(m)$ ends with $1\,0^j$, so the last $1$ marks exactly where $m$ ends.

Security proof

Claim. If $\Pi$ satisfies Definition 3.8, then $\Pi'$ satisfies Definition 3.8 even for adversaries that output messages of different lengths.

Let $\mathcal{A}'$ be any PPT adversary against $\Pi'$ (messages of arbitrary lengths up to $\ell(n)-1$). Build $\mathcal{A}$ against $\Pi$:

1.Run $\mathcal{A}'(1^n)$ and get $m_0, m_1$.
2.Output $\mathsf{pad}(m_0), \mathsf{pad}(m_1)$. Both have length exactly $\ell(n)$, so this is a legal pair for $\Pi$.
3.Receive $c \leftarrow \mathsf{Enc}_k(\mathsf{pad}(m_b))$, give $c$ to $\mathcal{A}'$, and output whatever $\mathcal{A}'$ outputs.

$c$ is distributed exactly like $\mathsf{Enc}'_k(m_b)$, so $\mathcal{A}'$'s view is the same as in $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A}',\Pi'}$ and

$$\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A}',\Pi'}(n) = 1] = \Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] \le \tfrac12 + \mathsf{negl}(n).$$

$\mathcal{A}$ runs in polynomial time because padding takes $O(\ell(n))$ steps. $\blacksquare$

Result. Pad every message to the fixed length $\ell(n)$ (with $1\,0^*$ so it can be removed) and encrypt with $\Pi$. Since all padded messages have the same length, the restriction to equal-length messages disappears. This costs one bit of message length. $\blacksquare$

The price is efficiency: a 1-bit message produces a ciphertext as long as one for an $\ell(n)$-bit message. This is unavoidable if lengths must be hidden.
