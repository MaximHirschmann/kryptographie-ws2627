Question

In DES, the two halves are swapped after the last Feistel round: if round 16 ends with $(L_{16}, R_{16})$, the cipher outputs $(R_{16}, L_{16})$. Show that, because of this swap, $\mathsf{DES}_k^{-1}$ is computed by exactly the same procedure as $\mathsf{DES}_k$, only with the sub-keys in reverse order.

Source: Katz & Lindell, 1st ed., Exercise 5.8 (restated).

Setting

Encryption with sub-keys $k_1, \dots, k_{16}$ and mangler $f$ (initial and final permutation for now ignored):

$$L_i = R_{i-1}, \qquad R_i = L_{i-1} \oplus f(k_i, R_{i-1}) \quad (i = 1, \dots, 16), \qquad \text{output } (R_{16}, L_{16}).$$

Claim. Running the same procedure on input $(R_{16}, L_{16})$ with sub-keys $k_{16}, k_{15}, \dots, k_1$ outputs $(L_0, R_0)$.

Proof by induction

Call the values of the second run $(L'_j, R'_j)$, with $(L'_0, R'_0) = (R_{16}, L_{16})$; round $j$ uses $k_{17-j}$.

Invariant. $(L'_j, R'_j) = (R_{16-j},\, L_{16-j})$ for $j = 0, \dots, 16$.

$j = 0$: by definition.

$j \to j+1$: let $i = 16 - j$, so by assumption $(L'_j, R'_j) = (R_i, L_i)$, and round $j+1$ uses $k_i$.

$$L'_{j+1} = R'_j = L_i = R_{i-1},$$ $$R'_{j+1} = L'_j \oplus f(k_i, R'_j) = R_i \oplus f(k_i, L_i) = \big(L_{i-1} \oplus f(k_i, R_{i-1})\big) \oplus f(k_i, R_{i-1}) = L_{i-1},$$

using $L_i = R_{i-1}$ and the definition of $R_i$. So $(L'_{j+1}, R'_{j+1}) = (R_{i-1}, L_{i-1}) = (R_{16-(j+1)}, L_{16-(j+1)})$. ✓

For $j = 16$: $(L'_{16}, R'_{16}) = (R_0, L_0)$. The final swap outputs $(L_0, R_0)$, the original input. $\blacksquare$

Initial and final permutation

DES computes $(L_0, R_0) = IP(x)$ and outputs $y = IP^{-1}(R_{16} \| L_{16})$. Running DES on $y$ starts with $IP(y) = (R_{16}, L_{16})$, runs the rounds with reversed keys to get $(L_0, R_0)$ after the swap, and ends with $IP^{-1}(L_0 \| R_0) = x$. So the permutations do not change the statement.

Result. Thanks to the final swap, $\mathsf{DES}^{-1}_k$ equals $\mathsf{DES}$ with the sub-key order $k_{16}, \dots, k_1$. One circuit can do both encryption and decryption, and $f$ never has to be inverted. $\blacksquare$

This is used in Question 71: if all sub-keys are equal, reversing their order changes nothing, so $\mathsf{DES}_k^{-1} = \mathsf{DES}_k$.
