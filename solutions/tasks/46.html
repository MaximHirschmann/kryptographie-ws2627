Question

Formally define the key-exchange experiment $\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n)$ and its security in the presence of an eavesdropper.

Experiment $\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n)$

1.The parties run $\Pi(1^n)$; this gives the transcript $\mathsf{trans}$ (all messages sent) and the key $k \in \{0,1\}^n$.
2.$b \leftarrow \{0,1\}$; $k_0 \leftarrow \{0,1\}^n$ uniformly; $k_1 := k$.
3.$b' \leftarrow \mathcal{A}(\mathsf{trans}, k_b)$.
4.Output $1$ iff $b' = b$.

Security

Definition. $\Pi$ is secure in the presence of an eavesdropper if for every PPT $\mathcal{A}$ there is a negligible $\mathsf{negl}$ with $$\Pr\big[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1\big] \le \tfrac12 + \mathsf{negl}(n).$$

The key must be indistinguishable from random, not merely hard to compute; only then can it be used in a private-key scheme.
