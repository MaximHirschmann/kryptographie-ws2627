Question

Let $F$ be a pseudorandom function and $k \in \{0,1\}^n$ the shared key. Show that each of these MACs is insecure:

  1. For $m = m_1 \cdots m_\ell$ with $m_i \in \{0,1\}^n$: $t := F_k(m_1) \oplus \cdots \oplus F_k(m_\ell)$.
  2. Same blocks, but choose $r \leftarrow \{0,1\}^n$, set $t := F_k(r) \oplus F_k(m_1) \oplus \cdots \oplus F_k(m_\ell)$ and send $\langle r, t \rangle$.
  3. Blocks $m_i \in \{0,1\}^{n/2}$; choose $r \leftarrow \{0,1\}^n$, set $t := F_k(r) \oplus F_k(\langle 1 \rangle \| m_1) \oplus \cdots \oplus F_k(\langle \ell \rangle \| m_\ell)$, where $\langle i \rangle$ is the $n/2$-bit encoding of $i$, and send $\langle r, t \rangle$.

Source: Katz & Lindell, 1st ed., Exercise 4.4 (restated).

All three tags are XORs of PRF values, and a PRF input that appears twice cancels: $F_k(x) \oplus F_k(x) = 0^n$. So the forger chooses inputs that cancel and outputs the tag $0^n$, with no oracle query at all.

(a)

Output the message $x \| x$ with tag $0^n$: $\mathsf{Mac}_k(x \| x) = F_k(x) \oplus F_k(x) = 0^n$.

(b)

The forger may choose $r$ itself. Output the one-block message $x$ with $\langle r, t \rangle = \langle x, 0^n \rangle$: $F_k(x) \oplus F_k(x) = 0^n$.

(c)

$r$ and $\langle 1 \rangle \| m_1$ are both $n$-bit strings, so they can coincide. Output the one-block message $x \in \{0,1\}^{n/2}$ with $r := \langle 1 \rangle \| x$ and $t := 0^n$: $F_k(\langle 1 \rangle \| x) \oplus F_k(\langle 1 \rangle \| x) = 0^n$.

Each forgery is valid with probability $1$. $\blacksquare$
