Question

Let $F$ be a pseudorandom function and $k \in \{0,1\}^n$ the shared key. Show that each of these MACs is insecure:

  1. For $m = m_1 \cdots m_\ell$ with $m_i \in \{0,1\}^n$: $t := F_k(m_1) \oplus \cdots \oplus F_k(m_\ell)$.
  2. Same blocks, but choose $r \leftarrow \{0,1\}^n$, set $t := F_k(r) \oplus F_k(m_1) \oplus \cdots \oplus F_k(m_\ell)$ and send $\langle r, t \rangle$.
  3. Blocks $m_i \in \{0,1\}^{n/2}$; choose $r \leftarrow \{0,1\}^n$, set $t := F_k(r) \oplus F_k(\langle 1 \rangle \| m_1) \oplus \cdots \oplus F_k(\langle \ell \rangle \| m_\ell)$, where $\langle i \rangle$ is the $n/2$-bit encoding of $i$, and send $\langle r, t \rangle$.

Source: Katz & Lindell, 1st ed., Exercise 4.4 (restated).

Common idea

All three tags are XORs of PRF values. If the same PRF input appears twice in the sum, the two terms cancel: $F_k(x) \oplus F_k(x) = 0^n$. The adversary picks inputs so that every term cancels and the valid tag is $0^n$, without knowing $k$ and without any oracle query. Each forgery is valid with probability $1$, so each MAC is broken.

(a)

Output the message $m^* = x \| x$ for any block $x$, with tag $t^* = 0^n$:

$$\mathsf{Mac}_k(x \| x) = F_k(x) \oplus F_k(x) = 0^n.$$

Other attacks: XOR is commutative, so after querying $m_1 \| m_2$ the same tag is valid for $m_2 \| m_1$. Also, the tags of $x\|y$, $x$ and $y$ satisfy $t_{xy} = t_x \oplus t_y$.

(b)

The random $r$ is chosen by the sender, but the forger may put any $r$ into its forgery. Output the one-block message $m^* = x$ with $\langle r^*, t^* \rangle = \langle x, 0^n \rangle$:

$$F_k(r^*) \oplus F_k(m_1) = F_k(x) \oplus F_k(x) = 0^n.$$

(c)

The counters $\langle i \rangle$ prevent repeated block terms, but the term $F_k(r)$ is not separated from the block terms: $r$ is an $n$-bit string and so is $\langle i \rangle \| m_i$. Output the one-block message $m^* = x$ (with $x \in \{0,1\}^{n/2}$) and

$$r^* := \langle 1 \rangle \| x, \qquad t^* := 0^n.$$ $$\text{Verification: } F_k(r^*) \oplus F_k(\langle 1 \rangle \| x) = F_k(\langle 1 \rangle \| x) \oplus F_k(\langle 1 \rangle \| x) = 0^n. \checkmark$$
Result. All three MACs allow a forgery with tag $0^n$ and no queries: (a) $x \| x$; (b) message $x$ with $r = x$; (c) message $x$ with $r = \langle 1\rangle \| x$. $\blacksquare$

Construction (c) is almost the XOR-MAC of Bellare, Guérin and Rogaway. Their version is secure because it uses domain separation: $F_k(0 \| r) \oplus \bigoplus_i F_k(1 \| \langle i \rangle \| m_i)$. With the extra prefix bit, the nonce term can never equal a block term. The general lesson: when you combine PRF values, make sure different roles use disjoint input sets.
