Question

Show that the shift, substitution, and Vigenère ciphers are all trivial to break using a chosen-plaintext attack. How much plaintext must be encrypted in order for the adversary to completely recover the key? Compare to the amount of plaintext necessary for a known-plaintext attack.

Attack model

In a chosen-plaintext attack, the attacker chooses messages $m$ and receives $c = \mathsf{Enc}_k(m)$. This is at least as strong as a known-plaintext attack (Question 3), because the attacker can pick a plaintext that reveals the key as fast as possible. Letters are numbers, $\texttt{a} = 0, \texttt{b} = 1, \dots, \texttt{z} = 25$.

Shift cipher

Ask for the encryption of $m = \texttt{a}$. Then $c = 0 + k$, so the ciphertext is the key:

$$k = c_0.$$
Needed: 1 letter.

Mono-alphabetic substitution cipher

Ask for the encryption of the alphabet $m = \texttt{abc}\cdots\texttt{y}$. Then $c_x = \pi_k(x)$, so the ciphertext is the permutation written out:

$$\pi_k = (c_0, c_1, \dots, c_{24}, \text{the one letter still missing}).$$
Needed: 25 letters (or all 26, to read the last value directly).

Vigenère cipher

Ask for the encryption of $m = \texttt{aa}\cdots\texttt{a}$. Then $c_x = 0 + k_{x \bmod t}$, so the ciphertext is the key repeated:

$$c = k_0 k_1 \cdots k_{t-1} k_0 k_1 \cdots$$
Needed: $t$ letters if the key length $t$ is known. If $t$ is unknown, ask for a longer string of $\texttt{a}$s. The smallest period of the ciphertext is $t$, and it becomes visible after about $2t$ letters.

Comparison with the known-plaintext attack

CipherChosen plaintextKnown plaintext (Q3)
Shift1 letter: $\texttt{a}$1 letter
Substitution25 letters: $\texttt{abc}\cdots\texttt{y}$any text containing 25 different letters; can be much longer
Vigenère$t$ letters: $\texttt{a}^t$ ($\approx 2t$ if $t$ unknown)$t$ letters ($\approx 2t$ if $t$ unknown)

For the shift and Vigenère ciphers, any letter reveals one key letter, so choosing the plaintext saves nothing: both attacks need the same amount of text. The difference shows up for the substitution cipher. With a known plaintext the attacker has to wait until rare letters such as q, x or z appear. With a chosen plaintext they ask for each letter exactly once, so 25 letters always suffice.

Choosing $\texttt{a} = 0$ just makes the ciphertext equal to the key. Any other known plaintext would also work, because $k = c - m$.
