Question

Let $F$ be a pseudorandom permutation. Construct a keyed permutation $F'$ that is still a pseudorandom permutation, but not a strong pseudorandom permutation (where the distinguisher may also query the inverse).

Source: Katz & Lindell, 1st ed., Exercise 3.13 (restated). Hint from the book: arrange that $F'_k(k) = 0^{|k|}$.

Construction

Let $x^* := F_k^{-1}(0^n)$, the input that $F_k$ maps to $0^n$. Swap the outputs of $k$ and $x^*$:

$$F'_k(x) = \begin{cases} 0^n & \text{if } x = k,\\ F_k(k) & \text{if } x = x^*,\\ F_k(x) & \text{otherwise.} \end{cases}$$

(If $x^* = k$, then $F'_k = F_k$ already satisfies $F'_k(k) = 0^n$.) Swapping two outputs keeps $F'_k$ a permutation. Both $F'_k$ and its inverse are efficiently computable given $k$, because $F_k^{-1}$ is.

Part 1: $F'$ is not a strong PRP

$D^{O, O^{-1}}(1^n)$:
1.Query the inverse oracle: $\hat k := O^{-1}(0^n)$.
2.Pick some $x \notin \{\hat k\}$, query $y := O(x)$.
3.Output $1$ iff $y = F'_{\hat k}(x)$ (computed locally).

With $O = F'_k$: $O^{-1}(0^n) = k$, so $\hat k = k$ and the check always succeeds: probability $1$. With a random permutation $f$: $\hat k$ is just some value and $f(x)$ is uniform over the $2^n - 1$ values different from $f(\hat k) = 0^n$, so the check succeeds with probability at most $\frac{1}{2^n - 1}$. The advantage is $\approx 1$.

Part 2: $F'$ is still a PRP

Let $D'$ be a PPT distinguisher with a forward oracle only, making $q = q(n)$ queries. $F'_k$ and $F_k$ differ only on the two inputs $k$ and $x^*$. Let $\mathsf{Bad}$ be the event that $D'$, run with oracle $F_k$, queries $k$ or $x^*$. Until $\mathsf{Bad}$ happens the two oracles answer identically, so

$$\big|\Pr[D'^{F'_k} = 1] - \Pr[D'^{F_k} = 1]\big| \le \Pr[\mathsf{Bad}].$$

$\Pr[\mathsf{Bad}]$ is negligible

Build $D''$ against $F$:

1.Run $D'$, answering its queries with the own oracle $O$; let $x_1, \dots, x_q$ be the queries.
2.Query one more point $z \notin \{x_1, \dots, x_q\}$ and get $O(z)$.
3.Output $1$ iff some $O(x_i) = 0^n$ or some $x_i$ satisfies $F_{x_i}(z) = O(z)$.
  • $O = F_k$: if $D'$ queries $x^*$, then $O(x^*) = 0^n$; if $D'$ queries $k$, then $F_k(z) = O(z)$. So $\Pr[D''^{F_k} = 1] \ge \Pr[\mathsf{Bad}]$.
  • $O = f$ random permutation: each answer $f(x_i)$ equals $0^n$ with probability at most $\frac{1}{2^n - q}$. $f(z)$ is uniform over at least $2^n - q$ values independent of $D'$'s view, so it matches one of the $q$ values $F_{x_i}(z)$ with probability at most $\frac{q}{2^n - q}$. In total $\Pr[D''^{f} = 1] \le \frac{2q}{2^n - q}$.

$F$ is a PRP, so $\Pr[D''^{F_k} = 1] \le \Pr[D''^{f} = 1] + \mathsf{negl}(n)$. Hence $\Pr[\mathsf{Bad}] \le \frac{2q}{2^n - q} + \mathsf{negl}(n)$, which is negligible.

Putting it together

$$\big|\Pr[D'^{F'_k} = 1] - \Pr[D'^{f} = 1]\big| \le \Pr[\mathsf{Bad}] + \big|\Pr[D'^{F_k} = 1] - \Pr[D'^{f} = 1]\big| \le \mathsf{negl}(n).$$
Result. $F'$ (which maps $k$ to $0^n$) is a PRP: without an inverse oracle, finding $k$ or $F_k^{-1}(0^n)$ is as hard as breaking $F$. With an inverse oracle, the single query $O^{-1}(0^n)$ returns the key. $\blacksquare$
