Question

Let $F$ be a pseudorandom permutation. Construct a keyed permutation $F'$ that is still a pseudorandom permutation, but not a strong pseudorandom permutation (where the distinguisher may also query the inverse).

Source: Katz & Lindell, 1st ed., Exercise 3.13 (restated). Hint from the book: arrange that $F'_k(k) = 0^{|k|}$.

Construction

Swap the outputs of $k$ and $F_k^{-1}(0^n)$, so that $F'_k(k) = 0^n$:

$$F'_k(x) = \begin{cases} 0^n & \text{if } x = k,\\ F_k(k) & \text{if } x = F_k^{-1}(0^n),\\ F_k(x) & \text{otherwise.} \end{cases}$$

Swapping two outputs keeps $F'_k$ a permutation, and $F'_k$ and its inverse are efficient given $k$.

Not a strong PRP

Query the inverse oracle on $0^n$ and obtain $\hat k$. Then pick $x \notin \{\hat k, F_{\hat k}^{-1}(0^n)\}$, query $y = O(x)$, and output $1$ iff $y = F_{\hat k}(x)$. With $F'_k$ we get $\hat k = k$ and always output $1$; with a random permutation this happens only with probability about $2^{-n}$.

Still a PRP

With forward queries only, $F'_k$ and $F_k$ differ only if the distinguisher queries $k$ or $F_k^{-1}(0^n)$. Finding either point is infeasible: a distinguisher that queries $x^* = F_k^{-1}(0^n)$ sees the answer $0^n$, and one that queries $k$ can check the guess by evaluating $F_k$ itself. Either event would let it tell $F_k$ from a random permutation, contradicting that $F$ is a PRP. So $F'_k \approx F_k \approx$ random permutation. $\blacksquare$
