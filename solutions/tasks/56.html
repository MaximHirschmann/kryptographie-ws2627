Question

Prove the missing direction of Lemma 2.2: if $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ is perfectly secret (Definition 2.1), then for every distribution over $\mathcal{M}$, every $m \in \mathcal{M}$ and every $c \in \mathcal{C}$:

$$\Pr[C = c \mid M = m] = \Pr[C = c].$$

Source: Katz & Lindell, 1st ed., Exercise 2.1 (restated). In the lecture script this is the direction "Def. 1 ⇒ Def. 2" of Theorem 2 whose proof is now included in the script.

Setting

Fix a distribution over $\mathcal{M}$, a message $m$ and a ciphertext $c$. To talk about $\Pr[C = c \mid M = m]$ at all we need $\Pr[M = m] \gt 0$. As in the book's convention for Chapter 2, we assume this.

Case 1: $\Pr[C = c] \gt 0$

Bayes' theorem in both directions gives

$$\Pr[C = c \mid M = m] = \frac{\Pr[M = m \mid C = c] \cdot \Pr[C = c]}{\Pr[M = m]}.$$

By perfect secrecy (Definition 2.1, which applies because $\Pr[C = c] \gt 0$), $\Pr[M = m \mid C = c] = \Pr[M = m]$. Substituting:

$$\Pr[C = c \mid M = m] = \frac{\Pr[M = m] \cdot \Pr[C = c]}{\Pr[M = m]} = \Pr[C = c].$$

Case 2: $\Pr[C = c] = 0$

Then also $\Pr[C = c \wedge M = m] \le \Pr[C = c] = 0$, so

$$\Pr[C = c \mid M = m] = \frac{\Pr[C = c \wedge M = m]}{\Pr[M = m]} = 0 = \Pr[C = c].$$
Result. In both cases $\Pr[C = c \mid M = m] = \Pr[C = c]$. Since the distribution, $m$ and $c$ were arbitrary, the statement holds for all of them. Together with the direction shown in the book, Definition 2.1 and the condition of Lemma 2.2 are equivalent. $\blacksquare$

Case 2 is exactly the place where Definition 2.1 says nothing (it only speaks about $c$ with $\Pr[C = c] \gt 0$), so it has to be handled separately. Compare Question 9 and Question 14.
