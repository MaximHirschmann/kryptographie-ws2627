Question

Consider the following public-key encryption scheme. The public key is $(\mathbb{G}, q, g, h)$ and the private key is $x$, generated exactly as in the ElGamal encryption scheme. In order to encrypt a bit $b$, the sender does the following:

  1. If $b = 0$ then choose a random $y \leftarrow \mathbb{Z}_q$ and compute $c_1 = g^y$ and $c_2 = h^y$. The ciphertext is $\langle c_1, c_2 \rangle$.
  2. If $b = 1$ then choose independent random $y, z \leftarrow \mathbb{Z}_q$, compute $c_1 = g^y$ and $c_2 = g^z$, and set the ciphertext equal to $\langle c_1, c_2 \rangle$.

Show that it is possible to decrypt efficiently given knowledge of $x$. Prove that this encryption scheme is CPA-secure if the decisional Diffie-Hellman problem is hard relative to $\mathcal{G}$.

Hint: Given an adversary $\mathcal{A}$ attacking the encryption scheme $\Pi$, construct an algorithm $\mathcal{A}'$ that solves the DDH problem by using $\mathcal{A}$ as a subroutine. Then, consider the experiment $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n)$.

Decryption

Output $0$ if $c_1^{\,x} = c_2$, otherwise $1$. For $b = 0$, $c_1^x = g^{xy} = h^y = c_2$, so this is always correct. For $b = 1$, $c_1^x = g^{xy}$ equals $c_2 = g^z$ only if $z = xy$, which has negligible probability $\frac1q$. It costs one exponentiation.

CPA security from DDH

For public-key schemes EAV security is CPA security, and the only messages are the bits $0$ and $1$. The key observation: together with $h = g^x$,

  • an encryption of $0$, $\langle g^y, g^{xy} \rangle$, is a DH tuple;
  • an encryption of $1$, $\langle g^y, g^z \rangle$, is a random tuple.

Distinguisher $\mathcal{A}'(\mathbb{G}, q, g, h_1, h_2, h_3)$: run $\mathcal{A}$ on $pk = (\mathbb{G}, q, g, h_1)$, give it the challenge $\langle h_2, h_3 \rangle$, and output $1$ ("DH tuple") iff $\mathcal{A}$ answers $0$. Then $\mathcal{A}$ sees a real encryption of $0$ on DH tuples and of $1$ on random tuples, so

$$\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi} = 1] = \tfrac12 + \tfrac12\big(\Pr[\mathcal{A}'(\text{DH}) = 1] - \Pr[\mathcal{A}'(\text{rand}) = 1]\big) \le \tfrac12 + \mathsf{negl}(n). \qquad \blacksquare$$
