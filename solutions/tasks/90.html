Question

Textbook RSA signatures: $\sigma = [m^d \bmod N]$, valid iff $\sigma^e \equiv m \pmod N$. Decide for each of two weaker security notions whether textbook RSA satisfies it, and prove your answer:

  1. The adversary gets $pk$ and a random message $m$, may ask for one signature on a message $m' \ne m$ of its choice, and must then output a valid signature on $m$.
  2. As (a), but the adversary may not ask for any signature.

Source: Katz & Lindell, 1st ed., Exercise 12.2 (restated).

(a) One signing query: insecure

Use the multiplicative structure (blinding): $(xy)^d = x^d y^d$.

1.Given $(N, e)$ and $m \in \mathbb{Z}_N^*$, choose $r \leftarrow \mathbb{Z}_N^* \setminus \{1\}$ and set $m' := m \cdot r^e \bmod N$.
2.Ask for $\sigma' = (m')^d = m^d \cdot r^{ed} = m^d \cdot r \bmod N$.
3.Output $\sigma := \sigma' \cdot r^{-1} \bmod N = m^d$.

The query is legal: $x \mapsto x^e$ is a permutation of $\mathbb{Z}_N^*$, so $r \ne 1$ gives $r^e \ne 1$ and $m' \ne m$. The output satisfies $\sigma^e = m$, so the forgery always succeeds. (If $\gcd(m, N) \ne 1$, which happens with negligible probability, $\gcd(m, N)$ factors $N$ and signing is easy.) $\blacksquare$

(b) No queries: secure under the RSA assumption

Without queries, the task "given $(N, e)$ and a uniform $m$, find $\sigma$ with $\sigma^e = m$" is the RSA problem.

Proof. Let $\mathcal{A}$ win this experiment with probability $\varepsilon(n)$. Build $\mathcal{I}$ for the RSA experiment, which gets $(N, e, y)$ with $y \leftarrow \mathbb{Z}_N^*$:

$\mathcal{I}(N, e, y)$:give $pk = (N, e)$ and the message $m := y$ to $\mathcal{A}$; output its $\sigma$.

$\mathcal{A}$'s input has exactly the right distribution (assuming the random message is uniform in $\mathbb{Z}_N^*$). Whenever $\mathcal{A}$ wins, $\sigma^e \equiv y$, so

$$\Pr[\mathsf{RSA\text{-}inv}_{\mathcal{I}} = 1] = \varepsilon(n).$$

Under the RSA assumption, $\varepsilon$ is negligible. $\blacksquare$

Result. (a) Insecure: a single blinded query $m r^e$ gives the signature on $m$. (b) Secure if the RSA problem is hard: forging on a random message without help is exactly inverting RSA. $\blacksquare$

Textbook RSA also falls to a "no-message attack" in the standard definition: pick any $\sigma$ and output $(\sigma^e \bmod N, \sigma)$. That works because the forger chooses the message. In (b) the message is random and fixed in advance, which rules this out.
