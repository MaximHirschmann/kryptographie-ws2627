Question

Let $\mathsf{negl}_1$ and $\mathsf{negl}_2$ be negligible functions. Prove that:

  1. The function $\mathsf{negl}_3$ defined by $\mathsf{negl}_3(n) = \mathsf{negl}_1(n) + \mathsf{negl}_2(n)$ is negligible.
  2. For any (positive) polynomial $p$, the function $\mathsf{negl}_4$ defined by $\mathsf{negl}_4(n) = p(n) \cdot \mathsf{negl}_1(n)$ is negligible.
  3. Prove that for all negligible functions $\mathsf{negl}$ with $\forall n \in \mathbb{N} : \mathsf{negl}(n) \ge 0$ it holds that $\lim_{n\to\infty} \mathsf{negl}(n) = 0$.
  4. Prove or refute whether the following functions are negligible: (a) $n^{-\log n}$   (b) $n^{-c}$ for fixed $c \in \mathbb{N}$   (c) $c^{-n}$ for $c \in \mathbb{R}$   (d) $f(n) = c$ for fixed $c \in \mathbb{R}$
Definition (script Def. 9). $f$ is negligible if for every polynomial $p$ there is an $N$ such that $f(n) \lt \frac{1}{p(n)}$ for all $n \gt N$. Below, all polynomials are positive for large $n$, and for functions that can be negative we use $|f(n)|$.

1. Sum

Let $p$ be a polynomial. Apply the definition to the polynomial $2p$:

$$\exists N_1\ \forall n \gt N_1: \mathsf{negl}_1(n) \lt \tfrac{1}{2p(n)}, \qquad \exists N_2\ \forall n \gt N_2: \mathsf{negl}_2(n) \lt \tfrac{1}{2p(n)}.$$

For $n \gt N := \max(N_1, N_2)$: $\mathsf{negl}_3(n) \lt \frac{1}{2p(n)} + \frac{1}{2p(n)} = \frac{1}{p(n)}$. $\blacksquare$

2. Polynomial times negligible

Let $q$ be any polynomial. $p \cdot q$ is again a polynomial, so there is an $N$ with $\mathsf{negl}_1(n) \lt \frac{1}{p(n) q(n)}$ for $n \gt N$. Multiplying by $p(n) \gt 0$:

$$\mathsf{negl}_4(n) = p(n) \cdot \mathsf{negl}_1(n) \lt \frac{1}{q(n)} \quad \text{for all } n \gt N. \qquad \blacksquare$$

Meaning: if an event has negligible probability in one experiment, it still has negligible probability when the experiment is repeated polynomially many times (union bound).

3. Negligible functions tend to 0

Let $\varepsilon \gt 0$. Take the constant polynomial $p(n) := \lceil 1/\varepsilon \rceil$. There is an $N$ such that for all $n \gt N$:

$$0 \le \mathsf{negl}(n) \lt \frac{1}{\lceil 1/\varepsilon \rceil} \le \varepsilon.$$

This is exactly the definition of $\lim_{n \to \infty} \mathsf{negl}(n) = 0$. $\blacksquare$

The converse is false: $\frac1n \to 0$, but $\frac1n$ is not negligible (see 4b).

4. Examples

(a) $n^{-\log n}$: negligible

Let $p$ be a polynomial of degree $d$. Then $p(n) \le n^{d+1}$ for all large $n$. For $n \gt 2^{d+1}$ we have $\log n \gt d + 1$, hence

$$n^{-\log n} \lt n^{-(d+1)} \le \frac{1}{p(n)}.$$

So $n^{-\log n}$ is negligible: it decreases faster than any inverse polynomial.

(b) $n^{-c}$ for fixed $c \in \mathbb{N}$: not negligible

Take the polynomial $p(n) = n^c$. Then $n^{-c} = \frac{1}{p(n)}$ for every $n$, so $n^{-c} \lt \frac{1}{p(n)}$ never holds. (For $c = 0$, $f \equiv 1$, which is not negligible either.)

(c) $c^{-n}$: depends on $c$

  • $|c| \gt 1$: negligible. Write $|c| = e^{a}$ with $a = \ln|c| \gt 0$. For a polynomial $p$ of degree $d$, the series $e^{an} = \sum_j \frac{(an)^j}{j!}$ gives $e^{an} \ge \frac{(an)^{d+1}}{(d+1)!}$, which is greater than $p(n)$ for all large $n$. Hence $|c^{-n}| = e^{-an} \lt \frac{1}{p(n)}$.
  • $|c| = 1$: not negligible, because $|c^{-n}| = 1$.
  • $0 \lt |c| \lt 1$: not negligible, because $|c^{-n}| = |c|^{-n} \to \infty$.
  • $c = 0$: $c^{-n}$ is undefined.

(d) Constant $f(n) = c$

  • $c = 0$: negligible, because $0 \lt \frac{1}{p(n)}$ always.
  • $c \ne 0$: not negligible. Take the constant polynomial $p(n) = \lceil 1/|c| \rceil$. Then $|c| \ge \frac{1}{p(n)}$ for all $n$.

If the definition is applied literally without absolute values ($f(n) \lt \frac{1}{p(n)}$), every $c \le 0$ would count as "negligible". This is why one usually requires $|f(n)| \lt \frac{1}{p(n)}$.
