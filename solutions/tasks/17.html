Question

Let $\mathsf{negl}_1$ and $\mathsf{negl}_2$ be negligible functions. Prove that:

  1. The function $\mathsf{negl}_3$ defined by $\mathsf{negl}_3(n) = \mathsf{negl}_1(n) + \mathsf{negl}_2(n)$ is negligible.
  2. For any (positive) polynomial $p$, the function $\mathsf{negl}_4$ defined by $\mathsf{negl}_4(n) = p(n) \cdot \mathsf{negl}_1(n)$ is negligible.
  3. Prove that for all negligible functions $\mathsf{negl}$ with $\forall n \in \mathbb{N} : \mathsf{negl}(n) \ge 0$ it holds that $\lim_{n\to\infty} \mathsf{negl}(n) = 0$.
  4. Prove or refute whether the following functions are negligible: (a) $n^{-\log n}$   (b) $n^{-c}$ for fixed $c \in \mathbb{N}$   (c) $c^{-n}$ for $c \in \mathbb{R}$   (d) $f(n) = c$ for fixed $c \in \mathbb{R}$

Definition (script Def. 9): $f$ is negligible if for every polynomial $p$ there is an $N$ with $|f(n)| \lt \frac{1}{p(n)}$ for all $n \gt N$.

1. Sum

Given $p$, apply the definition to $2p$: for large $n$, $\mathsf{negl}_1(n), \mathsf{negl}_2(n) \lt \frac{1}{2p(n)}$, so $\mathsf{negl}_3(n) \lt \frac{1}{p(n)}$. $\blacksquare$

2. Polynomial times negligible

Given $q$, apply the definition to the polynomial $p \cdot q$: for large $n$, $\mathsf{negl}_1(n) \lt \frac{1}{p(n)q(n)}$, so $p(n)\,\mathsf{negl}_1(n) \lt \frac{1}{q(n)}$. $\blacksquare$

3. Negligible functions tend to 0

Given $\varepsilon \gt 0$, use the constant polynomial $p := \lceil 1/\varepsilon \rceil$: for large $n$, $0 \le \mathsf{negl}(n) \lt \frac1p \le \varepsilon$. That is $\lim_{n\to\infty} \mathsf{negl}(n) = 0$. (The converse fails: $\frac1n \to 0$ is not negligible.) $\blacksquare$

4. Examples

  • (a) $n^{-\log n}$: negligible. If $\deg p = d$, then $p(n) \le n^{d+1}$ for large $n$, and for $n \gt 2^{d+1}$ we have $\log n \gt d+1$, so $n^{-\log n} \lt n^{-(d+1)} \le \frac{1}{p(n)}$.
  • (b) $n^{-c}$: not negligible. For $p(n) = n^c$, $n^{-c} \lt \frac{1}{p(n)}$ never holds.
  • (c) $c^{-n}$: negligible iff $|c| \gt 1$. Then $|c|^n$ grows faster than every polynomial, so $|c|^{-n} \lt \frac{1}{p(n)}$ eventually. For $|c| = 1$ the value is $1$, for $0 \lt |c| \lt 1$ it grows to $\infty$ ($c = 0$ is undefined).
  • (d) $f(n) = c$: negligible iff $c = 0$. For $c \ne 0$, the constant polynomial $p = \lceil 1/|c| \rceil$ gives $|c| \ge \frac1p$ for all $n$.
