Question

Agree or disagree with the following statement: if a public-key encryption scheme $\Pi$ has indistinguishable encryptions in the presence of an eavesdropper then $\Pi$ also has indistinguishable encryptions under a chosen-plaintext attack. Justify your answer.

Answer. Agree. The adversary knows $pk$, so it can encrypt any message itself; the CPA encryption oracle gives it nothing new.

Justification

Given a CPA adversary $\mathcal{A}$, the EAV adversary $\mathcal{A}'(pk)$ runs $\mathcal{A}(pk)$ and answers every oracle query $m$ by computing $\mathsf{Enc}_{pk}(m)$ itself; it forwards the challenge and outputs $\mathcal{A}$'s guess. The answers have exactly the right distribution, so

$$\Pr[\mathsf{PubK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] = \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A}',\Pi}(n) = 1] \le \tfrac12 + \mathsf{negl}(n). \qquad \blacksquare$$

For private-key schemes this fails: $m \oplus F_k(0^n)$ is EAV- but not CPA-secure (Question 20).
