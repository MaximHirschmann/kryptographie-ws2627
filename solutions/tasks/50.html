Question

Agree or disagree with the following statement: if a public-key encryption scheme $\Pi$ has indistinguishable encryptions in the presence of an eavesdropper then $\Pi$ also has indistinguishable encryptions under a chosen-plaintext attack. Justify your answer.

Answer. Agree. In the public-key setting the adversary knows $pk$, so it can encrypt any message itself. The encryption oracle of the CPA game gives it nothing new.

Justification

Let $\mathcal{A}$ be a PPT adversary in $\mathsf{PubK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}$, with oracle access to $\mathsf{Enc}_{pk}(\cdot)$. Build $\mathcal{A}'$ for $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A}',\Pi}$:

$\mathcal{A}'(pk)$ run $\mathcal{A}(pk)$ whenever $\mathcal{A}$ queries its oracle on $m$: compute $c \leftarrow \mathsf{Enc}_{pk}(m)$ itself and return $c$ forward $\mathcal{A}$'s challenge messages $m_0, m_1$, and the challenge ciphertext back to $\mathcal{A}$ output $\mathcal{A}$'s guess

$\mathsf{Enc}$ is public and PPT, so $\mathcal{A}'$ is PPT. The self-computed answers have exactly the distribution of real oracle answers. So $\mathcal{A}$'s view is identical in both games, and

$$\Pr[\mathsf{PubK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] = \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A}',\Pi}(n) = 1] \le \tfrac12 + \mathsf{negl}(n). \qquad \blacksquare$$

This differs from the private-key setting, where an EAV-secure scheme need not be CPA-secure (e.g. $m \oplus F_k(0^n)$, Question 20). A consequence is that a deterministic public-key scheme, such as textbook RSA, cannot even be EAV-secure: the adversary just encrypts $m_0$ itself and compares.
