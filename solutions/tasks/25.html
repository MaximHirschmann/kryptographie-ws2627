Question
  1. Let $G$ be a deterministic polynomial-time algorithm such that for any input $s \in \{0,1\}^n$, algorithm $G$ outputs a string of length $\ell(n)$. Give a formal definition of the two conditions that must hold for $G$ to be a pseudorandom generator. Hint: use $D$ to denote a PPT distinguisher, and do not forget to specify the lengths of any random values or seed values used in the definition.
  2. Let $G$ be a pseudorandom generator with expansion factor $\ell(n) = 2 \cdot n$. Show that it is trivial to distinguish between a pseudorandom string generated by $G$ and a random string given unlimited time.

1. Definition

$G$ is a pseudorandom generator if

  1. Expansion: $\ell(n) \gt n$ for every $n$, and
  2. Pseudorandomness: for every PPT distinguisher $D$ there is a negligible $\mathsf{negl}$ with $$\Big|\Pr_{r \leftarrow \{0,1\}^{\ell(n)}}[D(r) = 1] - \Pr_{s \leftarrow \{0,1\}^n}[D(G(s)) = 1]\Big| \le \mathsf{negl}(n).$$

2. An unbounded distinguisher

$D(y)$: try every seed $s \in \{0,1\}^n$ and output $1$ iff some $G(s) = y$.

  • For $y = G(s)$, $D$ always outputs $1$.
  • For uniform $y \in \{0,1\}^{2n}$: $G$ has at most $2^n$ outputs, so $\Pr[D(y) = 1] \le 2^n / 2^{2n} = 2^{-n}$.

The advantage is at least $1 - 2^{-n}$. $D$ needs $2^n$ evaluations of $G$, so this does not contradict the definition, which only covers PPT distinguishers. $\blacksquare$
