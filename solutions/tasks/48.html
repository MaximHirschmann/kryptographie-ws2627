Question

The natural way of applying hybrid encryption to the El Gamal encryption scheme is as follows. The public key is $pk = \langle \mathbb{G}, q, g, h \rangle$ as in the El Gamal scheme, and to encrypt a message $m$ the sender chooses random $k \leftarrow \{0,1\}^n$ and sends

$$\langle g^r,\ h^r \cdot k,\ \mathsf{Enc}_k(m) \rangle,$$

where $r \leftarrow \mathbb{Z}_q$ is chosen at random and $\mathsf{Enc}$ represents a private-key encryption scheme. Suggest an improvement that results in a shorter ciphertext containing only a single group element followed by a private-key encryption of m.

Observation

In ElGamal, $h^r = g^{xr}$ is already a fresh Diffie–Hellman value that only the sender and the receiver can compute. There is no need to choose $k$ separately and transport it with $h^r \cdot k$. We can derive the key from $h^r$ directly. This is the key-encapsulation (KEM) approach.

Improved scheme (DHIES / ECIES)

Let $H : \mathbb{G} \to \{0,1\}^n$ be a key-derivation function, e.g. a hash function modelled as a random oracle, or a randomness extractor.

Enc$r \leftarrow \mathbb{Z}_q$;   $k := H(h^r)$;   output $\langle g^r,\ \mathsf{Enc}_k(m) \rangle$
Decinput $x$ and $\langle c_1, c_2 \rangle$:   $k := H(c_1^{\,x})$;   output $\mathsf{Dec}_k(c_2)$

Correctness: $c_1^{\,x} = g^{rx} = (g^x)^r = h^r$, so both sides derive the same $k$.

Shorter: the ciphertext contains one group element $g^r$ instead of two, followed by the private-key encryption.

The lecture uses the same idea in the random-oracle model ("Public-Key Encryption in the RO Model", Mitschrift 16.2): $c_1 := [r^e \bmod N]$, $c_2 := H(r) \oplus m$. The key is derived from the encapsulated value by $H$, and nothing else is transported.

Why it is secure (sketch)

$(g, h = g^x, g^r)$ is a Diffie–Hellman transcript. Under DDH, $h^r$ looks like a uniform group element. $H$ turns it into a (pseudo)random $n$-bit key $k$, either as a random oracle under CDH or as an extractor under DDH. Then the hybrid argument goes through as for Construction 10.12 (Question 49): $\langle g^r, \mathsf{Enc}_k(m) \rangle$ is indistinguishable from $\langle g^r, \mathsf{Enc}_{k'}(m) \rangle$ for an independent uniform $k'$, and the latter hides $m$ by the security of the private-key scheme.

We need $H$: $h^r$ itself is a group element, not a uniform bit string, and its encoding might have structure. The KDF turns it into a uniform symmetric key.
