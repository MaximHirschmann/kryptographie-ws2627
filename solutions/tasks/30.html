Question

Say $\Pi = (\mathsf{Gen}, \mathsf{Mac}, \mathsf{Vrfy})$ is a secure MAC, and for $k \in \{0,1\}^n$ the tag-generation algorithm $\mathsf{Mac}_k$ always outputs tags of length $t(n)$. Prove that $t$ must be super-logarithmic.

Hint: Show $t(n) = \mathcal{O}(\log n) \Rightarrow \Pi$ is not a secure MAC.

Assume $t(n) \le c \log n$ for a constant $c$ (for infinitely many $n$ suffices). We show that $\Pi$ is not secure.

Attack: guess the tag

$\mathcal{A}$ makes no oracle queries. It outputs an arbitrary message $m$ together with a uniform $t \leftarrow \{0,1\}^{t(n)}$.

$m$ was never queried, and by correctness $m$ has at least one valid tag of length $t(n)$. So $\mathcal{A}$ hits a valid tag with probability at least

$$2^{-t(n)} \ \ge\ 2^{-c \log n} = n^{-c},$$

which is not negligible. Hence a secure MAC needs $t(n) = \omega(\log n)$. $\blacksquare$
