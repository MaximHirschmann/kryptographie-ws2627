Question

In an attempt to prevent Kasiski's attack on the Vigenère cipher, the following modification has been proposed. Given the period $t$ of the cipher, the plaintext is broken up into blocks of size $t$. Recall that within each block, the Vigenère cipher works by encrypting the $i$th character with the $i$th key (using a shift cipher). Letting the key be $k_1, \dots, k_t$, this means the $i$th character in each block is encrypted by adding $k_i$ to it, modulo 26. The proposed modification is to encrypt the $i$th character in the $j$th block by adding $k_i + j \bmod 26$.

  1. Show that decryption can be carried out.
  2. Describe the effect of the above modification on Kasiski's attack.
  3. Devise an alternate way to determine the period for this scheme.

Setup

As in Question 1, we count from $0$: the key is $k_0, \dots, k_{t-1}$, and the letter at position $x$ lies in block $j = \lfloor x / t \rfloor$ at place $i = x \bmod t$, so $x = jt + i$. The modified encryption is

$$c_x = m_x + k_{x \bmod t} + \lfloor x / t \rfloor \bmod 26.$$

1. Decryption is possible

The receiver knows the key $k_0, \dots, k_{t-1}$ and the period $t$. For every position $x$ they also know $x$, so they can compute the block number $\lfloor x/t \rfloor$ and the place $x \bmod t$. Therefore:

Dec input $k_0, \dots, k_{t-1}$, $c \in \Sigma^*$ for $x = 0$ to $|c| - 1$ do $m_x := c_x - k_{x \bmod t} - \lfloor x/t \rfloor \bmod 26$ output $m = m_0 \cdots m_{|c|-1}$

Correctness: $\big(m_x + k_{x \bmod t} + \lfloor x/t \rfloor\big) - k_{x \bmod t} - \lfloor x/t \rfloor = m_x \bmod 26$.

2. Effect on Kasiski's attack

Kasiski relies on this: the same plaintext word at the same place in two different blocks gives the same ciphertext. With the modification, the shift used at position $x$ is

$$k'_x := k_{x \bmod t} + \lfloor x/t \rfloor \bmod 26.$$

Take the same word at positions $x$ and $x + d$ with $d = s \cdot t$. Then the two shifts differ by exactly $s$:

$$k'_{x+st} - k'_x = s \bmod 26.$$

So the two copies are encrypted the same way only if $s \equiv 0 \pmod{26}$, that is, only if $d$ is a multiple of $26t$.

Effect. The scheme is really an ordinary Vigenère cipher with the longer key $k'_0, \dots, k'_{26t-1}$ with $26t$ as a period (not necessarily the fundamental period), because $\lfloor (x + 26t)/t \rfloor = \lfloor x/t \rfloor + 26$. Kasiski's attack is not prevented, but:
  • for equal fragments whose starting positions agree modulo $t$, matching ciphertext now requires a distance divisible by $26t$. Accidental repetitions and special keys can produce other distances;
  • Kasiski can suggest $26t$ or a divisor/multiple rather than revealing $t$ directly. Splitting into $26t$ columns leaves fewer samples per column; there is no universal factor-26 bound on the ciphertext required.

3. Another way to find the period

The modification is public; only the key is secret. So for each guess $\tilde t = 1, 2, 3, \dots$ the attacker can undo the block counter and test whether an ordinary Vigenère cipher with period $\tilde t$ remains:

$$c'_x := c_x - \lfloor x / \tilde t \rfloor \bmod 26.$$

If $\tilde t = t$, then $c'_x = m_x + k_{x \bmod t}$. This is a normal Vigenère ciphertext with period $t$, and the index-of-coincidence test from the script recognises it. Split $c'$ into the columns $C_i = \{c'_i, c'_{i+t}, c'_{i+2t}, \dots\}$ and compute the letter frequencies $q_0, \dots, q_{25}$ of each column:

$$S = \sum_{i=0}^{25} q_i^2 \approx \begin{cases} 0.065 & \text{if } \tilde t = t \text{ (each column is an English text shifted by } k_i) \\ \text{variable} & \text{for a wrong guess; mixtures need not be uniform} \end{cases}$$

Use peaks near $0.065$ as candidate periods, then check all columns and the resulting plaintext. The test is statistical, not a guarantee for every key or finite text. For example, $t=3$ and $k=(0,9,18)$ give $k'_x=9x\bmod26$, whose fundamental period is $26$, although $26t=78$ is also a period.

Put another way: inside column $i$, consecutive letters are shifted by $k_i, k_i + 1, k_i + 2, \dots$. Subtracting $0, 1, 2, \dots$ from the column's letters makes the shift constant again. That is exactly what $c'_x$ does.
