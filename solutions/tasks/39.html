Question

Show that DES has the property that $\mathrm{DES}_K(x) = \overline{\mathrm{DES}_{\overline K}(\overline x)}$ for every key $k$ and input $x$ (where $\overline z$ denotes the bitwise complement of $z$). This is called the complementarity property of DES. The illustrations on the sheet show the Feistel structure, the round function (expansion, XOR with the 48-bit subkey, S-boxes 1–8, permutation) and the key schedule (PC-1, left rotations, PC-2).

Fact used: every bit permutation or bit selection $\sigma$ commutes with complementing, $\sigma(\overline z) = \overline{\sigma(z)}$; and $\overline a \oplus \overline b = a \oplus b$.

Step 1: key schedule

PC-1, the rotations and PC-2 only select and move bits, so the key $\overline K$ gives the round keys $\overline{k_1}, \dots, \overline{k_{16}}$.

Step 2: round function

$f(R, k) = P(S(E(R) \oplus k))$ with the bit selection $E$. Since $E(\overline R) \oplus \overline k = E(R) \oplus k$, the S-boxes get the same input, so $f(\overline R, \overline k) = f(R, k)$.

Step 3: rounds

$IP$ is a bit permutation, so the computation on $(\overline x, \overline K)$ starts with $(\overline{L_0}, \overline{R_0})$. If round $i - 1$ ends with $(\overline{L_{i-1}}, \overline{R_{i-1}})$, then round $i$ gives

$$L'_i = \overline{R_{i-1}} = \overline{L_i}, \qquad R'_i = \overline{L_{i-1}} \oplus f(R_{i-1}, k_i) = \overline{R_i}.$$

So every state is complemented. The final swap and $IP^{-1}$ are bit permutations too, hence $\mathrm{DES}_{\overline K}(\overline x) = \overline{\mathrm{DES}_K(x)}$, which is the claim. $\blacksquare$
