Question

Show that DES has the property that $\mathrm{DES}_K(x) = \overline{\mathrm{DES}_{\overline K}(\overline x)}$ for every key $k$ and input $x$ (where $\overline z$ denotes the bitwise complement of $z$). This is called the complementarity property of DES. The illustrations on the sheet show the Feistel structure, the round function (expansion, XOR with the 48-bit subkey, S-boxes 1–8, permutation) and the key schedule (PC-1, left rotations, PC-2).

Two XOR rules

$$\overline a \oplus \overline b = a \oplus b, \qquad \overline a \oplus b = \overline{a \oplus b}.$$

Also, any bit permutation or bit selection $\sigma$ (which may repeat or drop bits) commutes with complementing: $\sigma(\overline z) = \overline{\sigma(z)}$. Each output bit is just some input bit, and that bit gets flipped.

Step 1: Key schedule

PC-1, the left rotations and PC-2 are all bit selections or permutations. So complementing the key complements every round key:

$$K \mapsto \overline K \quad \Longrightarrow \quad k_i \mapsto \overline{k_i} \quad (i = 1, \dots, 16).$$

Step 2: Round function

$f(R, k) = P\big(S(E(R) \oplus k)\big)$, with $E$ the expansion (a bit selection) and $P$ a permutation. Then

$$E(\overline R) \oplus \overline k = \overline{E(R)} \oplus \overline k = E(R) \oplus k,$$

so the S-boxes get exactly the same input:

$$f(\overline R, \overline k) = f(R, k).$$

Step 3: Induction over the rounds

The initial permutation $IP$ is a bit permutation, so $IP(\overline x) = \overline{IP(x)}$, and the computation for $(\overline x, \overline K)$ starts with $(\overline{L_0}, \overline{R_0})$. Suppose that after round $i - 1$ it holds $(\overline{L_{i-1}}, \overline{R_{i-1}})$. Then

$$L'_i = \overline{R_{i-1}} = \overline{L_i}, \qquad R'_i = \overline{L_{i-1}} \oplus f(\overline{R_{i-1}}, \overline{k_i}) = \overline{L_{i-1}} \oplus f(R_{i-1}, k_i) = \overline{L_{i-1} \oplus f(R_{i-1}, k_i)} = \overline{R_i}.$$

So every intermediate state is complemented, including the final one. The final swap and $IP^{-1}$ are bit permutations as well, so

$$\mathrm{DES}_{\overline K}(\overline x) = \overline{\mathrm{DES}_K(x)} \quad \Longleftrightarrow \quad \mathrm{DES}_K(x) = \overline{\mathrm{DES}_{\overline K}(\overline x)}. \qquad \blacksquare$$

The only non-linear part, the S-boxes, never sees the complement, because the complements of the key and of the data cancel in the XOR just before it. Question 40 uses this to halve the cost of an exhaustive key search.
