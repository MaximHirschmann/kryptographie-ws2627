Question

Show that basic CBC-MAC is not a secure MAC if it is used for messages of different lengths.

Source: Katz & Lindell, 1st ed., Exercise 4.8 (restated).

Basic CBC-MAC: $t_0 := 0^n$, $t_i := F_k(t_{i-1} \oplus m_i)$, tag $t_\ell$. So the tag of a one-block message $x$ is $F_k(x)$.

Attack

1.Query the one-block message $x$ and get $t = F_k(x)$.
2.Output the two-block message $x \,\|\, (t \oplus x)$ with tag $t$.

Check: $t_1 = F_k(x) = t$ and $t_2 = F_k(t \oplus t \oplus x) = F_k(x) = t$. The message is new (it has two blocks), so the forgery is valid with probability $1$ after one query. $\blacksquare$
