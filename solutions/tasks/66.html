Question

Show that basic CBC-MAC is not a secure MAC if it is used for messages of different lengths.

Source: Katz & Lindell, 1st ed., Exercise 4.8 (restated).

Basic CBC-MAC

For $m = m_1 \cdots m_\ell$ with $n$-bit blocks: $t_0 := 0^n$, $t_i := F_k(t_{i-1} \oplus m_i)$, and the tag is $t := t_\ell$. Because $t_0 = 0^n$, the tag of a one-block message is simply $F_k(m_1)$.

Attack

1.Query the one-block message $x$ and get $t_x = F_k(x)$.
2.Output the two-block message $m^* = x \,\|\, (t_x \oplus x)$ with tag $t^* = t_x$.

Why the forgery is valid

CBC-MAC of $m^*$:

$$t_1 = F_k(x) = t_x, \qquad t_2 = F_k(t_1 \oplus (t_x \oplus x)) = F_k(t_x \oplus t_x \oplus x) = F_k(x) = t_x.$$

So the tag of $m^*$ is $t_x$. The message $m^*$ has two blocks, so it differs from the only queried message $x$. The forgery is valid with probability $1$ after one query. $\blacksquare$

General form

With tags $t$ of $m = m_1 \cdots m_\ell$ and $t'$ of $m' = m'_1 \cdots m'_{\ell'}$, the message

$$m_1 \cdots m_\ell \,\|\, (m'_1 \oplus t) \,\|\, m'_2 \cdots m'_{\ell'}$$

has tag $t'$: after the first $\ell$ blocks the chain value is $t$, and XORing $t$ into the next block "resets" the chain to the start of $m'$.

Result. Basic CBC-MAC with variable lengths is forgeable with one query. That is why the length must be bound into the computation, e.g. by prepending $|m|$ as the first block or by encrypting the last chain value with a second key. $\blacksquare$
