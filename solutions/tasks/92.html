Question

Encoded RSA signatures: keys as in textbook RSA; a public encoding function $\mathsf{enc}$ is fixed, and $\sigma = [\mathsf{enc}(m)^d \bmod N]$.

  1. How is a signature verified?
  2. Why can a good choice of $\mathsf{enc}$ prevent the no-message attack on textbook RSA?
  3. Show that encoded RSA is insecure for $\mathsf{enc}(m) = 0 \| m \| 0^{\ell/10}$, where $\ell = \|N\|$, $|m| = 9\ell/10 - 1$ and $m \ne 0\cdots0$.
  4. Show that it is insecure for $\mathsf{enc}(m) = 0 \| m \| 0 \| m$, where $|m| = (\|N\| - 1)/2$ (roughly) and $m \ne 0\cdots0$.

Source: Katz & Lindell, 1st ed., Exercise 12.4 (restated).

(a) Verification

$$\mathsf{Vrfy}_{(N,e)}(m, \sigma) = 1 \iff \sigma^e \equiv \mathsf{enc}(m) \pmod N.$$

(b) No-message attack

Against textbook RSA, the forger picks any $\sigma$ and outputs the message $m := \sigma^e \bmod N$. With an encoding, the forger needs $\sigma^e \bmod N$ to be a valid encoding $\mathsf{enc}(m)$ of some message. If the image of $\mathsf{enc}$ is a sparse set (e.g. it has a fixed structure such as many zero bits or redundancy), a random $\sigma^e$ lands in it only with negligible probability. For example, if $\mathsf{enc}$ forces 100 fixed bits, the chance is about $2^{-100}$.

Key observation for (c) and (d)

In both cases $\mathsf{enc}$ is multiplication by a constant (as integers):

$$\text{(c)}\ \ \mathsf{enc}(m) = m \cdot 2^{\ell/10}, \qquad \text{(d)}\ \ \mathsf{enc}(m) = m \cdot (2^{|m|+1} + 1),$$

because appending zeros multiplies by a power of two, and $m \| 0 \| m = m \cdot 2^{|m|+1} + m$. Call the constant $C$, so $\mathsf{enc}(m) = C \cdot m$. Then for messages with $m_1 m_2 = m_3 m_4$ (as integers):

$$\mathsf{enc}(m_1)\,\mathsf{enc}(m_2) = C^2 m_1 m_2 = C^2 m_3 m_4 = \mathsf{enc}(m_3)\,\mathsf{enc}(m_4),$$

and since $x \mapsto x^d$ is multiplicative, the same relation holds for the signatures.

(c) and (d): the forgery

Use $2 \cdot 2 = 1 \cdot 4$:

1.Ask for the signatures on $m = 1$ and $m = 2$ (written with the required number of bits; both are non-zero): $\sigma_1 = (C)^d$, $\sigma_2 = (2C)^d$.
2.Output the message $4$ with $\sigma^* := \sigma_2^2 \cdot \sigma_1^{-1} \bmod N$.

Check:

$$(\sigma^*)^e = \frac{\left((2C)^d\right)^{2e}}{(C^d)^e} = \frac{(2C)^2}{C} = 4C = \mathsf{enc}(4) \pmod N.$$

The message $4$ was never queried and $\mathsf{enc}(4)$ is a legal encoding (the integer $4$ easily fits into $|m|$ bits), so this is a valid forgery after two queries. ($\sigma_1$ is invertible modulo $N$ except with negligible probability; otherwise it reveals a factor of $N$.) $\blacksquare$

More generally, any messages with $m_1 m_2 = m_3 m_4$ work: three signatures give the fourth. Since the forger chooses the messages, it can always arrange this.

Result. (a) Check $\sigma^e = \mathsf{enc}(m)$. (b) A sparse image of $\mathsf{enc}$ defeats "pick $\sigma$ first". (c, d) Both encodings are linear ($\mathsf{enc}(m) = Cm$), so RSA's multiplicativity carries over: $\sigma(4) = \sigma(2)^2/\sigma(1)$. Redundancy alone is not enough. The encoding must also destroy the algebraic structure, which a cryptographic hash in hashed RSA (heuristically) does. $\blacksquare$
