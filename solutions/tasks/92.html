Question

Encoded RSA signatures: keys as in textbook RSA; a public encoding function $\mathsf{enc}$ is fixed, and $\sigma = [\mathsf{enc}(m)^d \bmod N]$.

  1. How is a signature verified?
  2. Why can a good choice of $\mathsf{enc}$ prevent the no-message attack on textbook RSA?
  3. Show that encoded RSA is insecure for $\mathsf{enc}(m) = 0 \| m \| 0^{\ell/10}$, where $\ell = \|N\|$, $|m| = 9\ell/10 - 1$ and $m \ne 0\cdots0$.
  4. Show that it is insecure for $\mathsf{enc}(m) = 0 \| m \| 0 \| m$, where $|m| = (\|N\| - 1)/2$ (roughly) and $m \ne 0\cdots0$.

Source: Katz & Lindell, 1st ed., Exercise 12.4 (restated).

(a) Verification

$$\mathsf{Vrfy}_{(N,e)}(m, \sigma) = 1 \iff \sigma^e \equiv \mathsf{enc}(m) \pmod N.$$

(b) No-message attack

The attack picks $\sigma$ first and needs $[\sigma^e \bmod N]$ to be a valid encoding $\mathsf{enc}(m)$. If a uniform element of $\mathbb{Z}_N^*$ lies in the range of $\mathsf{enc}$ only with negligible probability (e.g. because $\mathsf{enc}$ forces many fixed bits), this fails. Both encodings in (c) and (d) have this property.

(c) and (d): both encodings are multiplication by a constant

Appending zeros multiplies by a power of two, and $m \| 0 \| m = m \cdot 2^{|m|+1} + m$. So, as integers,

$$\text{(c)}\ \ \mathsf{enc}(m) = m \cdot 2^{\ell/10}, \qquad \text{(d)}\ \ \mathsf{enc}(m) = m \cdot (2^{|m|+1} + 1),$$

i.e. $\mathsf{enc}(m) = C \cdot m$ for a constant $C$. RSA signatures are multiplicative, so this structure carries over. Use $2 \cdot 2 = 1 \cdot 4$:

1.Ask for the signatures $\sigma_1 = C^d$ on the message $1$ and $\sigma_2 = (2C)^d$ on the message $2$.
2.Output the message $4$ with $\sigma^* := \sigma_2^2 / \sigma_1 \bmod N$.
$$(\sigma^*)^e = \frac{(2C)^2}{C} = 4C = \mathsf{enc}(4) \pmod N.$$

The message $4$ was never queried, so this is a valid forgery. $\blacksquare$

For a small exponent $e$ (so that $2^e$ fits into a message), one query suffices: ask for the signature $\sigma$ on $2^e$; then $\sigma / 2 = C^d$ is the signature on $1$.
