Question

Let $\Pi'$ and $\Pi''$ be two private-key encryption schemes for which it is known that at least one of them is CPA-secure. However, you do not know which are the CPA-secure ones. Construct a CPA-secure encryption scheme $\Pi$, which uses $\Pi', \Pi''$, while not knowing which of the two is CPA-secure. Prove that your $\Pi$ is CPA-secure.

Hint: Generate two plaintext messages from the original plaintext so that knowledge of either one of the parts reveals nothing about the plaintext, but knowledge of both does yield the original plaintext.

It is sufficient to give half the proof, that is, to give a proof assuming that $\Pi'$ is CPA-secure. Note that, to complete the proof, one would have to show also that the construction is CPA-secure if one assumes that $\Pi''$ is CPA-secure.

Construction: secret-share the message

Split $m$ into two XOR shares $r$ and $r \oplus m$. Each share on its own is uniformly random, but together they give $m$. Encrypt one share with each scheme.

Gen$k' \leftarrow \mathsf{Gen}'(1^n)$, $k'' \leftarrow \mathsf{Gen}''(1^n)$; output $k = (k', k'')$
Encinput $k$, $m$:   $r \leftarrow \{0,1\}^{|m|}$;   $c' \leftarrow \mathsf{Enc}'_{k'}(r)$;   $c'' \leftarrow \mathsf{Enc}''_{k''}(r \oplus m)$;   output $\langle c', c'' \rangle$
Decinput $k$, $\langle c', c'' \rangle$:   output $\mathsf{Dec}'_{k'}(c') \oplus \mathsf{Dec}''_{k''}(c'')$

Correctness: $r \oplus (r \oplus m) = m$.

Proof (assuming $\Pi'$ is CPA-secure)

Let $\mathcal{A}$ be a PPT adversary attacking $\Pi$. We build $\mathcal{A}'$ attacking $\Pi'$. $\mathcal{A}'$ has an encryption oracle for $\mathsf{Enc}'_{k'}$ and generates $k'' \leftarrow \mathsf{Gen}''(1^n)$ itself.

OracleWhen $\mathcal{A}$ asks for the encryption of $m$: choose $r \leftarrow \{0,1\}^{|m|}$, get $c' \leftarrow \mathsf{Enc}'_{k'}(r)$ from the own oracle, compute $c'' \leftarrow \mathsf{Enc}''_{k''}(r \oplus m)$ with the own key, and return $\langle c', c'' \rangle$.
ChallengeWhen $\mathcal{A}$ outputs $m_0, m_1$: choose $s \leftarrow \{0,1\}^{|m_0|}$ and output the pair $(s \oplus m_0,\ s \oplus m_1)$ as $\mathcal{A}'$'s own challenge. Receive $c'^* \leftarrow \mathsf{Enc}'_{k'}(s \oplus m_b)$, compute $c''^* \leftarrow \mathsf{Enc}''_{k''}(s)$, and give $\langle c'^*, c''^* \rangle$ to $\mathcal{A}$.
OutputKeep answering queries as above. Output whatever bit $b'$ $\mathcal{A}$ outputs.

The simulation is perfect

  • Oracle answers are real $\Pi$-encryptions.
  • The challenge is a real encryption of $m_b$ with the share $r := s \oplus m_b$. This $r$ is uniform because $s$ is uniform, and $r \oplus m_b = s$, so $c''^*$ encrypts exactly the right second share.
  • $|s \oplus m_0| = |s \oplus m_1|$, so $\mathcal{A}'$'s challenge pair is valid.

Hence $\mathcal{A}$'s view is distributed exactly as in $\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}$ with the same bit $b$, and

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] = \Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A}',\Pi'}(n) = 1] \le \tfrac12 + \mathsf{negl}(n).$$

$\mathcal{A}'$ is PPT, so $\Pi$ is CPA-secure. $\blacksquare$

The other half is symmetric. If $\Pi''$ is CPA-secure, $\mathcal{A}''$ generates $k'$ itself, puts the fresh uniform share $s$ under $\Pi'$, and sends the challenge pair $(s \oplus m_0, s \oplus m_1)$ to its $\Pi''$ challenger. The construction works without knowing which scheme is secure, because one uniformly random share reveals nothing about $m$.

The lecture's version (00_header.pdf, Theorem 1)

The lecture uses the same construction ($\mathsf{Enc}_{k'}(r)$, $\mathsf{Enc}_{k''}(m \oplus r)$ with $r \leftarrow \{0,1\}^n$) and proves the contrapositive with advantage $\epsilon(n) := \big|\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n) = 1] - \frac12\big|$. For Case 1 ($\Pi'$ secure) it argues differently: instead of re-randomising the challenge, $\mathcal{A}'$ asks its challenger to encrypt either the real share or $0^n$.

Ask$k'' \leftarrow \mathsf{Gen}''(1^n)$; $r \leftarrow \{0,1\}^n$; output the pair $(r,\ 0^n)$.
GuessOn $c_1$: $m_0, m_1 \leftarrow \mathcal{A}$; $b \leftarrow \{0,1\}$; $c_2 \leftarrow \mathsf{Enc}''_{k''}(m_b \oplus r)$; $b' \leftarrow \mathcal{A}(c_1, c_2)$; output $0$ iff $b = b'$.
OracleOn $m^i$: $r^i \leftarrow \{0,1\}^n$; $c^i_1 \leftarrow \mathsf{Enc}'(r^i)$ via the own oracle; $c^i_2 \leftarrow \mathsf{Enc}''_{k''}(m^i \oplus r^i)$.

If the challenger encrypted $r$ ($\hat b = 0$), $\mathcal{A}$ sees a real $\Pi$-encryption and wins with probability $\frac12 + \epsilon(n)$. If it encrypted $0^n$ ($\hat b = 1$), $c_1$ says nothing about $r$, so $c_2$ is a one-time pad encryption of $m_b$ and $\mathcal{A}$ wins with probability exactly $\frac12$. Hence

$$\tfrac12 + \mathsf{negl}(n) \ \ge\ \tfrac12\Big(\tfrac12 + \epsilon(n)\Big) + \tfrac12 \cdot \tfrac12 = \tfrac12 + \tfrac12\epsilon(n) \quad\Longrightarrow\quad \epsilon(n) \le 2\,\mathsf{negl}(n).$$

Case 2 ($\Pi''$ secure) in the lecture is the direct re-randomisation: $\mathcal{A}''$ outputs $(m_0 \oplus r, m_1 \oplus r)$ and adds $c_1 \leftarrow \mathsf{Enc}_{k'}(r)$ itself. That is exactly the argument used above, applied to the other scheme. Both styles are valid; the version above simulates perfectly, the lecture's Case 1 uses a hybrid with $0^n$.
