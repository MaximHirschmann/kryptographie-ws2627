Question

Strengthen the MAC security definition so that the adversary gets oracle access to both $\mathsf{Mac}_k(\cdot)$ and $\mathsf{Vrfy}_k(\cdot, \cdot)$.

  1. Give the formal definition and explain which real-world attacks the $\mathsf{Vrfy}$ oracle models.
  2. Show: if $\Pi$ has unique tags, then $\Pi$ satisfies your definition whenever it satisfies the usual definition (Definition 4.2).
  3. Show: without unique tags, $\Pi$ may satisfy Definition 4.2 but not your definition.

Source: Katz & Lindell, 1st ed., Exercise 4.5 (restated).

(a) Definition

$\mathsf{Mac\text{-}forge}^{\mathsf{vrfy}}_{\mathcal{A},\Pi}(n)$: $k \leftarrow \mathsf{Gen}(1^n)$; $\mathcal{A}$ gets oracles $\mathsf{Mac}_k(\cdot)$ and $\mathsf{Vrfy}_k(\cdot,\cdot)$ and outputs $(m, t)$; with $\mathcal{Q}$ the set of $\mathsf{Mac}$ queries, the output is $1$ iff $\mathsf{Vrfy}_k(m, t) = 1$ and $m \notin \mathcal{Q}$. $\Pi$ is secure if this happens with negligible probability for every PPT $\mathcal{A}$.

What it models: an attacker sends forged messages to the receiver and observes whether they are accepted (the receiver acts on them, returns an error, takes longer, or drops the connection).

(b) Unique tags make the $\mathsf{Vrfy}$ oracle useless

With unique tags, $\mathsf{Vrfy}_k(m, t) = 1$ iff $t = \mathsf{Mac}_k(m)$. Every verification query $(m, t)$ falls into one of three cases:

  • $m$ was MAC-queried with answer $t$: the adversary knows the answer is $1$.
  • $m$ was MAC-queried with a different answer: the adversary knows the answer is $0$.
  • $m$ is new: the answer is $1$ only if $(m, t)$ is already a forgery.

So a forger $\mathcal{A}'$ with a $\mathsf{Vrfy}$ oracle (at most $q_v$ queries) gives a forger $\mathcal{A}$ without one: $\mathcal{A}$ guesses $j \leftarrow \{1, \dots, q_v + 1\}$, answers the first two cases itself and every new-message query with $0$, and outputs the $j$-th new-message query (or $\mathcal{A}'$'s final output if $j = q_v + 1$). With probability $\frac{1}{q_v + 1}$ it outputs the first valid forgery, so $\Pr[\mathcal{A}' \text{ wins}] \le (q_v + 1) \cdot \mathsf{negl}(n)$. $\blacksquare$

(c) Without unique tags: a counterexample

From a secure MAC $\Pi$ with key $k \in \{0,1\}^n$, build $\Pi'$ with tags $(t, i, \beta)$:

Mac'$\mathsf{Mac}'_k(m) = (\mathsf{Mac}_k(m), 0, 0)$
Vrfy'accept iff $\mathsf{Vrfy}_k(m, t) = 1$ and ($i = 0$ or $k_i = \beta$)

$\Pi'$ satisfies Definition 4.2: any forgery contains a valid $\Pi$-tag $t$ on a new message. But with a $\mathsf{Vrfy}'$ oracle the attacker gets $(t, 0, 0)$ for some $m$, then asks $\mathsf{Vrfy}'(m, (t, i, 0))$ for $i = 1, \dots, n$; each answer reveals the key bit $k_i$. With the whole key it forges any message. $\blacksquare$
