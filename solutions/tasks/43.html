Question

Determine whether or not the following problem is hard. Let $p$ be prime, and fix $x \in \mathbb{Z}^*_{p-1}$. Given $p$, $x$, and $y := [g^x \bmod p]$ (where $g$ is a random value between $1$ and $p - 1$), find $g$; that is, compute $[y^{1/x} \bmod p]$. If you claim the problem is hard, show a reduction to one of the cryptographic hardness assumptions introduced in class. If you claim the problem is easy, present an algorithm, justify its correctness, and analyze its complexity.

Answer. The problem is easy: $p - 1$ is known, so $x$ can be inverted in the exponent.

Algorithm

1.Compute $d := [x^{-1} \bmod (p - 1)]$ with the extended Euclidean algorithm. It exists because $\gcd(x, p-1) = 1$.
2.Output $[y^d \bmod p]$.

Correctness

$g \in \mathbb{Z}_p^*$, a group of order $p - 1$, so exponents can be reduced modulo $p - 1$:

$$y^d = (g^x)^d = g^{[xd \bmod (p-1)]} = g^1 = g \pmod p.$$

Complexity

Extended Euclid and square-and-multiply both take $\mathcal{O}(n^3)$ bit operations for $n = \|p\|$, so the algorithm runs in polynomial time. $\blacksquare$

Contrast with RSA: there the group order $\varphi(N)$ is secret, which is why $e$-th roots modulo $N$ are hard.
