Question

Determine whether or not the following problem is hard. Let $p$ be prime, and fix $x \in \mathbb{Z}^*_{p-1}$. Given $p$, $x$, and $y := [g^x \bmod p]$ (where $g$ is a random value between $1$ and $p - 1$), find $g$; that is, compute $[y^{1/x} \bmod p]$. If you claim the problem is hard, show a reduction to one of the cryptographic hardness assumptions introduced in class. If you claim the problem is easy, present an algorithm, justify its correctness, and analyze its complexity.

Answer. The problem is easy. Since $x$ is invertible modulo $p - 1 = |\mathbb{Z}_p^*|$, taking $x$-th roots is just exponentiation with $x^{-1} \bmod (p-1)$. It works like RSA decryption when $\varphi$ is known: here $\varphi(p) = p - 1$ is public.

Algorithm

1.Compute $d := x^{-1} \bmod (p - 1)$ with the extended Euclidean algorithm. It exists because $x \in \mathbb{Z}^*_{p-1}$, i.e. $\gcd(x, p-1) = 1$.
2.Output $[y^d \bmod p]$, computed by square-and-multiply.

Correctness

$xd \equiv 1 \pmod{p-1}$, so $xd = 1 + j(p - 1)$ for some integer $j$. Since $1 \le g \le p - 1$, $g \in \mathbb{Z}_p^*$, and Fermat's little theorem (07_number_theory, Corollary 1.22) gives $g^{p-1} \equiv 1 \pmod p$:

$$y^d = g^{xd} = g^{1 + j(p-1)} = g \cdot \big(g^{p-1}\big)^j \equiv g \pmod p.$$

This is the remark after Example 1.28 in 07_number_theory: if $(x, \varphi(n)) = 1$ there is $y$ with $xy \equiv 1 \pmod{\varphi(n)}$, and then $a^{xy} \equiv a \pmod n$. For a prime modulus, $\varphi(p) = p - 1$ is public.

Complexity

Let $n = \|p\|$ be the bit length.

  • Extended Euclid: $\mathcal{O}(n)$ division steps on $n$-bit numbers, so $\mathcal{O}(n^3)$ bit operations (naively; $\mathcal{O}(n^2)$ with care).
  • Modular exponentiation: at most $2n$ modular multiplications of $n$-bit numbers, so $\mathcal{O}(n^3)$ bit operations.

In total $\mathcal{O}(n^3)$, which is polynomial in the input length. So the problem is easy. $\blacksquare$

Contrast with RSA: there, the $e$-th root modulo $N$ is hard because the group order $\varphi(N)$ is secret, and computing it is as hard as factoring (Question 41). Modulo a prime $p$ the group order $p - 1$ is public.
