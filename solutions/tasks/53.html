Question

Let $f$ be a one-way permutation. Consider the following signature scheme $\Pi$ for messages in the set $\{1, \dots, n\}$:

  • To generate keys, choose random $x \leftarrow \{0,1\}^n$ and set $y := f^n(x)$. The public key is $y$ and the private key is $x$.
  • To sign message $i \in \{1, \dots, n\}$, output $f^{n-i}(x)$, where $f^0(x) := x$ by definition.
  • To verify signature $\sigma$ on message $i$ with respect to public key $y$, check whether $y = f^i(\sigma)$.
  1. Show that the above is not a one-time signature scheme. Given a signature on a message $i$, for what messages $j$ can an adversary output a forgery?
  2. Prove that no PPT adversary $\mathcal{A}$ given a signature on $i$ can output a forgery on any message $j \gt i$ except with negligible probability. Define a modified one-time signature experiment $\mathsf{Sig\text{-}forge}'_{\mathcal{A}}(n)$; define security in it (weakly secure); construct an algorithm $\mathcal{D}$ that runs $\mathcal{A}$ as a subroutine in an inversion experiment $\mathsf{Invert}_{\mathcal{A},f}(n)$; use $\mathcal{D}$ to prove that $\Pi$ is weakly secure.
  3. Suggest how to modify $\Pi$ so as to obtain a one-time signature scheme. Hint: Include two values $y, y'$ in the public key. Reason informally why your modification is secure.

The key is the start of a chain $x \to f(x) \to \cdots \to f^n(x) = y$; the signature on $i$ is the element $i$ steps before the end.

1. Forgeries for every $j \lt i$

Applying $f$ is easy, so from $\sigma_i = f^{n-i}(x)$ the attacker computes $\sigma_j := f^{\,i-j}(\sigma_i) = f^{n-j}(x)$, which verifies: $f^j(\sigma_j) = f^n(x) = y$. So a signature on $i$ gives forgeries on every $j \lt i$; the scheme is not one-time secure. (A signature on $n$ is $x$ itself.)

2. No forgeries for $j \gt i$

$\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi}(n)$:
1.$x \leftarrow \{0,1\}^n$, $y := f^n(x)$; $\mathcal{A}$ gets $y$.
2.$\mathcal{A}$ chooses $i$ and receives $\sigma_i := f^{n-i}(x)$.
3.$\mathcal{A}$ outputs $(j, \sigma)$; the output is $1$ iff $j \gt i$ and $f^j(\sigma) = y$.

Weakly secure: $\Pr[\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi}(n) = 1] \le \mathsf{negl}(n)$ for every PPT $\mathcal{A}$.

Inverter $\mathcal{D}$ in $\mathsf{Invert}_{\mathcal{D},f}(n)$, given $y' = f(x')$: put $y'$ into the chain at the position that will be revealed.

1.Guess $i^* \leftarrow \{1, \dots, n\}$, set $y := f^{\,i^*}(y')$ and run $\mathcal{A}(y)$.
2.If $\mathcal{A}$ asks for $i \ne i^*$, abort; otherwise answer $\sigma_{i^*} := y'$.
3.If $\mathcal{A}$ outputs $(j, \sigma)$ with $j \gt i^*$ and $f^j(\sigma) = y$, output $f^{\,j - i^* - 1}(\sigma)$.

Analysis. $f$ is a permutation, so $y'$ is uniform and the simulation is perfect (with the implicit key $x = f^{-(n-i^*)}(y')$); $\mathcal{A}$'s view does not depend on $i^*$, so $i = i^*$ with probability $\frac1n$. A successful forgery gives $f^{\,j-i^*}(\sigma) = y'$ (as $f^{i^*}$ is injective), so the output is a preimage of $y'$. Hence $\Pr[\mathsf{Invert}_{\mathcal{D},f} = 1] \ge \frac1n \Pr[\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi} = 1]$, and the latter is negligible. $\blacksquare$

3. A one-time signature: two chains in opposite directions

Gen$x, x' \leftarrow \{0,1\}^n$; $pk := (f^n(x), f^n(x'))$
Sign$\sigma_i := \big(f^{n-i}(x),\ f^{\,i}(x')\big)$
Vrfycheck $f^i(\sigma) = y$ and $f^{n-i}(\sigma') = y'$

From a signature on $i$, the first chain only yields forgeries for $j \lt i$ and the second only for $j \gt i$. A forgery on $j \ne i$ must satisfy both chains, so it requires inverting $f$ on one of them, which by part 2 succeeds only with negligible probability.
