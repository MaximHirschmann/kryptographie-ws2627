Question

Let $f$ be a one-way permutation. Consider the following signature scheme $\Pi$ for messages in the set $\{1, \dots, n\}$:

  • To generate keys, choose random $x \leftarrow \{0,1\}^n$ and set $y := f^n(x)$. The public key is $y$ and the private key is $x$.
  • To sign message $i \in \{1, \dots, n\}$, output $f^{n-i}(x)$, where $f^0(x) := x$ by definition.
  • To verify signature $\sigma$ on message $i$ with respect to public key $y$, check whether $y = f^i(\sigma)$.
  1. Show that the above is not a one-time signature scheme. Given a signature on a message $i$, for what messages $j$ can an adversary output a forgery?
  2. Prove that no PPT adversary $\mathcal{A}$ given a signature on $i$ can output a forgery on any message $j \gt i$ except with negligible probability. Define a modified one-time signature experiment $\mathsf{Sig\text{-}forge}'_{\mathcal{A}}(n)$; define security in it (weakly secure); construct an algorithm $\mathcal{D}$ that runs $\mathcal{A}$ as a subroutine in an inversion experiment $\mathsf{Invert}_{\mathcal{A},f}(n)$; use $\mathcal{D}$ to prove that $\Pi$ is weakly secure.
  3. Suggest how to modify $\Pi$ so as to obtain a one-time signature scheme. Hint: Include two values $y, y'$ in the public key. Reason informally why your modification is secure.

The signing key sits at the start of a hash chain: $x \to f(x) \to f^2(x) \to \cdots \to f^n(x) = y$. Signing $i$ reveals the element $f^{n-i}(x)$, which is $i$ steps before the end.

1. Forgeries for every $j \lt i$

Given $\sigma_i = f^{n-i}(x)$ and $j \lt i$, the attacker can walk forward along the chain, since $f$ is public and efficient:

$$\sigma_j := f^{\,i-j}(\sigma_i) = f^{\,i-j}\big(f^{n-i}(x)\big) = f^{n-j}(x).$$

This verifies: $f^j(\sigma_j) = f^n(x) = y$. So a single signature on $i$ allows forgeries on every $j \lt i$, and the scheme is not a one-time signature scheme. For example, a signature on $n$, which is $x$ itself, allows signing everything.

2. No forgeries for $j \gt i$

Experiment $\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi}(n)$

1.$x \leftarrow \{0,1\}^n$, $y := f^n(x)$. $\mathcal{A}$ gets $y$.
2.$\mathcal{A}$ chooses one message $i \in \{1, \dots, n\}$ and receives $\sigma_i := f^{n-i}(x)$.
3.$\mathcal{A}$ outputs $(j, \sigma)$.
4.Output $1$ iff $j \gt i$ and $f^j(\sigma) = y$.
Definition (weakly secure). $\Pi$ is weakly secure if for every PPT $\mathcal{A}$: $\Pr[\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi}(n) = 1] \le \mathsf{negl}(n)$.

Inversion experiment $\mathsf{Invert}_{\mathcal{D},f}(n)$

$x' \leftarrow \{0,1\}^n$, $y' := f(x')$. $\mathcal{D}$ gets $y'$ and wins if it outputs $x''$ with $f(x'') = y'$. Since $f$ is one-way, every PPT $\mathcal{D}$ wins with only negligible probability.

The inverter $\mathcal{D}$

Idea: put the challenge $y'$ into the chain at the position that will be revealed as the signature. A forgery further back in the chain then contains a preimage of $y'$.

$\mathcal{D}(y')$ guess $i^* \leftarrow \{1, \dots, n\}$ uniformly $y := f^{\,i^*}(y')$; run $\mathcal{A}(y)$ when $\mathcal{A}$ asks for a signature on $i$: if $i \ne i^*$ abort; else answer $\sigma_{i^*} := y'$ when $\mathcal{A}$ outputs $(j, \sigma)$: if $j \gt i^*$ and $f^j(\sigma) = y$, output $x'' := f^{\,j - i^* - 1}(\sigma)$

Analysis

  • Perfect simulation. $f$ is a permutation, so $y' = f(x')$ is uniform, and $x := f^{-(n-i^*)}(y')$ is a uniform secret key with $f^{n-i^*}(x) = y'$ and $f^n(x) = y$. Thus $y$ and the answer $\sigma_{i^*} = y'$ are distributed exactly as in $\mathsf{Sig\text{-}forge}'$. $\mathcal{A}$'s view does not depend on $i^*$, so $\Pr[i = i^*] = \frac1n$.
  • Forgery yields a preimage. If $j \gt i^*$ and $f^j(\sigma) = y = f^{i^*}(y')$, then, since $f^{i^*}$ is injective, $f^{\,j-i^*}(\sigma) = y'$. Hence $f(x'') = f\big(f^{\,j-i^*-1}(\sigma)\big) = y'$, and $j - i^* - 1 \ge 0$.
  • Efficiency. At most $2n$ evaluations of $f$ plus one run of $\mathcal{A}$, so $\mathcal{D}$ is PPT.
$$\Pr[\mathsf{Invert}_{\mathcal{D},f}(n) = 1] \ \ge\ \frac1n \cdot \Pr[\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi}(n) = 1].$$

The left side is negligible, so $\Pr[\mathsf{Sig\text{-}forge}'_{\mathcal{A},\Pi}(n) = 1] \le n \cdot \mathsf{negl}(n)$, which is negligible (Question 17). So $\Pi$ is weakly secure. $\blacksquare$

3. A real one-time signature: two chains in opposite directions

Use a second chain that runs the other way:

Gen$x, x' \leftarrow \{0,1\}^n$;   $pk := (y, y') = (f^n(x), f^n(x'))$;   $sk := (x, x')$
Sign$\sigma_i := \big(f^{n-i}(x),\ f^{\,i}(x')\big)$
Vrfyaccept $(\sigma, \sigma')$ on $i$ iff $f^i(\sigma) = y$ and $f^{n-i}(\sigma') = y'$

Why it is secure (informally). From one signature on $i$:

  • the first chain only allows forging messages $j \lt i$ (part 1), and forging $j \gt i$ there means inverting $f$ (part 2);
  • the second chain is mirrored: from $f^{i}(x')$ one can compute $f^{j}(x')$ only for $j \gt i$, and going to $j \lt i$ means inverting $f$.

A forgery on any $j \ne i$ must satisfy both chains, so it requires inverting $f$ on one of them. By the reduction from part 2, applied to the chain where $j$ is on the "hard side", this happens with only negligible probability.

This is the idea behind Winternitz one-time signatures. Each message moves "down" one chain and "up" the other, so no message dominates another.
