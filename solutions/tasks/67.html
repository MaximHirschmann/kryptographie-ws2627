Question

Show that these two modifications of CBC-MAC are not secure, even as fixed-length MACs:

  1. A fresh random $t_0 \leftarrow \{0,1\}^n$ is used instead of $0^n$, and the tag is $\langle t_0, t_\ell \rangle$.
  2. All intermediate values $t_1, \dots, t_\ell$ are output, not only $t_\ell$.

Source: Katz & Lindell, 1st ed., Exercise 4.9 (restated).

Throughout, $t_i = F_k(t_{i-1} \oplus m_i)$ for $n$-bit blocks.

(a) Random IV sent along

The verifier takes $t_0$ from the tag, and the first PRF input is $t_0 \oplus m_1$. So $t_0$ and $m_1$ can be changed together.

1.Query any $m = m_1 \| m_2 \cdots m_\ell$ and get $\langle t_0, t \rangle$.
2.For any $\Delta \ne 0^n$, output $(m_1 \oplus \Delta) \| m_2 \cdots m_\ell$ with tag $\langle t_0 \oplus \Delta, t \rangle$.

$(t_0 \oplus \Delta) \oplus (m_1 \oplus \Delta) = t_0 \oplus m_1$, so the chain and $t$ are unchanged. Valid with probability $1$. $\blacksquare$

(b) All intermediate values are output

Take $\ell = 2$ (longer messages work the same way on the first two blocks).

1.Query $m_1 \| m_2$ and get $t_1 = F_k(m_1)$, $t_2 = F_k(t_1 \oplus m_2)$.
2.Output the message $(t_1 \oplus m_2) \,\|\, (t_2 \oplus m_1)$ with tag $(t_2, t_1)$.

Check: the first chain value is $F_k(t_1 \oplus m_2) = t_2$, the second is $F_k(t_2 \oplus t_2 \oplus m_1) = F_k(m_1) = t_1$. The message is new unless $t_1 \oplus m_2 = m_1$ and $t_2 \oplus m_1 = m_2$, which happens only with negligible probability. So one query gives a forgery. $\blacksquare$
