Question

Show that these two modifications of CBC-MAC are not secure, even as fixed-length MACs:

  1. A fresh random $t_0 \leftarrow \{0,1\}^n$ is used instead of $0^n$, and the tag is $\langle t_0, t_\ell \rangle$.
  2. All intermediate values $t_1, \dots, t_\ell$ are output, not only $t_\ell$.

Source: Katz & Lindell, 1st ed., Exercise 4.9 (restated).

Throughout, messages have a fixed number $\ell$ of $n$-bit blocks, $t_i = F_k(t_{i-1} \oplus m_i)$.

(a) Random IV

The first PRF input is $t_0 \oplus m_1$. The verifier takes $t_0$ from the tag, so the forger can change $t_0$ and $m_1$ together without changing that input.

1.Query any message $m = m_1 \| m_2 \cdots m_\ell$ and get $\langle t_0, t \rangle$.
2.Pick any $\Delta \ne 0^n$ and output $m^* = (m_1 \oplus \Delta) \| m_2 \cdots m_\ell$ with tag $\langle t_0 \oplus \Delta, t \rangle$.

Check: $(t_0 \oplus \Delta) \oplus (m_1 \oplus \Delta) = t_0 \oplus m_1$, so all chain values and the final $t$ are unchanged. $m^* \ne m$ because $\Delta \ne 0^n$. Valid with probability $1$, already for $\ell = 1$. $\blacksquare$

(b) Output all blocks

Now every intermediate value $t_i = F_k(\cdot)$ is visible. In particular, the first output value of any query is $F_k$ of its first block. So the adversary can evaluate $F_k$ at points of its choice and build the chain itself. Let $\ell \ge 2$.

1.Query $m = x \| y \| m_3 \cdots m_\ell$ and get $t_1 = F_k(x)$ (and more).
2.Choose $y^* \ne y$. Query $m' = (t_1 \oplus y^*) \| m_3 \| \cdots \| m_\ell \| z$ where $z$ differs from the last block of the intended forgery $m^*$, and get $(s_1, \dots, s_\ell)$.
3.Output $m^* = x \| y^* \| m_3 \cdots m_\ell$ with tag $(t_1, s_1, s_2, \dots, s_{\ell-1})$.

Check: the chain of $m^*$ is $F_k(x) = t_1$, then $F_k(t_1 \oplus y^*) = s_1$, and from there on it processes $m_3, \dots, m_\ell$ starting from chain value $s_1$, exactly like the chain of $m'$. So its values are $s_2, \dots, s_{\ell-1}$. $m^* \ne m$ because $y^* \ne y$, and $m^* \ne m'$ because their last blocks differ by the choice of $z$. Valid with probability $1$ after two queries. $\blacksquare$

For $\ell = 1$, variant (b) is just $\mathsf{Mac}_k(m) = F_k(m)$ and therefore secure. The attack needs at least two blocks.

Result. (a) A random IV that is sent along lets the forger shift $t_0$ and $m_1$ by the same $\Delta$. (b) Revealing intermediate values turns the MAC into an $F_k$-oracle, so the forger can compute the chain for a new message. CBC-MAC is only secure with a fixed IV $0^n$ and only the last value as the tag. $\blacksquare$
