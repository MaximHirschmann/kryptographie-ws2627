Question

Prove or refute: For every encryption scheme that is perfectly secret it holds that for every distribution over the message space $\mathcal{M}$, every $m, m' \in \mathcal{M}$, and every $c \in \mathcal{C}$:

$$\Pr[M = m \mid C = c] = \Pr[M = m' \mid C = c].$$
Answer. False. Perfect secrecy says that the ciphertext does not change the probability of a message. It does not say that all messages are equally likely.

Why it fails

By perfect secrecy (Definition 2.1), for every $c$ with $\Pr[C = c] \gt 0$:

$$\Pr[M = m \mid C = c] = \Pr[M = m] \quad \text{and} \quad \Pr[M = m' \mid C = c] = \Pr[M = m'].$$

So the claim would require $\Pr[M = m] = \Pr[M = m']$ for every distribution. That holds only for the uniform distribution.

The statement mixes this up with the script's Definition 5, $\Pr[C = c \mid M = m_0] = \Pr[C = c \mid M = m_1]$, which is true. There we condition on the message, not on the ciphertext.

Counterexample

Take the one-time pad with $\ell = 1$, so $\mathcal{M} = \mathcal{K} = \mathcal{C} = \{0, 1\}$ and $c = m \oplus k$ with uniform $k$. It is perfectly secret (script Theorem 5). Choose the distribution

$$\Pr[M = 0] = \tfrac14, \qquad \Pr[M = 1] = \tfrac34.$$

For $c = 0$:

$$\Pr[C = 0] = \Pr[M = 0]\Pr[K = 0] + \Pr[M = 1]\Pr[K = 1] = \tfrac14 \cdot \tfrac12 + \tfrac34 \cdot \tfrac12 = \tfrac12 \gt 0,$$ $$\Pr[M = 0 \mid C = 0] = \frac{\Pr[M = 0 \wedge K = 0]}{\Pr[C = 0]} = \frac{\frac14 \cdot \frac12}{\frac12} = \tfrac14, \qquad \Pr[M = 1 \mid C = 0] = \frac{\frac34 \cdot \frac12}{\frac12} = \tfrac34.$$

So $\Pr[M = 0 \mid C = 0] = \frac14 \ne \frac34 = \Pr[M = 1 \mid C = 0]$, although the scheme is perfectly secret. $\blacksquare$

The statement is true only for the uniform distribution over $\mathcal{M}$: then both sides equal $\frac{1}{|\mathcal{M}|}$.
