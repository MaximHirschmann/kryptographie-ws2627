Question

Prove or refute: For every encryption scheme that is perfectly secret it holds that for every distribution over the message space $\mathcal{M}$, every $m, m' \in \mathcal{M}$, and every $c \in \mathcal{C}$:

$$\Pr[M = m \mid C = c] = \Pr[M = m' \mid C = c].$$
Answer. False. Perfect secrecy says the ciphertext does not change a message's probability, $\Pr[M = m \mid C = c] = \Pr[M = m]$. So the claim would require all messages to be equally likely, which fails for non-uniform distributions.

Counterexample

Take the one-bit one-time pad (perfectly secret) with $\Pr[M = 0] = \frac14$, $\Pr[M = 1] = \frac34$. For any $c$, perfect secrecy gives

$$\Pr[M = 0 \mid C = c] = \tfrac14 \ne \tfrac34 = \Pr[M = 1 \mid C = c]. \qquad \blacksquare$$

The true statement conditions on the message instead: $\Pr[C = c \mid M = m] = \Pr[C = c \mid M = m']$ (script Definition 5).
