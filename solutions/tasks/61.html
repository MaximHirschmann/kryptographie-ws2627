Question

Adapt the CPA definition (Definition 3.21) to perfect secrecy: no limit on the adversary's running time, and the success probability must be exactly $\frac12$. Show that no encryption scheme can satisfy this definition.

Source: Katz & Lindell, 1st ed., Exercise 3.12 (restated).

Definition

$\Pi$ is perfectly CPA-secret if $\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi} = 1] = \frac12$ for every adversary $\mathcal{A}$, with no bound on its running time. (The experiment is the usual CPA game.)

Attack

1.Query the oracle on $m_0 = 0^n$ and receive $c_0$.
2.Output $m_0 = 0^n$, $m_1 = 1^n$ and receive the challenge $c$.
3.Output $0$ if $c = c_0$, otherwise $1$.

If $m_1$ was encrypted, then $c \ne c_0$ by correctness ($c$ and $c_0$ decrypt to different messages under the same key), so $\mathcal{A}$ is always right. If $m_0$ was encrypted, then $c = c_0$ with some probability $\delta \gt 0$, because two encryptions of the same message under the same key coincide with positive probability. Hence

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi} = 1] = \tfrac12 (\delta + 1) \gt \tfrac12.$$

So no scheme satisfies the definition. $\blacksquare$
