Question

Adapt the CPA definition (Definition 3.21) to perfect secrecy: no limit on the adversary's running time, and the success probability must be exactly $\frac12$. Show that no encryption scheme can satisfy this definition.

Source: Katz & Lindell, 1st ed., Exercise 3.12 (restated).

Definition

The experiment $\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}$:

1.$k \leftarrow \mathsf{Gen}$.
2.$\mathcal{A}$ gets oracle access to $\mathsf{Enc}_k(\cdot)$ and outputs $m_0, m_1$ of equal length.
3.$b \leftarrow \{0,1\}$, $c \leftarrow \mathsf{Enc}_k(m_b)$ is given to $\mathcal{A}$, who still has the oracle.
4.$\mathcal{A}$ outputs $b'$; the output is $1$ iff $b' = b$.

$\Pi$ is perfectly CPA-secret if $\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi} = 1] = \frac12$ for every adversary $\mathcal{A}$, with no bound on its running time.

Attack

Fix two different messages $m_0 \ne m_1$ of the same length.

1.Query the oracle once: $c_0 \leftarrow \mathsf{Enc}_k(m_0)$.
2.Output $m_0, m_1$; receive the challenge $c$.
3.Output $b' = 0$ if $c = c_0$, otherwise $b' = 1$.

Analysis

Case $b = 1$. Then $c$ is an encryption of $m_1$ and $c_0$ an encryption of $m_0$ under the same key. If $c = c_0$, correctness would give $m_1 = \mathsf{Dec}_k(c) = \mathsf{Dec}_k(c_0) = m_0$. So $c \ne c_0$ always, and $\mathcal{A}$ outputs $1$: correct with probability $1$.

Case $b = 0$. Then $c$ and $c_0$ are two independent encryptions of $m_0$ under $k$. Let $\delta := \Pr[c = c_0 \mid b = 0]$. $\mathsf{Enc}_k(m_0)$ takes values in a finite set under a fixed polynomial runtime bound (and at worst a countable set for a general terminating probabilistic algorithm), so for each fixed $k$

$$\Pr[c = c_0 \mid k] = \sum_{x} \Pr[\mathsf{Enc}_k(m_0) = x]^2 \;\gt\; 0,$$

and therefore $\delta \gt 0$. $\mathcal{A}$ is correct in this case exactly when $c = c_0$.

$$\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi} = 1] = \tfrac12 \cdot \delta + \tfrac12 \cdot 1 = \tfrac12 + \tfrac{\delta}{2} \;\gt\; \tfrac12.$$
Result. One oracle query always gives an advantage $\delta/2 \gt 0$, so no scheme is perfectly CPA-secret. For deterministic encryption $\delta = 1$ and the adversary always wins. $\blacksquare$

This is why CPA security is only defined computationally. A randomized scheme with $\delta \le \mathsf{negl}(n)$ (e.g. $\langle r, F_k(r) \oplus m \rangle$ with a fresh $r$) makes this attack useless, but $\delta$ can never be exactly $0$. The adversary does not even need unbounded running time here; the only thing that fails is the requirement "exactly $\frac12$".
