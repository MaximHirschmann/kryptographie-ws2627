Question

Three users have RSA public keys $\langle N_1, 3\rangle$, $\langle N_2, 3\rangle$, $\langle N_3, 3\rangle$ with $N_1 \lt N_2 \lt N_3$. To send the same $m$ to all three, the sender picks one $r \leftarrow \mathbb{Z}_{N_1}$ and broadcasts

$$\big\langle\, [r^3 \bmod N_1],\ [r^3 \bmod N_2],\ [r^3 \bmod N_3],\ H(r) \oplus m \,\big\rangle.$$
  1. Show that an adversary can recover $m$, even if $H$ is a random oracle.
  2. Fix the scheme to get CPA security with ciphertext length $3|m| + O(n)$.
  3. Do better: CPA security with ciphertext length $|m| + O(n)$.

Source: Katz & Lindell, 1st ed., Exercise 13.6 (restated). This is Håstad's broadcast attack.

(a) Attack via the CRT

Let $c_i = [r^3 \bmod N_i]$ (assume the $N_i$ pairwise coprime; otherwise a gcd factors them).

1.With the CRT compute $R \in \mathbb{Z}_{N_1 N_2 N_3}$ with $R \equiv c_i \pmod{N_i}$.
2.Since $r \lt N_1 \lt N_2 \lt N_3$, $r^3 \lt N_1 N_2 N_3$, so $R = r^3$ over the integers. Compute the integer cube root $r = \sqrt[3]{R}$.
3.Query $H(r)$ and output $m = H(r) \oplus c_4$.

The random oracle does not help, because $r$ itself is recovered. $\blacksquare$

(b) Independent $r_i$ per recipient: $3|m| + O(n)$

$$\big\langle\, [r_1^3 \bmod N_1],\ [r_2^3 \bmod N_2],\ [r_3^3 \bmod N_3],\ H(r_1) \oplus m,\ H(r_2) \oplus m,\ H(r_3) \oplus m \,\big\rangle$$

with independent $r_i \leftarrow \mathbb{Z}_{N_i}$. Each part is the CPA-secure RSA scheme in the random oracle model (Question 96), and independent encryptions stay CPA-secure (hybrid argument).

(c) Hybrid encryption: $|m| + O(n)$

Use (b) to send a fresh key $k \leftarrow \{0,1\}^n$ and encrypt $m$ only once under $k$:

$$\big\langle\, [r_i^3 \bmod N_i],\ H(r_i) \oplus k \,\big\rangle_{i=1,2,3},\ \ \mathsf{Enc}'_k(m),$$

for a CPA-secure private-key scheme $\Pi'$ with ciphertexts of length $|m| + O(n)$. The key parts have length $O(n)$, so the total is $|m| + O(n)$. $\blacksquare$
