Question

Three users have RSA public keys $\langle N_1, 3\rangle$, $\langle N_2, 3\rangle$, $\langle N_3, 3\rangle$ with $N_1 \lt N_2 \lt N_3$. To send the same $m$ to all three, the sender picks one $r \leftarrow \mathbb{Z}_{N_1}$ and broadcasts

$$\big\langle\, [r^3 \bmod N_1],\ [r^3 \bmod N_2],\ [r^3 \bmod N_3],\ H(r) \oplus m \,\big\rangle.$$
  1. Show that an adversary can recover $m$, even if $H$ is a random oracle.
  2. Fix the scheme to get CPA security with ciphertext length $3|m| + O(n)$.
  3. Do better: CPA security with ciphertext length $|m| + O(n)$.

Source: Katz & Lindell, 1st ed., Exercise 13.6 (restated). This is Håstad's broadcast attack.

(a) Attack via the CRT

Let $c_i = r^3 \bmod N_i$. If two moduli share a factor, $\gcd(N_i, N_j)$ factors both and the attacker can decrypt directly. So assume the $N_i$ are pairwise coprime.

1.Use the CRT to find the unique $R \in \mathbb{Z}_{N_1N_2N_3}$ with $R \equiv c_i \pmod{N_i}$ for $i = 1,2,3$.
2.Since $r \lt N_1 \lt N_2 \lt N_3$, we have $r^3 \lt N_1 N_2 N_3$, so $R = r^3$ as an integer, with no modular reduction.
3.Compute the ordinary integer cube root $r = \sqrt[3]{R}$ (binary search, polynomial time).
4.Query $H(r)$ and output $m = H(r) \oplus c_4$.

The random oracle does not help: the security proof assumes $r$ stays hidden, but here $r$ is recovered completely without ever inverting RSA. The problem is that the same $r$ is encrypted under three moduli with the small exponent $e = 3$. $\blacksquare$

(b) Independent randomness per recipient: $3|m| + O(n)$

Encrypt separately for each recipient with fresh randomness $r_i \leftarrow \mathbb{Z}_{N_i}$:

$$\big\langle\, r_1^3 \bmod N_1,\ H(r_1) \oplus m,\ \ r_2^3 \bmod N_2,\ H(r_2) \oplus m,\ \ r_3^3 \bmod N_3,\ H(r_3) \oplus m \,\big\rangle.$$

Each part is the RSA scheme from Question 96, which is CPA-secure in the random oracle model under the RSA assumption. Three independent encryptions under independent keys remain CPA-secure by a hybrid argument (replace $m_0$ by $m_1$ in one part at a time). Length: $3 \cdot (\|N\| + |m|) = 3|m| + O(n)$, with $\|N_i\| = O(n)$.

(c) Hybrid encryption: $|m| + O(n)$

Encrypt the message only once, under a fresh short key, and send that key to everyone:

$$k \leftarrow \{0,1\}^n, \qquad \big\langle\, r_i^3 \bmod N_i,\ H(r_i) \oplus k \,\big\rangle_{i = 1,2,3},\ \ G(k) \oplus m,$$

with independent $r_i \leftarrow \mathbb{Z}_{N_i}$, $H$ with $n$-bit output, and a second random oracle $G$ with $|m|$-bit output. (Equivalently, the last part can be $\mathsf{Enc}'_k(m)$ for any EAV-secure private-key scheme.)

  • Length: $3(\|N\| + n) + |m| = |m| + O(n)$.
  • Security sketch: unless the adversary queries $H$ at some $r_i$ (which requires inverting RSA for a uniform $r_i$, so negligible), the three values $H(r_i) \oplus k$ are one-time pads and $k$ stays uniform. Unless the adversary then queries $G(k)$ (probability $\le q_G/2^n$), $G(k) \oplus m$ is a one-time pad of $m$. So the advantage is negligible.
Result. (a) The same $r$ with $e = 3$ under three moduli gives $r^3$ over the integers via the CRT, and an integer cube root reveals $r$. (b) Fresh $r_i$ per recipient fixes it at cost $3|m|$. (c) Hybrid encryption sends the long message once: encrypt a short key $k$ three times and $m$ once under $k$. $\blacksquare$

The lesson for practice: never encrypt the same (or related) values with small $e$ under several keys. Randomized padding or hybrid encryption with independent randomness per recipient is required.
