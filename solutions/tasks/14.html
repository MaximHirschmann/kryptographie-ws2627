Question

Assume that $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ satisfies Definition 2.1 for all distributions over $\mathcal{M}$ so that $\Pr[M = m] \gt 0$ for all $m \in \mathcal{M}$. Show that the scheme satisfies the definition for all distributions over $\mathcal{M}$, i.e., including those where $\Pr[M = m] = 0$ for some $m \in \mathcal{M}$. Conclude that the scheme is also perfectly secret for any message space $\mathcal{M}' \subseteq \mathcal{M}$.

Definition 2.1 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every $m \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$ for which $\Pr[C = c] \gt 0$ it holds that $\Pr[M = m \mid C = c] = \Pr[M = m]$.

Key observation

Let $p_m(c) := \Pr[\mathsf{Enc}_K(m) = c]$. Because $K$ is independent of $M$, this does not depend on the message distribution, and for every distribution $D$

$$\Pr_D[M = m \wedge C = c] = \Pr_D[M = m] \cdot p_m(c) \tag{$*$}$$

(also when $\Pr_D[M = m] = 0$: then both sides are $0$).

Step 1: $p_m(c)$ is the same for all $m$

Use the uniform distribution $U$, which gives every message positive probability, so the assumption applies. If $\Pr_U[C = c] \gt 0$, then by the assumption and $(*)$, $\frac{1}{|\mathcal{M}|} = \Pr_U[M = m \mid C = c] = \frac{p_m(c)}{|\mathcal{M}| \Pr_U[C = c]}$, so $p_m(c) = \Pr_U[C = c]$ for every $m$. If $\Pr_U[C = c] = \frac{1}{|\mathcal{M}|} \sum_m p_m(c) = 0$, then every $p_m(c) = 0$. Either way $p_m(c) = p(c)$ for all $m$.

Step 2: any distribution $D$

Fix $m$ and $c$ with $\Pr_D[C = c] \gt 0$. By $(*)$ and Step 1, $\Pr_D[C = c] = \sum_{m'} \Pr_D[M = m'] \, p(c) = p(c)$, hence

$$\Pr_D[M = m \mid C = c] = \frac{\Pr_D[M = m] \cdot p(c)}{p(c)} = \Pr_D[M = m]. \qquad \blacksquare$$

Conclusion for $\mathcal{M}' \subseteq \mathcal{M}$

A distribution over $\mathcal{M}'$ is a distribution over $\mathcal{M}$ that gives probability $0$ to the messages outside $\mathcal{M}'$. By Step 2 the scheme is perfectly secret for it, so it is perfectly secret over $\mathcal{M}'$. $\blacksquare$
