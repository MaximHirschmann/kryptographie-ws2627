Question

Assume that $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ satisfies Definition 2.1 for all distributions over $\mathcal{M}$ so that $\Pr[M = m] \gt 0$ for all $m \in \mathcal{M}$. Show that the scheme satisfies the definition for all distributions over $\mathcal{M}$, i.e., including those where $\Pr[M = m] = 0$ for some $m \in \mathcal{M}$. Conclude that the scheme is also perfectly secret for any message space $\mathcal{M}' \subseteq \mathcal{M}$.

Definition 2.1 An encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ over a message space $\mathcal{M}$ is perfectly secret if for every probability distribution over $\mathcal{M}$, every $m \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$ for which $\Pr[C = c] \gt 0$ it holds that $\Pr[M = m \mid C = c] = \Pr[M = m]$.

Key observation

For every $m \in \mathcal{M}$ and $c \in \mathcal{C}$ define

$$p_m(c) := \Pr[\mathsf{Enc}_K(m) = c].$$

This depends only on $\mathsf{Gen}$ and $\mathsf{Enc}$, not on the distribution of $M$, because $K$ is chosen independently of $M$. For every distribution over $\mathcal{M}$ (writing $\Pr_D$ for probabilities under $D$),

$$\Pr_D[M = m \wedge C = c] = \Pr_D[M = m] \cdot p_m(c). \tag{$*$}$$

This also holds when $\Pr_D[M = m] = 0$, because then both sides are $0$.

Step 1: $p_m(c)$ does not depend on $m$

Let $U$ be the uniform distribution over $\mathcal{M}$ ($\mathcal{M}$ is finite). Every message has probability $\frac{1}{|\mathcal{M}|} \gt 0$, so the assumption applies to $U$. Fix $c \in \mathcal{C}$.

Case $\Pr_U[C = c] \gt 0$. For every $m$, by the assumption and $(*)$:

$$\frac{1}{|\mathcal{M}|} = \Pr_U[M = m] = \Pr_U[M = m \mid C = c] = \frac{\Pr_U[M = m \wedge C = c]}{\Pr_U[C = c]} \overset{(*)}{=} \frac{\frac{1}{|\mathcal{M}|} \cdot p_m(c)}{\Pr_U[C = c]}.$$

Hence $p_m(c) = \Pr_U[C = c]$ for every $m$.

Case $\Pr_U[C = c] = 0$. Then $0 = \Pr_U[C = c] = \sum_m \frac{1}{|\mathcal{M}|} p_m(c)$. A sum of non-negative terms is $0$ only if every term is $0$, so $p_m(c) = 0$ for every $m$.

In both cases there is a value $p(c)$ with $p_m(c) = p(c)$ for all $m \in \mathcal{M}$.

Step 2: Definition 2.1 for an arbitrary distribution

Let $D$ be any distribution over $\mathcal{M}$, possibly with $\Pr_D[M = m] = 0$ for some $m$. Fix $m \in \mathcal{M}$ and $c$ with $\Pr_D[C = c] \gt 0$. By the law of total probability, $(*)$ and Step 1:

$$\Pr_D[C = c] = \sum_{m' \in \mathcal{M}} \Pr_D[M = m'] \cdot p_{m'}(c) = p(c) \sum_{m' \in \mathcal{M}} \Pr_D[M = m'] = p(c).$$

So $p(c) \gt 0$, and

$$\Pr_D[M = m \mid C = c] = \frac{\Pr_D[M = m \wedge C = c]}{\Pr_D[C = c]} \overset{(*)}{=} \frac{\Pr_D[M = m] \cdot p(c)}{p(c)} = \Pr_D[M = m].$$

This is Definition 2.1 for $D$. Since $D$ was arbitrary, the scheme is perfectly secret for all distributions over $\mathcal{M}$. $\blacksquare$

We could not simply use Bayes with $\Pr[C = c \mid M = m]$: if $\Pr_D[M = m] = 0$, that conditional probability is undefined. Working with the joint probability $(*)$ avoids the problem.

Conclusion: every $\mathcal{M}' \subseteq \mathcal{M}$

Restrict the scheme to a message space $\mathcal{M}' \subseteq \mathcal{M}$. Any distribution $D'$ over $\mathcal{M}'$ is also a distribution $D$ over $\mathcal{M}$, with $\Pr_D[M = m] = 0$ for $m \notin \mathcal{M}'$. Both give the same random variables $M$ and $C$. By Step 2, $\Pr_{D'}[M = m \mid C = c] = \Pr_{D'}[M = m]$ for all $m \in \mathcal{M}'$ and all $c$ with $\Pr_{D'}[C = c] \gt 0$. Hence the scheme is perfectly secret over $\mathcal{M}'$. $\blacksquare$

This is used in Question 15: in the PrivK game, the message is uniform over just two messages $\{m_0, m_1\} \subseteq \mathcal{M}$.
