Question

Let $N = pq$ the product of two distinct primes. Give a polynomial algorithm which takes as input $N$ and $\varphi(N)$ and computes $p$ and $q$.

Idea. $N$ and $\varphi(N)$ give the product and the sum of $p$ and $q$:

$$\varphi(N) = (p-1)(q-1) = N - (p + q) + 1 \quad\Longrightarrow\quad S := p + q = N - \varphi(N) + 1.$$

So $p, q$ are the roots of $X^2 - SX + N$.

Algorithm

1.$S := N - \varphi(N) + 1$
2.$d := \sqrt{S^2 - 4N}$ (integer square root; $S^2 - 4N = (p - q)^2$)
3.output $p := \frac{S + d}{2}$, $q := \frac{S - d}{2}$

Only additions, multiplications and an integer square root (binary search) on $\mathcal{O}(\log N)$-bit numbers, so it runs in polynomial time. Example: $N = 77$, $\varphi(N) = 60$ give $S = 18$, $d = 4$, $p = 11$, $q = 7$. $\blacksquare$
