Question

Consider a variant of CBC-mode encryption where the sender simply increments the $IV$ by 1 each time a message is encrypted (rather than choosing $IV$ at random each time). Show that the resulting scheme is not CPA-secure.

In CBC, $c_0 := IV$ and $c_i := F_k(c_{i-1} \oplus m_i)$; the IV is sent in the clear. In this variant the next IV is the previous one plus 1, so the attacker can predict it and cancel it with its challenge message.

Attack

1.Query the oracle on $0^n$ and receive $\langle IV, c \rangle$ with $c = F_k(IV)$.
2.The challenge will use $IV + 1$. Output $m_0 := IV \oplus (IV + 1)$ and any $m_1 \ne m_0$.
3.Receive $\langle IV + 1, c^* \rangle$ and output $0$ iff $c^* = c$.

If $b = 0$, the block-cipher input is $(IV + 1) \oplus m_0 = IV$, so $c^* = F_k(IV) = c$. If $b = 1$, the input differs from $IV$, and since $F_k$ is a permutation, $c^* \ne c$. The attacker always wins, so the scheme is not CPA-secure. $\blacksquare$

The book's solution uses $m_0 = 0^n$ and only works when $IV$ is even (success probability $\frac34$). Choosing $m_0 = IV \oplus (IV + 1)$ works for every IV.
