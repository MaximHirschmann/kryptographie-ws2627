Question

Let $G$ be a pseudorandom generator where $|G(s)| \gt 2|s|$.

  1. Is $G'(s) = G(s 0^{|s|})$ necessarily a pseudorandom generator?
  2. Is $G'(s) := G(s_1 \cdots s_{n/2})$, where $s = s_1 \cdots s_n$, necessarily a pseudorandom generator?

1. $G'(s) = G(s\,0^{|s|})$: no, not necessarily

$G'$ runs $G$ on a seed that is not uniform, and a PRG only guarantees anything for uniform seeds.

Counterexample. Let $H$ be a PRG with $|H(y)| \gt 4|y|$ and define $G(x \| y) := H(y)$ for $|x| = |y|$. $G$ is a PRG: its seed $x \| y$ has length $2n$, the output is longer than $4n$, and for a uniform seed $y$ is uniform. But

$$G'(s) = G(s \| 0^{|s|}) = H(0^{|s|})$$

is a fixed string, which is trivially distinguishable from random.

2. $G'(s) = G(s_1 \cdots s_{n/2})$: yes

Expansion: $|G'(s)| = |G(s_1 \cdots s_{n/2})| \gt 2 \cdot \frac n2 = n$.

Pseudorandomness: for uniform $s$, the half $s_1 \cdots s_{n/2}$ is uniform in $\{0,1\}^{n/2}$, so $G'(s)$ is distributed exactly like $G$ on a uniform seed of length $n/2$. Any distinguisher for $G'$ therefore distinguishes $G$ with the same advantage $\varepsilon(n) = \varepsilon'(n/2)$, which is negligible because $\varepsilon'$ is. $\blacksquare$
