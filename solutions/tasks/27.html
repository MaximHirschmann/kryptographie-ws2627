Question

Let $G$ be a pseudorandom generator where $|G(s)| \gt 2|s|$.

  1. Is $G'(s) = G(s 0^{|s|})$ necessarily a pseudorandom generator?
  2. Is $G'(s) := G(s_1 \cdots s_{n/2})$, where $s = s_1 \cdots s_n$, necessarily a pseudorandom generator?

1. $G'(s) = G(s\,0^{|s|})$: no, not necessarily

$G'$ feeds $G$ a seed that is not uniform: its second half is always $0^n$. A PRG only guarantees pseudorandom output for uniform seeds, so it may behave badly on this tiny set of seeds.

Counterexample. Let $\hat G$ be any PRG with $|\hat G(s)| \gt 2|s|$, and define on seeds $x \| y$ with $|x| = |y|$:

$$G(x \| y) := \begin{cases} 0^{\ell} & \text{if } y = 0^{|y|}, \\ \hat G(x \| y) & \text{otherwise.} \end{cases}$$
  • $G$ is a PRG: for a uniform seed, $y = 0^{|y|}$ happens only with probability $2^{-|y|}$, which is negligible. Otherwise $G$ behaves like $\hat G$, so any distinguisher's advantage changes by at most a negligible amount.
  • $G'$ is not a PRG: $G'(s) = G(s \| 0^{|s|}) = 0^{\ell}$ for every seed. The distinguisher "output $1$ iff the input is all zeros" has advantage $1 - 2^{-\ell}$.

2. $G'(s) = G(s_1 \cdots s_{n/2})$: yes

Expansion: $|G'(s)| = |G(s_1 \cdots s_{n/2})| \gt 2 \cdot \frac n2 = n = |s|$.

Pseudorandomness: if $s$ is uniform in $\{0,1\}^n$, its first half $s' := s_1 \cdots s_{n/2}$ is uniform in $\{0,1\}^{n/2}$. Let $D$ be a PPT distinguisher for $G'$. Then $D$ itself distinguishes $G$ at seed length $n/2$:

$$\Big|\Pr[D(G'(s)) = 1] - \Pr[D(r) = 1]\Big| = \Big|\Pr_{s' \leftarrow \{0,1\}^{n/2}}[D(G(s')) = 1] - \Pr[D(r) = 1]\Big| \le \mathsf{negl}(n/2).$$

$n \mapsto \mathsf{negl}(n/2)$ is negligible in $n$. For any polynomial $p$, apply the definition with the polynomial $p(2m)$: $\mathsf{negl}(m) \lt \frac{1}{p(2m)}$ for large $m$, i.e. $\mathsf{negl}(n/2) \lt \frac{1}{p(n)}$. So $G'$ is a PRG. $\blacksquare$

The difference: in part 2 the bits that are thrown away are simply ignored, and the bits that are used are still uniform. In part 1 half of the seed $G$ receives is fixed, so it is no longer uniform.
